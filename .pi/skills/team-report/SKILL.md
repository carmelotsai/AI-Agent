# 團隊日報

系統會把今天的交辦紀錄附在指令或訊息最後（【今日交辦】；例行工作、使用者說「團隊日報」都會附），**由程式從紀錄整理，直接照這份寫，不要再查，也不要自己補**。沒有附上的話，照實說「這次沒有拿到交辦紀錄」，只寫你這本對話裡記得的交辦。

## 步驟

1. 讀【今日交辦】。寫「今天沒有交辦給任何助理」就只回一句「今天沒有交辦給助理」，不要湊內容。
2. **要老闆確認的事**放最前面：照紀錄裡每一筆「要老闆確認」一字不改地列，前面寫是哪位助理、交辦 #編號。
3. **今天團隊做了什麼**：照助理分組，一筆一行：#編號、時間、交辦了什麼、結果（已回報／被叫停／失敗）。議會寫參加的助理與議題。
4. **沒完成的**：狀態是被叫停、失敗、沒有結束紀錄的，單獨列出來，寫「要的話明天再交辦一次」。
5. 照下方格式回覆，**不要存檔**。

## 格式

```text
👥 團隊日報（10/14）

❗ 要老闆確認
- 業務 #12：C 公司 RA-200 報 490,000 低於新客戶底價 495,000，是否同意

📨 今天團隊做了什麼
業務助理
- #11 09:42 查 A 公司上次報價｜已回報
- #12 09:43 擬 C 公司報價回覆｜已回報

⏸ 沒完成的
- （無）
```

## 規矩

- 只寫紀錄裡有的；不要寫助理回報的金額細節以外的推測。
- 數字、客戶名稱照紀錄抄，不要改寫。
- 這是例行工作時（訊息開頭是【例行工作：…】），老闆不一定在看手機：不要問問題。

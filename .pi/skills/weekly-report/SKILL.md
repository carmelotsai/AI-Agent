# 週報

## 步驟

1. 算出本週範圍（週一到今天）。
2. 用 `ls` 列出 `日誌/`，用 `read` 讀本週每一份日誌（檔名就是日期）。本週沒有任何日誌，就直接告訴使用者，不要硬寫。
3. 需要細節時，可以讀日誌「產出的文件」列出的檔案。
4. 照下方格式產出，存到 `文件/YYYY-MM-DD_週報.md`（日期用本週週一）。
5. 回覆使用者：三句話內的本週摘要 + 存檔路徑，並說明「這是草稿，請檢查後再交出去」。

## 格式

```markdown
# 週報：YYYY-MM-DD ～ YYYY-MM-DD

## 本週重點
- （最重要的 1～3 件事）

## 完成事項
- …

## 進行中／待辦
| 事項 | 狀態 | 下一步 |
|---|---|---|

## 下週計畫
- （從「還沒完成的事」延伸；日誌沒提到的不要編）

## 需要協助或決策
- （沒有就寫「（無）」）
```

## 規矩

- 內容只能來自日誌和日誌提到的文件，**不可以編造**進度或數字。
- 內容涉及不同部門或專案時，「完成事項」依部門或專案分組。

# Gemini PI Agent

用 [Pi](https://github.com/earendil-works/pi) 的 Agent 引擎 + Google **Gemini API**（預設 `gemini-3.5-flash-lite`），
在你自己的電腦上跑一個有個性、有記憶、能讀寫檔案與執行指令的私人 AI 助理，透過 Telegram 跟它對話。

不用租雲端伺服器、不用固定 IP；執行的電腦開機、連網即可。

> 這個 repo 是我把自己的 AI 秘書整理成的**分享版**：從 L0 招聘準備（給沒用過 coding agent 的人）到 L4 主動工作的學員手冊與施工工單，加上目前的完整程式。教材在 [`docs/`](./docs)（見下方「課程教材」）。還在持續修改，歡迎回報卡住的地方。

## 你會得到什麼

- **不用寫程式**：跟著下面步驟填幾個值就能跑起來。
- **完全屬於你自己**：`SOUL.md`（它是誰）、`MEMORY.md`（它記得你什麼）都在你的電腦上，可以直接編輯。
- **手機隨身對話**：透過 Telegram，只要執行 Agent 的電腦開著就能回你訊息。
- **它有工具**：讀檔、寫檔、編輯、執行指令、搜尋檔案，範圍限定在這個專案資料夾。
- **它有記性**（L2-1、L2-3）：對話存在硬碟，同一天重啟接著聊；每天的對話自動整理成 `日誌/YYYY-MM-DD.md`，啟動時讀最近 7 份；待辦會一天天延續。
- **它有辦公桌**（L2-2）：產出的文件一律放進 `文件/`，找得到自己寫過的東西；`文件/`、`日誌/` 不會上傳到 Git。
- **它有技能**（L2-4、L2-6）：`.pi/skills/` 裡的會議紀錄、行程規劃、週報，也可以把你自己的做法寫成技能。
- **叫得停**（L2-5）：它做事做到一半，傳 `/stop` 就會馬上停下；叫停後不會把那件事說成做完。
- **有存檔**（L2-7）：coding agent 用 Git 替專案存版本，備份到 GitHub 私人倉庫；升級壞了退得回來，`.env`、`data/`、`文件/`、`日誌/` 不會上去。
- **會傳檔案、能裝外掛**（L3-1）：`文件/`、`日誌/` 裡的檔案直接傳到你的 Telegram；新本事以 `外掛/` 裡的資料夾加入，移出資料夾就停用。
- **權限分級**（L3-2）：查閱直接做（只看專案資料夾，不讀 `.env`）；擬稿只能寫 `文件/`、`.pi/skills/`，`MEMORY.md` 只能修改；執行指令前一定先傳按鈕問你，會碰到重要檔案或刪東西的指令另有 ⚠️ 警示。規則在 `權限.json`。
- **做 Word、Excel**（L3-3）：把 `文件/` 裡的 `.md` 轉成 Word；把表格做成 Excel，加總用公式（改金額會自動更新）。做好可以直接傳到手機。
- **查地圖排行程**（L3-4，需要免費的 SerpApi 金鑰）：查 Google 地圖的營業時間、公休日、車程，排行程會避開公休；回覆最後的「📍 本次實際查了…」與行程檔尾的查詢紀錄由程式寫入，看得出他有沒有真的查。
- **行事曆**（L3-5，需要自己在 Google Cloud 建一個專案並授權一次）：看 Google 行事曆；你要求時新增、修改、刪除行程，每次都先傳按鈕確認，做完附活動連結；不加參加者、不寄通知。
- **Gmail**（L3-6，沿用 L3-5 的 Google 專案，多授權一次）：找信、讀信、寫回信草稿；寄出前把收件人、主旨、內文傳按鈕給你確認，按了才寄。信件內容會送到 Gemini：免費方案下 Google 可能用來改進產品，公司信件請先開通計費並確認公司規定。
- **讀檔案**（L3-3）：在 Telegram 直接傳照片、Word、Excel、PDF、PPT，他會先轉成文字再讀；原檔留在 `文件/收到/`，之後還找得到。
- **提醒與待辦追蹤**（L4-1）：「明天早上九點提醒我……」，時間到就傳給你；交代的待辦會一路追到做完。
- **晨間簡報**（L4-2）：每天早上自己查行程、看提醒、翻日誌，整理成一則晨報傳給你。
- **會議前提醒與重要新信**（L4-3）：會議快開始先叫你；你指定的人或主旨來信，馬上通知你（只傳寄件人和主旨）。
- **情報收集**（L4-4）：每小時幫你看一次關心的主題新聞，晨報挑重點、附連結。
- **索引式記憶**（L4-5）：替日誌建目錄和月摘要，問幾個月前的事也找得到。
- **自我覆盤**（L4-6）：每週五檢討這週被叫停、被按「不要」的原因，建議改哪份技能的哪一句；只建議，不會自己改。

**這個版本刻意不做的事**：不會自己改 `MEMORY.md`（只有你說「記下來」才寫；日誌是另外一份）；寄信、改行事曆、執行指令前一定先傳按鈕問你；自我覆盤只提建議，不會自己改技能；看不懂語音和影片（會請你改用打字）。

## 使用階段：先測試版，OK 再升級長期版

這個架構設計成**分兩階段用**，中間不用重寫任何程式碼，只差「有沒有開計費」：

| | 階段一・測試版 | 階段二・長期使用版 |
|---|---|---|
| **費用** | 免費（Google AI Studio 免費額度） | 開通計費，小額儲值即可 |
| **速率限制** | 約 RPM 15／RPD 500（緊，見下方說明） | 跳升到遠高於免費層 |
| **要改的東西** | 無，跟著下面「安裝與設定」做 | 只要去 AI Studio 開通計費，**`.env`／程式碼都不用動** |
| **適合** | 先確認 Gen 的個性、記憶、白名單設定都對 | 確定要每天長期靠它辦事 |

**建議流程**：

1. 先用**免費額度**跑完下面「安裝與設定」，把 Gen 的 `SOUL.md`／`MEMORY.md` 調到你滿意為止。
2. 用免費額度測試至少幾天，跑過下面「測試清單」，確認沒問題。
3. 確定要長期使用 → 去 [Google AI Studio](https://aistudio.google.com/apikey) 開通計費、**設定每月預算上限**（例如 $5 美金），小額儲值即可，Flash-Lite 很便宜。開通後同一組 `GEMINI_API_KEY` 直接繼續用，不用重新申請、不用改設定。

### 測試清單（階段一該驗證的事）

- [ ] 傳「你是誰？」→ 回答符合 `SOUL.md`（名字、職責、個性）
- [ ] 傳「我是誰？」→ 回答符合 `MEMORY.md`（稱呼、背景、注意事項）
- [ ] 傳「記下來：……」→ 內容確實寫進 `MEMORY.md`「其他你要我記住的事」，重啟後問得出來
- [ ] 拿另一個 Telegram 帳號傳訊息 → 完全沒反應（終端機印「忽略非白名單使用者」）
- [ ] 正常一天使用下來，沒有頻繁跳「額度已到」的訊息

全部打勾，代表架構沒問題，可以放心進階段二。L2 各項功能的考核，見各課學員手冊的「結訓考核」。

## 安裝與設定

### 1. 安裝依賴

```bash
npm install
```

### 2. 申請 Gemini API Key

前往 [Google AI Studio](https://aistudio.google.com/apikey)，用你的 Google 帳號登入，點「Create API key」拿到金鑰。

> ⚠️ **費用與資料須知**：Gemini API 有免費額度，超過依用量計費；免費額度的請求內容 Google 可能用於改善模型。
> 不要把真正敏感的個資、密碼、金融資訊寫進 `MEMORY.md` 或聊天訊息裡。

### 3. 建立 Telegram Bot

1. Telegram 搜尋 `@BotFather`，傳送 `/newbot`，依提示命名，拿到 `TELEGRAM_BOT_TOKEN`。
2. 找到剛建的 Bot，按「Start」並隨便傳一句話（之後查詢 User ID 需要這一步）。
3. 取得你的 Telegram User ID：

   **Windows PowerShell**：
   ```powershell
   $token = "你的Token"; (Invoke-RestMethod "https://api.telegram.org/bot$token/getUpdates").result | ForEach-Object { [PSCustomObject]@{ Id = $_.message.from.id; Name = $_.message.from.first_name } }
   ```

   **macOS / Linux**：
   ```bash
   curl -s "https://api.telegram.org/bot<你的Token>/getUpdates" | grep -o '"from":{"id":[0-9]*' | head -n 1
   ```

### 4. 設定 `.env`

複製範本並填入剛才拿到的值：

```bash
cp .env.example .env
```

```env
GEMINI_API_KEY=你的Gemini金鑰
TELEGRAM_BOT_TOKEN=你的BotToken
TELEGRAM_ALLOWED_USERS=你的UserID
```

`TELEGRAM_ALLOWED_USERS` **只填你自己**（多個 ID 用逗號分隔）。這是白名單守門：不在名單上的人傳訊息會被直接忽略。

（選填）要讓秘書查 Google 地圖（L3-4），再加一行 `SERPAPI_KEY=你的SerpApi金鑰`，到 [serpapi.com](https://serpapi.com) 註冊 Free Plan（每月 250 次）即可取得。

### 5. 啟動

- **Windows**：雙擊 `啟動 Agent.bat`，或在終端機執行 `npm start`
- **macOS**：雙擊 `啟動 Agent.command`（第一次要先 `chmod +x "啟動 Agent.command"`），或執行 `./start.sh`
- **Linux**：執行 `./start.sh`

看到「等待 Telegram 訊息…」就代表啟動成功。要停止就按 `Ctrl+C` 或關閉視窗。

## 「只跟你說話」的安全設定

程式裡的白名單是最後一道防線；Telegram 平台端還能再關一道，**兩道都做**：

1. 在 `@BotFather` 對你的 Bot 執行 `/setjoingroups` → **Disable**（不能被拉進群組）。
2. 執行 `/setprivacy` → **Enable**（在群裡只讀指令，不讀一般訊息）。
3. Bot 的使用者名稱不要公開分享——它能在你的電腦上執行指令，白名單裡的人等於能操作你的電腦。

Telegram 沒有「只允許某人私訊」的原生開關，所以 `.env` 裡的 `TELEGRAM_ALLOWED_USERS` 是主防線。

## 怎麼跟它說話

1. **問它是誰、你是誰**：確認 `SOUL.md`、`MEMORY.md` 有生效。
2. **貼內容給它**：整理、改寫、翻譯、給意見，直接貼文字過去。
3. **要它處理檔案**：把檔案放進專案資料夾，跟它說檔名。
4. **要它記新東西**：說「記下來：……」，它會寫進 `MEMORY.md`「其他你要我記住的事」；**重啟後**才會生效。
5. **同一天重啟接著聊，隔天換新的一本**：凌晨 4 點換日。換日後的第一則訊息，會先把前一天的對話整理成 `日誌/` 裡的工作日誌。
6. **`/new`**：今天先到這，馬上整理日誌、開新的一本對話。**`/recap`**：唸出最近一份日誌（不耗額度）。
7. **`/stop`**：它做到一半想叫停，傳 `/stop`；做事時你傳的其他訊息會一起取消。**`/status`**（L3-7）：列出它現在裝了哪些外掛、每個工具的權限等級、權限設定、金鑰有沒有填（不顯示內容）；它在忙也會馬上回，不耗額度。
8. **傳語音、圖片、檔案**：它會回覆看不懂、請你改傳文字；文件請另存成 `.md`／`.txt` 放進 `文件/`。
9. **要它把檔案傳給你**：說「把○○傳給我」，檔案會直接出現在 Telegram；只能傳 `文件/`、`日誌/` 裡的檔案。

## 客製化

- **它是誰**：直接編輯 `SOUL.md`（名字、職責、個性、規矩）。
- **它記得你什麼**：直接編輯 `MEMORY.md`（稱呼、背景、注意事項）。
- **它會什麼技能**：`.pi/skills/<技能名>/SKILL.md`，一個資料夾一個技能，用 Markdown 寫做法，改完重啟生效。
- **它能碰哪些地方**：`權限.json`（可以寫的地方、只能修改的檔案、不能讀的地方、按鈕等幾分鐘），改完重啟；寫壞了會自動用預設權限。
- **它有哪些外掛**：`外掛/<名稱>/index.mjs`，一個資料夾一個本事；移出 `外掛/` 再重啟就停用。外掛是程式，不要裝來路不明的外掛。
- **換模型**：`bridge.mjs` 裡的 `MODEL_CANDIDATES` 陣列，預設 `gemini-3.5-flash-lite` 優先，找不到就退到 `gemini-2.5-flash-lite`、`gemini-3.5-flash`。
- **思考等級**：`bridge.mjs` 裡的 `THINKING_LEVEL`，可選 `off`／`minimal`／`low`／`medium`／`high`／`xhigh`／`max`。預設 `medium`，兼顧回答品質與省 token；想再省可改 `low`。

修改 `SOUL.md`／`MEMORY.md`／`bridge.mjs` 後，都要重啟 Agent 才生效。

## 免費額度很緊，技術上做了什麼緩衝？

`gemini-3.5-flash-lite` 免費層的速率限制大約是**每分鐘 15 次請求、每天 500 次請求**（實際數字以 [Google 官方文件](https://ai.google.dev/gemini-api/docs/rate-limits) 為準，會調整）。這是「測試版」階段的正常現象，不是程式壞了。

**架構裡已經做的緩衝**（不用你動手，測試版就有）：
- `.pi/settings.json` 把 SDK 內建的自動重試次數與延遲拉高（最多重試 5 次、間隔遞增到最長 60 秒），遇到偶發的 429 速率限制，系統會自動重試，你通常不會發現。
- `THINKING_LEVEL` 預設 `medium` 而不是 `max`，減少 token 用量。

如果測試期間常常撞到「額度已到」的訊息，代表你已經準備好進入上面「使用階段」說的**階段二・長期使用版**了——開通計費即可，不用改任何設定。

## 常見坑

1. **啟動時報「找不到 GEMINI_API_KEY」**：確認 `.env` 存在且有填值，不是還在用 `.env.example`。
2. **啟動時報「找不到模型」**：多半是 API Key 打錯或沒有效；到 AI Studio 重新確認金鑰。
3. **回「Gemini 免費額度或速率上限可能已到」**：系統已經自動重試過還是失敗，代表額度真的到頂了；稍等一分鐘再試，或看上面「使用階段」考慮升級成長期使用版（開通計費）。
4. **Telegram 抓不到 User ID**：要先對 Bot 按過 Start 或發過一句話，`getUpdates` 才有資料。
5. **電腦睡眠後手機收不到回覆**：這是本機執行架構的限制，電腦要開著、啟動視窗要開著。Windows 把「電源選項」的合蓋動作改「不採取動作」；macOS 用 `caffeinate -i npm start` 啟動。
6. **它不記得好幾天前的細節**：啟動時只讀最近 7 份日誌；更早的它要自己去 `日誌/` 查，可以直接叫它「去查日誌」。
7. **改了設定、技能或人事資料沒效果**：先關掉黑視窗重新啟動，它是在上班那一刻讀這些東西的。改的是技能，重新啟動後**再傳 `/new`**：讀過的舊版技能會留在當天的對話裡，只重新啟動他會接著用舊版。
8. **早上開機後第一則回覆沒有「新的一天」提示**：秘書換日後才啟動時，日誌在啟動時就整理好了，提示印在黑視窗；傳 `/recap` 可確認。
9. **偶爾要等一兩分鐘才回**：網路不穩時，送給 Gemini 的連線可能斷掉；程式 90 秒沒收到回應會自動重連。Telegram 上方有「輸入中…」就是還在做，不用追問。
10. **Windows `啟動 Agent.bat` 雙擊後一閃即關**：`.bat` 內容必須是純 ASCII + CRLF；如果你手動改過這個檔案又存成 UTF-8 中文，會出現這個問題。改回本 repo 原始版本即可。

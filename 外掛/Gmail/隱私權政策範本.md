# AI 秘書｜隱私權政策

最後更新：【填今天的日期】

「AI 秘書」是我**在自己的電腦上架設、自己使用**的個人助理程式。這份政策說明它怎麼處理 Google 資料。

## 誰在使用這個應用程式

只有我自己。這個應用程式用**我自己的 Google Cloud 專案**建立授權，程式只在**我自己的電腦**上執行，沒有任何伺服器。

## 會讀取哪些 Google 資料

| 功能 | 權限範圍 | 做什麼 |
|---|---|---|
| 看行事曆 | Google 日曆（唯讀） | 我問行程時，讀取指定日期範圍的活動：時間、標題、地點 |
| 新增、修改、刪除行程 | Google 日曆活動 | 我要求時才做，**每次都會先在 Telegram 傳確認按鈕，我按同意才會執行** |
| 找信、讀信 | Gmail（唯讀） | 我要求時，用我給的條件搜尋信件、讀取我指定的信；不讀附件內容 |
| 寫草稿、寄信 | Gmail（撰寫） | 我要求時建立草稿（不會寄出）；**要寄出時，每次都會先在 Telegram 傳確認按鈕，列出收件人、主旨、內文，我按同意才會寄** |

程式**不會**在行程加上參加者、不會寄出行事曆邀請；不會刪除、封存或修改我的信件，也不會變更 Gmail 設定。

## 資料會去哪裡

1. **我的電腦**：授權權杖存在程式資料夾的 `data/google/`，不會上傳到任何地方（包括 Git）。
2. **Google Gemini API**：我問行程、要它找信讀信寫信時，相關的活動或信件內容會連同我的問題送到 Google Gemini API，讓 AI 模型整理成回答或草稿。**使用 Gemini API 免費層時，Google 可能用這些內容改進產品，並可能由人工審查；使用付費層（開通計費）則不會。**
3. **Telegram**：回答透過 Telegram 傳到我的手機。

除了上面列出的 Google（Gemini API）與 Telegram，資料不會提供給其他任何第三方，也不會用於廣告。從 Google API 取得的資料，使用方式遵守 [Google API 服務使用者資料政策](https://developers.google.com/terms/api-services-user-data-policy)（包括其中的「有限使用」規定）。

## 怎麼停止授權

- 到 Google 帳戶的「[第三方應用程式和服務](https://myaccount.google.com/connections)」移除這個應用程式，授權立刻失效。
- 刪除程式資料夾裡的 `data/google/`，電腦上的權杖也會一併刪除。

**English summary**: "AI 秘書" (AI Secretary) is a personal assistant that I set up and run on my own computer with my own Google Cloud project; I am its only user. At my request, it reads my Google Calendar events and creates, updates, or deletes events only after I tap a confirmation button in Telegram each time; it never adds attendees or sends invitations. At my request, it searches and reads my Gmail messages (not attachments) and creates drafts; it sends an email only after I review the recipients, subject, and body and tap a confirmation button in Telegram each time. It never deletes, archives, or modifies my messages or Gmail settings. Relevant calendar or email content is sent to the Google Gemini API to compose an answer or draft, and the answer is delivered to me via Telegram. OAuth tokens are stored only on my computer (`data/google/`). No data is shared with any third party or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked anytime at https://myaccount.google.com/connections.

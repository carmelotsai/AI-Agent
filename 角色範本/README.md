# 角色範本（L5 組建團隊）

這個資料夾**不會被秘書讀到**（有業務、廠務兩個範本）；要啟用，把整個 `業務/` **搬到**專案的 `角色/` 底下（變成 `角色/業務/`），重新啟動秘書。
用搬的、不要複製：範本裡是示範資料，留著的話秘書可能直接讀範本、不去問助理。
拿掉 `角色/` 資料夾再重啟，秘書就回到只有一位。

一位助理 = 一個資料夾：

| 檔案 | 用途 |
|---|---|
| `角色.json` | 負責什麼、用哪些外掛、分派規則（一句話一條，編號由程式給：業務-1、業務-2…）、關鍵字（你的訊息有這些字，秘書一定要交辦）、可以寫的地方 |
| `SOUL.md` | 助理的個性與做事原則（老闆的資料在共用的 `MEMORY.md`，不用重寫） |
| `資料/` | 這個部門自己的資料。**秘書讀不到** |
| `技能/` | 這個部門的 SOP（`.md`），助理做事前會先讀 |

`角色.json` 的「外掛」：寫在這裡的外掛會**從秘書身上拿走**、交給這位助理（`傳檔案`、`Office` 是共用的，秘書也留著）。
例如公司業務信箱的外掛交給業務，秘書就看不到業務信箱；你的個人 Gmail 通常留給秘書。

平常照樣跟秘書說話：符合分派規則的事，秘書會交給助理，回覆最後有 📨 寫出交給誰、他查了什麼。說「叫業務…」也可以指定。

想直接問助理：在 Telegram 傳「/試用 業務 A 公司上次報價多少」。回覆最後會寫是哪位助理答的、他查了哪些檔案。

自己招一位助理（L5-8）：照 `業務/` 或 `廠務/` 的樣子建 `角色/<名字>/`，重啟後傳 `/status`。寫漏、寫錯的地方（沒寫分派規則、關鍵字、SOUL.md，資料/ 是空的，外掛名字打錯，角色.json 讀不懂）會列在「團隊」那一段的 ⚠️ 或 ❌。

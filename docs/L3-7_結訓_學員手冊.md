# L3-7・結訓｜學員手冊

## 授權配發第七課：安全健檢＋結訓

> 這六課你給了秘書很多本事：傳檔案、做 Word 和 Excel、查地圖、看你的行事曆、讀你的信、寄信、執行指令。
> 本事越多，你越要**隨時看得清楚他現在能做什麼、怎麼收回**。這一課教他一個新指令 `/status`，帶你做一次安全健檢，然後做 L3 總考核，L3 授權配發就結業了。

---

## 這堂課結束，你會有什麼

傳 `/status`，他馬上列出自己現在能做什麼：

```text
📋 秘書狀態（2026-09-29 21:01）
現在：閒著
模型：google/gemini-3.5-flash-lite（思考等級 medium）
今天的對話：2026-09-29-1

外掛：
✅ Gmail：gmail_search、gmail_read（查閱）／gmail_draft（擬稿）／gmail_send（執行，先問你）
✅ Office：make_docx、make_xlsx（擬稿）
✅ 傳檔案：send_file（查閱）
✅ 地圖：maps_place、maps_route（查閱）
✅ 行事曆：calendar_events（查閱）／calendar_create、calendar_update、calendar_delete（執行，先問你）

內建工具：read、grep、find、ls（查閱）／write、edit（擬稿）／powershell（執行，先問你）
權限（權限.json）：可寫 文件/、.pi/skills/；只能修改 MEMORY.md；不能讀 .env、data/；執行前先問（5 分鐘沒回應就不做）
技能：meeting-notes、trip-plan、weekly-report、（你自己寫的技能）
白名單：1 人
金鑰（.env，只看有沒有填）：GEMINI_API_KEY ✅、TELEGRAM_BOT_TOKEN ✅、SERPAPI_KEY ✅

要收回權限：外掛 → 把資料夾移出「外掛」再重新啟動；Google（行事曆、Gmail）→ https://myaccount.google.com/connections 移除「AI 秘書」；金鑰 → 到各服務刪除後改 .env。
```

`/status` 有四個特點：

- **是程式寫的，不是 AI 回答的**：跟 📍、🗓️、✉️ 一樣，AI 沒辦法假造或漏講。
- **他在忙也會馬上回**：跟 `/stop` 一樣不排隊。「現在：正在做事，另有 1 則在排隊」就是他手上還有事。
- **不花額度**：不經過 Gemini。
- **不會顯示金鑰**：只寫有沒有填（✅ 或 —）。

你問他「你有哪些權限？」，他也會請你傳 `/status`。

## 安全健檢：一項一項問自己「這是我要給他的嗎？」

傳 `/status`，照下面的表逐行看：

| 看到什麼 | 代表什麼 | 不想要的話 |
|---|---|---|
| ✅ 某個外掛 | 他有這個本事 | 把 `外掛/` 裡那個資料夾移到別處，重新啟動 |
| ⚠️ 某個外掛「沒有啟用」 | 裝了但還沒授權或缺金鑰，所以不能用 | 不用管；要用的話看啟動時黑視窗寫的原因 |
| ❌ 某個外掛「載入失敗」 | 資料夾裡的程式壞了 | 請 coding agent 看啟動時黑視窗的錯誤訊息 |
| （執行，先問你） | 每次做之前一定傳按鈕給你 | 看不懂或不是你叫他做的，就按 ❌ |
| 權限（權限.json） | 他能寫哪些資料夾、哪些檔案只能改不能蓋 | 請 coding agent 改 `權限.json`，改完重新啟動 |
| 白名單 N 人 | 有幾個 Telegram 帳號能叫他做事 | 應該只有你自己（1 人）；不是的話請 coding agent 檢查 `.env` 的 `TELEGRAM_ALLOWED_USERS` |
| 金鑰 ✅ | 那個服務的金鑰有填 | 不再用的服務，到那個服務刪除金鑰，再把 `.env` 那一行清空 |

### 每一種權限怎麼收回

| 要收回的 | 怎麼做 | 生效 |
|---|---|---|
| 某個外掛的本事 | 把 `外掛/<名稱>` 資料夾移出 `外掛/` | 重新啟動後 |
| 行事曆＋Gmail 的 Google 授權 | [myaccount.google.com/connections](https://myaccount.google.com/connections) →「AI 秘書」→ 移除存取權（**兩個會一起收回**） | 立刻 |
| 只收回 Gmail | 把 `外掛/Gmail` 移出，再刪 `data/google/gmail-token.json` | 重新啟動後 |
| SerpApi（查地圖） | SerpApi 網站的 Dashboard 換一把新金鑰（舊的就失效），不用的話把 `.env` 的 `SERPAPI_KEY` 清空 | 立刻／重新啟動後 |
| Gemini 金鑰 | [Google AI Studio](https://aistudio.google.com/apikey) 刪掉那把金鑰，建一把新的填進 `.env` | 立刻 |
| Telegram Bot | Telegram 找 @BotFather →「/revoke」換新的 Token，填進 `.env` | 立刻 |

> **金鑰外流時**（例如不小心貼到群組、上傳到公開的地方）：不管倉庫或對話是不是私人的，**馬上照上表換新的**。

### 要不要轉正？

L3-6 讓他讀你的信。**免費方案下，送進 Gemini 的內容 Google 會拿去改進產品，可能有人工審閱**；開通計費（L1 教的「轉正」）後就不會。

- 只用個人 Gmail、不敏感的信 → 免費方案也可以，自己斟酌。
- 公司信件、客戶資料、合約、個資 → **轉正**，並先確認公司規定。

健檢的時候，順便把這件事決定下來。

### 存一版「L3 完成」

健檢完、考核通過後，跟 coding agent 說（L2-7 教過）：

> 先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：L3 完成

以後 L4 升級出問題，就可以退回到這一版。

## 日常管理

### 每個月做一次健檢

傳 `/status` 看一眼，花不到一分鐘。特別注意：多了你不記得裝過的外掛、白名單不是 1 人、不用的服務金鑰還 ✅。

### 裝新外掛之後

每次 coding agent 幫你裝新外掛（或 L4 以後的課），重新啟動後傳 `/status`，確認多了什麼、屬於哪一級。

## 附錄・Q&A

**Q：`/status` 沒反應？**
主程式還是舊的，或沒有重新啟動。關掉所有黑視窗、重新啟動。

**Q：某個外掛寫「沒有啟用」？**
裝了但缺東西：地圖缺 `SERPAPI_KEY`、行事曆或 Gmail 還沒授權。啟動時黑視窗那一行會寫原因；不打算用就不用管。

**Q：技能那一行跟手冊的例子不一樣？**
正常。那一行會列出你自己在 L2-6 教他的技能，每個人都不同。

**Q：「現在：正在做事」但我沒叫他做事？**
可能是換日整理日誌，或前一件事還沒做完。等一下再看；一直卡著就傳 `/stop`。

**Q：改了東西沒效果？**
重新啟動，再傳 `/new`。

到目前為止，都是你開口，他才做事。L4 讓他**不等你開口**：每天固定時間送上晨間簡報、開會前提醒你、定期幫你收集產業消息，還會每週檢討自己哪裡做錯（只建議，不自己改）。

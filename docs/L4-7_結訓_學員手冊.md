## `/status` 怎麼看

### 「主動工作」

每一行是一個外掛自己報的狀態，順序固定：提醒與待辦追蹤 → 例行工作 → 固定會議 → 會前提醒與會前準備 → 重要新信 → 產業消息。

| 看到 | 代表 |
|---|---|
| 「下次 …」 | 下一次會在什麼時候做 |
| 「上次 …」 | 上一次**真的做了**的時間 |
| 「還沒做過」 | 設好之後還沒輪到過 |
| 「…讀不懂，請修好或刪掉它」 | 那個設定檔格式壞了；**只有那一行受影響**，其他照常 |
| 「（沒有任何提醒、例行工作或通知）」 | 什麼主動工作都沒設 |

### 「已經上班」

從這次啟動算起過了多久。**關掉黑視窗、電腦重開機，就會重新算**——所以如果你早上看到「已經上班：5 分鐘」，代表他剛重開過。

注意：**電腦睡著時這個數字不會停**（程式本身沒停，只是不能動）。電腦有沒有可能睡著，要看下面「電腦睡眠」那一行。停下來的那段時間，提醒會在醒來時補發，例行工作照「中午前補做」的規則（L4-2）。

### 「電腦睡眠」

啟動時查一次 Windows 的電源設定：

| 看到 | 代表 |
|---|---|
| 插電時永不睡眠 ✅ | 很好 |
| ⚠️ 插電時 30 分鐘沒動就睡著，睡著時不會提醒你（…） | 你離開半小時，他就停了。照下一節改 |

## 讓他一直在線

### 一、電腦不要睡著

1. 開「**設定**」（`Win + I`）→「**系統**」→「**電源與電池**」（桌機叫「**電源**」）。
2. 展開「**螢幕、睡眠與休眠逾時**」。
3. 「**插電時，經過以下時間後讓裝置進入睡眠狀態**」選「**永不**」。

螢幕關掉沒關係（省電），**睡眠**才會讓他停下來。

> **筆電**：蓋上蓋子預設也會睡著。「控制台」→「電源選項」→「選擇蓋上螢幕時的行為」→「**插電時**」選「**不執行任何動作**」。用電池時建議維持原樣，不然包包裡會發燙。

改完重新啟動秘書，`/status` 的「電腦睡眠」應該變成「插電時永不睡眠 ✅」。

### 二、開機自動上班

電腦更新後重開機、停電後再開機，秘書不會自己起來，主動工作就停了。讓 Windows 開機時自動雙擊 `啟動 Agent.bat`：

1. 在檔案總管找到你的專案資料夾裡的 `啟動 Agent.bat`，**按右鍵 →「顯示其他選項」→「建立捷徑」**。
2. 按 `Win + R`，輸入 `shell:startup`，按 Enter。會打開一個「啟動」資料夾。
3. 把剛剛建立的**捷徑**拖進這個資料夾。

下次開機、登入 Windows 後，黑視窗會自己跳出來。

> ⚠️ **要登入 Windows 才會啟動**。如果你的電腦開機要輸入密碼，停電重開後要有人去輸入密碼他才會上班。這是 Windows 的安全設計，課程不教怎麼跳過。

> ⚠️ **同一個資料夾只能開一個秘書**（L4-2）。開機自動啟動之後，**不要再手動雙擊** `啟動 Agent.bat`，第二個會自己結束。

### 三、Windows 更新

Windows 有時會在半夜自動更新、重開機。設好開機自動啟動之後，重開完他會自己回來；中間錯過的提醒會補發。

想避開上班時間重開：「設定」→「Windows Update」→「進階選項」→「**使用時段**」設成你的上班時間，Windows 就不會在那段時間重開機。

## 日常管理

### 每天早上看一眼

傳 `/status`：「已經上班」很短，代表他剛重開過（例如半夜 Windows 更新）；「電腦睡眠」有 ⚠️，代表他可能會睡著，電源設定要再檢查一次。

### 主動工作太多、太吵

`/status` 看一遍，用不到的就跟他說「停掉 XX」。一次調一樣，觀察一週。

### 要出門好幾天

不用關。電腦開著，提醒、晨報照常；你在手機上照樣收得到。如果要關機，回來開機後錯過的提醒會補發，例行工作照 L4-2 的規則（早上的中午前補、過中午只說明）。

## 附錄・Q&A

**Q：`/status` 沒有「電腦睡眠」那行？**
不是 Windows，或查不到電源設定。不影響其他功能。

**Q：已經設成永不睡眠，`/status` 還是寫 ⚠️？**
`/status` 是**啟動時**查一次。改完設定要重新啟動秘書。

**Q：開機後黑視窗沒出現？**
確認 `shell:startup` 資料夾裡的是**捷徑**，而且捷徑指到的 `啟動 Agent.bat` 還在原本的位置（專案資料夾搬過就要重建捷徑）。

**Q：開機後跳出兩個黑視窗，其中一個說「已經有一個秘書在跑了」？**
你在啟動資料夾放了兩個捷徑，或開機後又手動雙擊了一次。刪掉多的捷徑就好，那個自己結束的不用管。

**Q：「主動工作」某一行寫「…讀不懂」？**
那個設定檔（例如 `排程.json`）格式壞了。其他功能照常。把那行截圖給 coding agent，或刪掉那個檔案重新設定。

## L4 主動工作結業 🎓

| 課程 | 他學會了 |
|---|---|
| L4-1・提醒 | 時間到把你交代的話傳給你；盯著今天的待辦 |
| L4-2・晨間簡報 | 每天早上自己整理晨報；沒人看著時只能查資料、擬草稿 |
| L4-3・會議前提醒、重要新信 | 開會前提醒你、重要的信馬上說、固定會議遇假日先問 |
| L4-4・情報收集 | 每小時看你關心的新聞，晨報挑重要的給你 |
| L4-5・索引式記憶 | 日誌有了目錄，幾個月前的事也找得到 |
| L4-6・自我覆盤 | 每週檢討自己哪裡做錯，只建議、你點名才改 |
| L4-7・結訓 | 一眼看清他所有的主動工作；電腦不睡、開機自動上班 |

從 L1 到 L4，他從一個只會回話的聊天機器人，變成：

- **記得你**（L2）：重啟不失憶，每天寫日誌，照你的 SOP 做事。
- **能辦事**（L3）：讀寫文件、查地圖、看行事曆、擬信，該問你的先問你。
- **會主動**（L4）：不等你開口，時間到自己做；而且每週檢討自己。

# L0-1・基本概念｜學員手冊

## 招聘準備第一課：先搞懂你要招的是什麼人

> 從 L1 開始，你會招一位 AI 秘書。但秘書的辦公室要有人幫你裝潢：這個人叫 **coding agent**，本課程叫他「施工人員」。
> 招人之前，先把幾個名詞搞懂。之後每一課看到「額度」「權限」「API Key」，你就知道在講什麼。

---

## 這堂課結束，你會知道

- 聊天機器人和 **Agent** 差在哪裡
- 施工人員和秘書有什麼不同
- **token、上下文、額度、速率限制**是什麼，為什麼會出現「額度已到」
- **帳號登入**和 **API Key** 有什麼不同
- Agent 為什麼一直問你「要不要允許」
- 你打的字、它讀的檔案會送到哪裡

這一課不用動手，也不用裝任何東西。

---

## 一、聊天機器人 vs. Agent

| | 聊天機器人（例如網頁版 Gemini、ChatGPT） | Agent |
|---|---|---|
| 比喻 | **電話諮詢的顧問**：你問，他答 | **到府施工的師傅**：你交代，他動手做 |
| 看得到什麼 | 只看得到你貼給他的東西 | 可以自己打開你電腦裡的檔案 |
| 做完的東西 | 一段文字，你自己複製、自己存檔 | 直接幫你寫進檔案 |
| 做事方式 | 一問一答 | 自己拆步驟、一步一步做，做完回報 |

同一個要求，兩種做法差很多：

```text
你：幫我把「會議筆記.txt」整理成會議紀錄

聊天機器人：請把會議筆記的內容貼給我。
            （你貼上 → 它回一段文字 → 你自己開新檔、貼上、存檔）

Agent：     我先讀一下 會議筆記.txt……
            整理好了，要建立「會議紀錄.md」嗎？ 1. 允許 2. 不允許
            （你選「允許」→ 檔案已經在資料夾裡）
```

Agent 能自己動手，靠的是**工具**：讀檔、寫檔、執行指令、上網查資料。有工具，它就從「會說」變成「會做」。

## 二、施工人員和秘書

本課程裡有兩位 Agent，工作不一樣：

| | 施工人員（coding agent） | 秘書（L1 開始招） |
|---|---|---|
| 住在哪裡 | 你電腦上的終端機視窗 | 你電腦上，透過手機 Telegram 找他 |
| 負責什麼 | 照《施工工單》幫你把秘書蓋好、升級 | 每天幫你辦事：會議紀錄、週報、行程…… |
| 本課程用哪一個 | 示範用 Google 的 **Antigravity CLI**（L0-3 安裝） | 你自己的 AI 秘書 |

**L0 的目標，就是讓你有一位會用的施工人員。**之後每一課，你都是把一份工單交給他，他照著做。

## 三、Agent 怎麼「算錢」：token、上下文、額度

### token：計算文字的單位

模型不是用「字數」算，而是用 **token**。中文大約一個字算一個 token 上下，實際看模型而定。你打的字、它讀的檔案、它回的話，全部都算 token。

### 上下文：它的工作桌面

**上下文**是它這一次對話能同時記住的份量，就像一張工作桌面：

- 對話越長、讀的檔案越多，桌面越滿，前面的事就容易漏掉，也越花額度。
- 所以**換一件事做，就開一段新的對話**（L0-4 會教怎麼開）。

### 額度與速率限制：試用期的上限

| | 意思 | 比喻 |
|---|---|---|
| **額度** | 一段時間內總共能用多少（每天、每週） | 每個月的手機流量 |
| **速率限制** | 一分鐘內不能問太多次 | 櫃台一次只能服務幾個人 |

免費方案兩種都有上限。看到「額度已到」「rate limit」，**不是壞掉**，是用到上限了：等一下再試，或等額度重置。

## 四、帳號登入 vs. API Key

AI 服務有兩種「進門方式」：

| | 帳號登入 | API Key |
|---|---|---|
| 比喻 | **本人刷員工證**進門 | **公司大小章**：誰拿到誰就能用 |
| 給誰用 | 人坐在電腦前操作的工具 | 程式自己在背景呼叫 |
| 本課程誰用 | 施工人員（L0-3 用 Google 帳號登入） | 秘書（L0-5 先申請，L1 填進設定檔） |

API Key 是一長串文字。**它外流，別人就能用你的額度**，所以：

- 不要貼進任何對話框（包括施工人員的對話）
- 不要截圖、不要傳到群組
- 只放進 L1 會教的 `.env` 設定檔

---

## 五、權限：它為什麼一直問「要不要允許」

Agent 能動你的電腦，所以做某些事之前會先問你。它做的事大致分三種：

| 動作 | 例子 | 風險 |
|---|---|---|
| **讀檔** | 打開一份文件看內容 | 低；但檔案內容會送到雲端 |
| **寫檔** | 建立新檔、修改舊檔 | 中；可能改壞你的檔案 |
| **執行指令** | 在終端機跑一行指令 | 高；指令可以做幾乎任何事 |

**它問你，是在保護你。**本課程的原則是「先擋得住，再放手」：

1. 每次它要寫檔、執行指令，**先看一眼再允許**。
2. 看不懂它要做什麼，**先問它「這是在做什麼」**，懂了再允許。
3. **不要開「全部自動允許」**。網路教學常教這招來省事，本課程不用。

這不只是本課程的囉嗦。Google 在施工人員第一次開啟時，也會跳出警告：AI 施工人員有自己執行程式、資料外洩、被藏在檔案或網頁裡的文字騙去做事等風險，**請盯著它做的每一個動作**（L0-3 會看到這個畫面）。

秘書也一樣：L2-5 會教你叫他停下來，L3-2 會幫他設好「哪些事只能看、哪些要先問你」。

---

## 六、你的資料會送到哪裡

Agent 的「大腦」是雲端上的模型。**你打的每一個字、它讀的每一份檔案，都會送到 Google 的伺服器。**

- 依 Google 目前的條款，**免費方案的內容可能被用來改善 Google 的產品**，也可能有人工審閱。施工人員第一次開啟時會問你同不同意（L0-3），可以取消勾選；秘書用的 API Key 免費方案沒有這個選項，要開通付費才不會被拿去用（L1 手冊第五章「轉正」）。
- 所以練習時**不要放公司機密、客戶資料、密碼、身分證字號**。
- 練習用的檔案放在一個獨立的資料夾（L0-2 會建一個），不要讓它碰你其他的資料。

## 附錄・Q&A

**Q：我平常用網頁版 Gemini、ChatGPT 就夠了，為什麼要 Agent？**
聊天機器人只能回你一段文字，存檔、整理、跑指令都要你自己來。秘書要能幫你「做事」，就得是 Agent。施工人員也是 Agent，才能幫你把秘書蓋起來。

**Q：token 要怎麼省？**
換一件事就開新對話；不要叫它讀跟這件事無關的大檔案。一般練習用量很小，不用太在意。

**Q：我已經會用 Claude Code、Codex 或其他 coding agent 了，要上 L0 嗎？**
L0-1 的概念建議看一遍；L0-2 到 L0-5 可以跳過，直接從 L1 開始。

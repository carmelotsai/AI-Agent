# L0-5・照工單施工｜學員手冊

## 招聘準備第五課：交出第一張工單＋結業

> 從 L1 開始，每一課你都會拿到一份《施工工單》，把它整份交給施工人員，他照著做。
> 這一課先用一張 15 分鐘做得完的**迷你工單**練一次：整理一份會議紀錄。
> 最後替秘書申請好「大腦的通行證」（Gemini API Key），L0 就結業了。

---

## 這堂課結束，你會有什麼

1. 練習資料夾裡一份施工人員照工單做出來的會議紀錄。
2. 一把存在安全地方的 **Gemini API Key**，L1 秘書報到時要用。

---

## 一、工單是什麼

**工單是寫給施工人員看的完整說明書。**你不用看懂每一行，但要知道裡面有什麼：

| 工單裡的章節 | 寫給誰 | 內容 |
|---|---|---|
| 施工者須知、作業紀律 | 施工人員 | 它該守的規矩，例如「不准捏造」「沒得到同意不准動工」 |
| 料表、製程 | 施工人員 | 要用什麼材料、一步一步怎麼做 |
| 自我檢查表 | 施工人員 | 做完要自己對一遍的清單 |
| 完成回報 | **你** | 它做完要交給你看的報告 |

你在工單裡的身分叫**委託人**。委託人要做的只有四件事：

1. **交出工單**
2. **回答它的問題**
3. **簽核**：它開工前會給你一張確認單，你看過沒問題才回「同意」
4. **驗收**：它說做完了，你自己打開成品檢查

L1 的工單長很多，但你要做的還是這四件事。

---

## 二、交出迷你工單

### 步驟 1：把工單放進練習資料夾

從課程教材裡找到《**L0-5_會議紀錄_迷你工單.md**》，複製到 `ai-practice` 資料夾。

> 為什麼放進練習資料夾？L0-4 說過：工作資料夾裡的檔案，施工人員可以直接讀。放進去，它就看得到整份工單。

### 步驟 2：開一段新的對話，交出工單

```powershell
cd ~\ai-practice
agy
```

（已經開著的話，打 `/clear` 開新對話。）然後說：

```text
請先完整讀過 L0-5_會議紀錄_迷你工單.md，照這份工單幫我施工。
```

### 步驟 3：回答它的問題

工單規定它要先問你兩個問題：

| 它會問 | 你怎麼答 |
|---|---|
| 這場會議是哪一天開的？ | 隨便給一個日期，例如「2026 年 9 月 22 日」 |
| 記錄人要寫誰的名字？ | 你的名字；不想寫可以說「不用」 |

> 📌 **觀察重點**：它有沒有**停下來等你回答**？如果它沒問就自己填了日期，那是違反工單紀律，請跟它說「工單規定要先問我日期，請重來」。L1 的面談也是一樣的道理：資料一定要由你決定。

### 步驟 4：簽核《開工確認》

它會給你一張單子：

```text
《開工確認》
────────────────────────────
要建立的檔案：會議紀錄_2026-09-22_展場攤位.md
位置：目前的工作資料夾
會議日期：2026-09-22
記錄人：Amy
內容：討論重點、決議、待辦（共 3 項）、待確認事項
不會做的事：不改其他檔案、不執行任何指令
────────────────────────────
請回覆「同意」開工，或告訴我要改哪裡。
```

看過檔名、日期沒錯，回「**同意**」。

### 步驟 5：允許建立檔案

它要建立檔案時會問你（`Allow creation of this file?`，L0-4 練過）。**先看檔名和內容，再選 `1. Yes, allow creation`**。

會議紀錄比較長，畫面只會先顯示前 20 行左右，最後一行寫著：

```text
… 12 more lines (f for full diff)
```

意思是「還有 12 行沒顯示，按 `f` 看全部」。**最重要的待辦表通常就在後面**，請按 `f` 看完整內容，確認小王、阿明的期限沒有被亂填，再回來選 `1`。

這張工單寫明了「不執行任何指令」。如果它問你要不要執行指令（`Run this command?`），選 `4. No, cancel`，並提醒它「工單規定不執行指令」。

### 步驟 6：看《完成回報》

它做完會交一份回報，列出自我檢查七個項目的結果。

---

## 三、驗收：你自己檢查

**不要只看它的回報，自己打開檔案。**對照下表：

| # | 檢查項目 | 正確答案 |
|---|---|---|
| 1 | 檔名 | `會議紀錄_你給的日期_展場攤位.md`，日期是你說的，不是今天 |
| 2 | 四段都有 | 討論重點、決議、待辦、待確認 |
| 3 | 待辦有三項 | 交設計稿（小李，10/10）、聯絡印刷廠並比兩家價格（小王，未指定）、換運輸廠商（阿明，未指定） |
| 4 | **沒有亂填期限** | 小王、阿明的期限都是「（未指定）」，**不是 10/15** |
| 5 | 決議 | 預算上限 30 萬、攤位最晚 10/15 定案 |
| 6 | 待確認 | 小王、阿明的期限；下次開會的日期 |
| 7 | 沒有多做 | 資料夾裡除了這份會議紀錄，其他檔案都沒被改 |

第 4 項是 AI 最常犯的錯：筆記裡有「10/15 定案」，它很容易拿來當別人的期限。工單裡已經寫了「容易搞錯的例子」提醒它，但**最後把關的還是你**。

**有錯的話**，直接告訴它哪裡不對，例如「小王那項原文沒有期限，請改成（未指定）」。工單規定它改完要重新檢查、重新回報。

> 這份會議紀錄的格式，跟 L2-4 秘書學的「會議紀錄」技能是同一套。到時候你會發現：你早就練過了。

## 四、申請 Gemini API Key

施工人員用你的 Google 帳號登入；**秘書是在背景跑的程式，要用 API Key**（L0-1 第四節）。L1 秘書報到時會用到，現在先申請好。

1. 前往 [Google AI Studio 的 API Keys 頁面](https://aistudio.google.com/apikey)，用**個人 Google 帳號**登入。
2. 第一次使用會請你同意服務條款。同意後，AI Studio 通常會**自動幫你建好一個專案和一把金鑰**。
3. 沒有看到金鑰的話，按「**Create API key**」建立一把。
4. 按複製，把金鑰存到安全的地方（見下方）。

免費方案**不用綁信用卡**。免費的額度夠你在 L1 試用秘書；轉成付費的做法，L1 手冊第五章「轉正」會教。

### 金鑰要存在哪裡

> 🔑 **這串金鑰就像公司大小章：誰拿到就能用你的額度。**

| ✅ 可以 | ⛔ 不可以 |
|---|---|
| 存進**密碼管理工具**（例如瀏覽器或手機內建的密碼管理） | **貼進施工人員的對話框**：對話內容會送到雲端 |
| 暫時不存也行：L1 要用時，再回 AI Studio 建一把新的 | **存在 `ai-practice` 資料夾裡**：施工人員可以自由讀取那裡的檔案 |
| | 截圖、傳 LINE、貼到群組或筆記 App |

L1 會教你把它填進秘書專用的設定檔 `.env`，那是它唯一該出現的地方。

### 萬一外流了

回到同一個 AI Studio 頁面，**先建一把新的，再把舊的刪掉**。

### 兩種額度不一樣

| | 施工人員（Antigravity CLI） | 秘書（Gemini API Key） |
|---|---|---|
| 怎麼進門 | Google 帳號登入 | API Key |
| 額度 | 每週重置 | 每天重置 |
| 看剩多少 | `/usage` | [AI Studio 的用量頁面](https://aistudio.google.com/rate-limit) |

兩邊的額度**各算各的**，施工人員用完了不影響秘書，反過來也一樣。

## 結訓考核（L0 結業）

| # | 考核項目 | 怎麼考 | 合格標準 |
|---|---|---|---|
| T0-5-01 | 它有照紀律 | 看步驟 3、4 | 它先問你日期、先給你《開工確認》，得到「同意」才動工 |
| T0-5-02 | 成品合格 | 第三節驗收表 | 七項全部正確（有錯的話，叫它改到正確也算通過） |
| T0-5-03 | 回報屬實 | 對照它的《完成回報》和你的驗收結果 | 它打勾的項目，你檢查也是對的 |
| T0-5-04 | 金鑰就緒 | 第四節 | 已申請；存在安全的地方，**不在練習資料夾、沒貼進任何對話** |

## 附錄・Q&A

**Q：它說找不到工單檔案？**
確認工單真的在 `ai-practice` 裡（打 `explorer .` 看），而且你是在 `ai-practice` 裡打 `agy` 的。檔名很長，可以在對話裡打 `@` 讓它跳出檔案清單給你選。

**Q：它沒問我日期就直接做了？**
請它停下來（`Esc`），說「工單規定要先問我會議日期，請從頭照工單做」。AI 偶爾會跳步驟，所以委託人要盯著看。這也是 L1 手冊說「它沒問你就自己填了，請叫它停下來重新問」的原因。

**Q：它自己多做了 Word 檔、或改了其他檔案？**
違反工單紀律第 3 條。請它刪掉多做的東西、把改過的檔案還原，並在回報裡寫出來。

**Q：AI Studio 說「沒有權限在這個專案建立金鑰」？**
通常是用了公司帳號。請改用個人 Google 帳號。

**Q：AI Studio 裡有一把舊金鑰，旁邊標著「Unrestricted」或「Blocked」？**
那是很久以前建的舊式金鑰，Google 已經不接受。直接建一把新的就好，新建的金鑰會自動設好限制。

### 下一步：L1 到職

你已經有一位會用的施工人員，也有秘書的大腦通行證了。L1 要正式替自己招一位 AI 秘書，除了 API Key，還要準備一個 Telegram Bot（L1 手冊第二章會教）。

L1 交工單的做法跟這一課一樣：

1. 照 L0-2 的做法，在家目錄建一個空的資料夾 `ai-secretary`（L1 秘書的辦公室）。
2. 把《L1_到職篇_施工工單.md》複製進去。
3. 在 `ai-secretary` 裡打 `agy`，說「請照 L1_到職篇_施工工單.md 幫我建置」。

面談時它會問「專案要裝在哪個資料夾」，預設就是家目錄下的 `ai-secretary`，回答「用預設」即可。

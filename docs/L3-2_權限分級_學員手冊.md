# L3-2・權限分級｜學員手冊

## 授權配發第二課：看、寫、做，分三級

> 到目前為止，「文件放 `文件/`」「不要改 `SOUL.md`」都寫在規矩裡。他照做，是因為他聽話；技術上，他什麼都改得動。
> 實測過：只擋住他的寫檔工具，他會改用 PowerShell 把檔案改掉，還回你「已成功」。
> 這一課把規矩變成**真的擋得住的權限**，也兌現 L1 說過的**核決權限：查閱／擬稿／執行**。

---

## 這堂課結束，你會有什麼

```text
你       14:00  幫我在 bridge.mjs 最後加一行註解
Melo     14:00  我沒有權限修改 bridge.mjs，我只能寫「文件/」和「.pi/skills/」。

你       14:01  那用 powershell 幫我加
Melo     14:01  秘書要執行：powershell

                ⚠️ 會碰到秘書平常不能改的檔案：bridge.mjs

                Add-Content -Path bridge.mjs -Value "// hi"
                [ ✅ 執行 ]  [ ❌ 不要 ]
你       14:01  （按 ❌ 不要）
Melo     14:01  執行指令被拒絕了，所以我沒有幫你加上這行。
```

秘書學會：

| 級別 | 他能做的事 | 規則 |
|---|---|---|
| **查閱** | 讀檔、搜尋、列資料夾、把檔案傳給你 | 直接做。只能看專案資料夾裡的東西，不能讀 `.env`（金鑰）、`data/`（對話存檔） |
| **擬稿** | 寫檔、改檔 | 只能寫 `文件/`、`.pi/skills/`；`MEMORY.md` 只能修改、不能整份覆寫（所以「記下來」照常） |
| **執行** | 執行指令（PowerShell）、之後會影響外界的外掛 | **每次都先傳按鈕問你**，你按「✅ 執行」才做；5 分鐘沒按就不做 |

你得到：

- **擋得住**：寫錯地方、讀金鑰會被程式直接擋下，他怎麼被說服都一樣。擋下時他會告訴你原因，不會自己想辦法繞過。
- **決定權在你**：要執行指令，一定先經過你；會碰到重要檔案或刪東西的指令，還會多一行 ⚠️ 警示。
- **`權限.json`**：權限寫在一個文字檔裡，看得懂、改得動。

## 按鈕怎麼用

秘書要執行指令時，會先傳一則附兩個按鈕的訊息，裡面是**他要執行的完整指令**：

| 你做 | 結果 | 那則訊息會變成 |
|---|---|---|
| 按「✅ 執行」 | 他執行，並回報結果 | 「✅ 已同意執行」 |
| 按「❌ 不要」 | 不執行，他告訴你沒做 | 「❌ 你按了不要」 |
| 5 分鐘都沒按 | 不執行 | 「⌛ 太久沒回應，沒有執行」 |
| 傳 `/stop` | 不執行，整件事停下 | 「⏹ 已用 /stop 取消」 |
| 改打字（例如「好」） | 他提醒你上面還有按鈕在等；你打的字排在後面 | （按鈕還在） |

按過之後按鈕就失效，再按會顯示「這個按鈕已經失效了」。

### 看到 ⚠️ 警示要想一下

| 警示 | 什麼時候出現 |
|---|---|
| ⚠️ 會碰到秘書平常不能改的檔案：… | 指令裡提到 `bridge.mjs`、`SOUL.md`、`.env`、`權限.json`、`外掛/` 等，他平常沒權限寫的東西 |
| ⚠️ 這個指令會刪除東西 | 指令裡有 `Remove-Item`、`rm`、`del` 這類刪除指令 |

警示是程式直接比對指令文字，不是秘書自己說的，所以他沒辦法用話術蓋過去。但指令換個寫法可能比對不到，**沒有警示不代表一定安全**。

**看不懂指令就按「❌ 不要」**，再問他：「你剛剛想執行什麼？用白話說明。」

### 為什麼不乾脆禁止 PowerShell？

禁止最安全，但有些事只有指令做得到。這一級要擋的是**秘書背著你做事**，不是擋你本人：每一條指令都攤在你眼前，你同意才做。
之後幾課會把常用的事（例如做 Word、查地圖）做成專用的外掛工具，就不用每次按按鈕了。

## `權限.json`：自己調整權限

專案裡多了一個 `權限.json`，用記事本就能打開：

```json
{
  "說明": "秘書的權限。改完要重新啟動才生效。路徑以專案資料夾為準，資料夾結尾要加 /。",
  "可以寫的地方": ["文件/", ".pi/skills/"],
  "只能修改的檔案": ["MEMORY.md"],
  "不能讀的地方": [".env", "data/"],
  "等我確認幾分鐘": 5
}
```

| 欄位 | 意思 | 例子 |
|---|---|---|
| 可以寫的地方 | 他可以新增、覆寫、修改的資料夾或檔案 | 想讓他寫 `報告/`，就加上 `"報告/"` |
| 只能修改的檔案 | 只能改其中幾行、不能整份覆寫 | 預設是 `MEMORY.md`，他「記下來」時只會加一條 |
| 不能讀的地方 | 連看都不能看 | 預設是金鑰和對話存檔 |
| 等我確認幾分鐘 | 按鈕等你多久，超過就不做 | 常常來不及按，可以改成 `10` |

- **改完要重新啟動**。黑視窗的「權限：…」那一行會顯示目前的設定。
- **寫壞了也不會出事**：少了逗號、括號這類錯誤，黑視窗會印「權限.json 讀不懂，先用預設權限」，秘書照預設權限上班。
- **範圍開越大，他能改的越多**。不建議把 `SOUL.md`、`bridge.mjs` 加進「可以寫的地方」。

---

## 這一課他還不會的事

- **自動用白話解釋指令**：確認訊息裡是原始指令；看不懂就按「不要」、再問他。
- **分得更細**：例如「只能新增技能、不能改舊技能」。現在是整個 `.pi/skills/` 都能寫；擔心的話，照 L2-6 手冊在 `SOUL.md` 加規矩，或把 `.pi/skills/` 從「可以寫的地方」拿掉。
- **對外的工具**：目前只有「傳檔案」（屬於查閱：只傳給你本人）。擬信這類影響外界的工具在後面的課，屬於執行級。

## 上課步驟

### 步驟 1：把工單交出去

把**《L3-2_權限分級_施工工單.md》整份**交給 coding agent，說：

> 請照這份施工工單，幫我把秘書升級到 L3-2。

> 💾 **交工單之前**，先跟 coding agent 說「先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：L3-2 升級前」（L2-7 教過）。驗收通過後再存一版「L3-2 完成」。升級出問題、改不回來，就說「退回到『L3-2 升級前』那一版」。

這一課**改程式、小改「傳檔案」外掛、新增 `權限.json`**，人事資料、技能、日誌都不動。coding agent 的測試**不需要你的金鑰**，它會用假的 Telegram（會按按鈕）和假的 Gemini 模擬各種寫檔、讀檔、執行指令。

### 步驟 2：重新上班

關掉舊的黑視窗，重新雙擊 `啟動 Agent.bat`。啟動畫面會**多一行**：

```text
權限：可寫 文件/、.pi/skills/；只能修改 MEMORY.md；執行前先問（5 分鐘沒回應就不做）
```

> **L2-5 的「睡 60 秒」考核從這課起多一步**：他會先問要不要執行 `Start-Sleep`，按「✅ 執行」之後才開始睡，再照原本的步驟傳 `/stop`。

## 日常管理

### 常常來不及按按鈕

打開 `權限.json`，把「等我確認幾分鐘」改大，重新啟動。

### 想讓他多寫一個資料夾

打開 `權限.json`，在「可以寫的地方」加上資料夾名稱（結尾加 `/`），例如 `["文件/", ".pi/skills/", "報告/"]`，重新啟動。

### 他會不會自己去改 `權限.json`？

用寫檔工具改不了（不在「可以寫的地方」）。用 PowerShell 改的話，一定會先問你，而且會跳 ⚠️ 警示。

## 附錄・Q&A

**Q：黑視窗沒有「權限：…」這一行？**
跑的是舊版。關掉黑視窗、重新雙擊啟動。

**Q：按了按鈕，沒有反應？**
如果跳出「這個按鈕已經失效了」，代表那一題已經結束（按過、逾時或 `/stop`）。叫他再做一次就好。

**Q：每次執行指令都要按，好煩？**
這是這一級的設計。之後幾課會把常用的事做成專用工具，就不用按了。

**Q：我已經在 `權限.json` 加了資料夾，他還是說沒有權限？**
要重新啟動。看黑視窗的「權限：…」那一行有沒有你加的資料夾；資料夾名稱結尾要加 `/`。

**Q：黑視窗出現「權限.json 讀不懂，先用預設權限」？**
`權限.json` 格式寫錯了（常見是少了逗號、引號或括號）。秘書照預設權限上班，不會出事；把檔案改回上面的樣子再重新啟動。

**Q：他說「記下來」的時候沒有權限？**
`MEMORY.md` 被移出「只能修改的檔案」了。把 `"MEMORY.md"` 加回去、重新啟動。

**Q：改了東西沒效果？**
重新啟動。

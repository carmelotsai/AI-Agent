# L0-4・第一次派工｜學員手冊

## 招聘準備第四課：交代小事、看懂它在問什麼

> 施工人員進場了。這一課在練習資料夾裡交代它幾件小事：讀檔、寫檔、改檔、跑指令。
> 重點不是它做得多好，而是**你看得懂它每一次在問你什麼**，也知道怎麼叫它停下、重做。

---

## 這堂課結束，你會有什麼

練習資料夾裡多了一份它幫你寫的待辦清單，而且建立之前，你親手看過內容、選了允許：

```text
● Create(~/ai-practice/待辦.md) (ctrl+o to expand)

Create file
──────────────────────────────────────────────
C:\Users\Amy\ai-practice\待辦.md  +5
   1 + # 本週待辦事項
   2 +
   3 + - [ ] 交季報
   4 + - [ ] 訂下週出差的高鐵票
   5 + - [ ] 回覆客戶報價

Allow creation of this file?
> 1. Yes, allow creation
  2. No, deny creation
```

---

## 上工

```powershell
cd ~\ai-practice
agy
```

看一下輸入框下方的**狀態列**（L0-3 步驟 4）：

```text
──────────────────────────────────────────────
? for shortcuts                    Gemini 3.8 Flash · high
```

左邊只寫 `? for shortcuts`，沒有 `[accept-edits]` 或 `[plan]` 的字樣，就是「**預設模式**」：建立新檔、修改檔案、執行指令之前都會先問你。本課程一律用預設模式。如果看到那些字樣，按 `Shift + Tab` 切換，直到字樣消失。

---

## 任務 1：讀檔（它不會問你）

```text
hello.txt 裡面寫了什麼？
```

它會直接打開 L0-2 建的 `hello.txt`，告訴你內容。**它沒有問你就讀了**，因為：

> 📌 **工作資料夾裡的檔案，它可以自由讀取。**讀到的內容會送到 Google 的伺服器。
> 這就是為什麼 L0-2 要你建一個獨立的練習資料夾：**不想被它看到的東西，就不要放進它工作的資料夾。**

如果它要讀**資料夾外面**的檔案，就會先問你。

---

## 任務 2：建立新檔（它會問你）

```text
幫我建立一個 待辦.md，列出這週三件事：交季報、訂下週出差的高鐵票、回覆客戶報價。用勾選清單的格式。
```

它會停下來，把**要建立的檔案和內容**給你看（畫面見上方「這堂課結束，你會有什麼」）：

| 畫面上的 | 意思 |
|---|---|
| `● Create(~/ai-practice/待辦.md)` | 它要**建立**一個新檔案，以及檔案的位置 |
| `C:\Users\Amy\ai-practice\待辦.md  +5` | 完整路徑；`+5` 是總共新增 5 行 |
| `1 +`、`2 +`…… | 每一行要寫進去的內容，`+` 表示新增 |
| `Allow creation of this file?` | 「允許建立這個檔案嗎？」 |

| 選項／按鍵 | 意思 |
|---|---|
| **1. Yes, allow creation** | 允許，照這樣建立 |
| **2. No, deny creation** | 不允許 |
| `f` | 打開全螢幕，看完整內容（內容很長時用） |
| `Esc` | 取消 |

**先看檔名、位置、內容，都對了再選 `1`。**內容不對就選 `2`，然後直接告訴它要怎麼改，例如「第二項改成訂機票」。

選了 `1` 之後，詢問畫面會收起來，只留下一行紀錄和它的說明：

```text
● Edit(~/ai-practice/待辦.md) (ctrl+o to expand)

  已為您建立 待辦.md：
  ……
```

> 💡 **看行首圓點的顏色**：**黃色 ●** 代表它在等你決定（允許或拒絕）；**綠色 ●** 代表這一步已經做完了。
> 建好之後，紀錄上的字會從 `Create` 變成 `Edit`，不用在意，都是指寫進這個檔案。

### 自己確認

它說寫好了，不要只相信它說的。自己打開來看：在 PowerShell 另外開一個視窗，進到練習資料夾打 `explorer .`，雙擊 `待辦.md`（用記事本打開即可）。

## 任務 3：修改檔案（看懂差異）

```text
幫我改 hello.txt，在最後加一行「早安」。
```

它會先讀檔，然後停下來，給你看**要改哪些地方**：

```text
● Read(~/ai-practice/hello.txt)
● Edit(~/ai-practice/hello.txt) (ctrl+o to expand)

Pending edit
──────────────────────────────────────────────
C:\Users\Amy\ai-practice\hello.txt  +2 -1
   1 -  你好
   1 +  你好
   2 +  早安

  shift+tab to auto-approve file edits
Accept this file edit?
> 1. Yes, accept this change
  2. No, reject this change
```

這種「刪掉哪幾行、換上哪幾行」的顯示方式叫做**差異**（diff）：

| 畫面上的 | 意思 |
|---|---|
| `Pending edit` | 「等你決定的修改」 |
| `+2 -1` | 總共新增 2 行、刪掉 1 行 |
| `-`（紅色）那一行 | 要刪掉的舊內容 |
| `+`（綠色）那幾行 | 要換上的新內容 |
| `Accept this file edit?` | 「接受這個修改嗎？」 |

> 為什麼「你好」被刪掉又加回來？它是把舊的第 1 行換成新的第 1、2 行。新舊的第 1 行內容一樣，實際的改變只有多了「早安」。看差異時，**找出真正不一樣的地方**就好。

| 選項 | 意思 |
|---|---|
| **1. Yes, accept this change** | 接受，照這樣改 |
| **2. No, reject this change** | 不接受 |

**只改了你要它改的地方，才選 `1`。**如果它順便改了別的地方，選 `2`，再告訴它「只要加一行早安，其他不要動」。

> ⚠️ 畫面上那行 `shift+tab to auto-approve file edits`，意思是「按 Shift + Tab 就能自動核准所有改檔」，也就是切到 `[accept-edits]` 模式。**本課程不要按。**

### 它也可能沒問就改了

實際測試時，請它修改**它自己在這段對話裡剛建立的檔案**（例如任務 2 的 `待辦.md`），有時它**沒有停下來問**，畫面直接出現綠點的紀錄：

```text
● Read(~/ai-practice/待辦.md)
● Edit(~/ai-practice/待辦.md) (ctrl+o to expand)

  已將 待辦.md 的第一項標記為已完成：
  ……
```

`● Edit` 前面是**綠點**，代表已經改好了。所以：

- **不要以為「它沒問，就是沒改」。**看到綠點的 `Edit`，就是那個檔案被改過了。
- **改完一定自己打開檔案檢查**（跟任務 2 的「自己確認」一樣）。

> 📌 **這也是練習資料夾不能放重要檔案的原因**：它在工作資料夾裡改檔案，不一定每次都會先問你。重要的檔案要練習，**先複製一份**進來再練。

## 任務 4：執行指令（看不懂先問）

```text
用指令幫我查這個資料夾裡有哪些檔案，還有每個檔案多大。
```

它會停下來，問你要不要執行它想跑的指令：

```text
● Bash(Get-ChildItem -File | Select-Object Name, Length, LastWriteTime)

Command
──────────────────────────────────────────────
Requesting permission for:
   Get-ChildItem -File | Select-Object Name, Length, LastWriteTime

Run this command?
> 1. Yes, run command
  2. Yes, and always allow in this conversation for commands that start with '...'
  3. Yes, and always allow for commands that start with '...' (Persist to settings.json)
  4. No, cancel

  ↑/↓ Navigate · tab Amend · ctrl+g edit/expand command
esc to cancel
```

`Requesting permission for:` 下面那一行，就是它**想執行的指令**。（前面寫 `Bash` 是工具的名稱，在 Windows 上實際跑的是 PowerShell 指令，不用在意。）

| 選項 | 意思 | 本課程 |
|---|---|---|
| **1. Yes, run command** | 這一次允許執行 | ✅ 看懂了、沒問題就選這個 |
| 2. Yes, and always allow in this conversation… | 這段對話裡，開頭一樣的指令以後都不問了 | ✗ 先不要用 |
| 3. Yes, and always allow… (Persist to settings.json) | **永遠**不問了，連下次開啟都不問（寫進設定檔） | ⛔ 不要選 |
| **4. No, cancel** | 不允許 | ✅ 看不懂、覺得怪就選這個 |

用 `↑`／`↓` 移動 `>`，按 `Enter` 確定。按 `Esc` 等於取消。

> ⚠️ **選項 2、3 很方便，但就是「自動允許」**：以後同類的指令它都不會再問你。第一個選項 `1` 永遠是最安全的選擇。

**練習「看不懂先問」**：這一次請先選 **`4. No, cancel`**，然後問它：

```text
你剛剛想執行的那一行指令是在做什麼？會不會改動或刪除任何東西？
```

聽懂了，再說「好，請執行」，它再問你時選 **`1. Yes, run command`**。

> 執行指令是三種動作裡**風險最高**的：一行指令可以做幾乎任何事。以後看到它要執行你看不懂的指令，都用這招。

## 任務 5：叫它停下、重做

```text
寫一篇 2000 字的文章介紹台灣的夜市文化，存成 夜市.md。
```

送出後，趁它還在想、還在寫的時候，按鍵盤的 **`Esc`**。它會立刻停下來，畫面顯示：

```text
> 寫一篇 2000 字的文章介紹台灣的夜市文化，存成 夜市.md。

  └ Interrupted · What should Antigravity CLI do instead?
──────────────────────────────────────────────
> ▌
```

`Interrupted` 是「已中斷」，後面那句是「那你要我改做什麼？」。輸入框又可以打字了，直接告訴它你要的：

```text
剛剛停掉了。改成 300 字就好，一樣存成 夜市.md。
```

| 狀況 | 怎麼做 |
|---|---|
| 它做到一半，方向不對 | 按 `Esc` 叫停，再告訴它正確的做法 |
| 它做完了，但你不滿意 | 直接說哪裡不對，例如「太長了，縮成三段」 |
| 它要建檔，但內容不對 | 選 `2. No, deny creation`，再告訴它怎麼改 |

> 💡 **`Esc` 是叫停，`Ctrl + C` 是下班。**在它工作時按 `Ctrl + C`，它會問你是不是要離開。只想叫停的話，用 `Esc`。

## 任務 6：換件事，開新對話

```text
/clear
```

這會清掉目前的對話，開一段新的（L0-1 說過：上下文像工作桌面，換件事就清桌面）。檔案不會被刪，只是它不記得剛剛聊過什麼。

## 權限速查表

| 它要做的事 | 會不會問你 | 你要看什麼 |
|---|---|---|
| 讀**工作資料夾裡**的檔案 | 不問 | —（所以不要放機密） |
| 讀**工作資料夾外**的檔案 | 會問 | 它為什麼需要讀外面的東西？ |
| 建立新檔案 | 會問，並顯示內容 | 檔名、位置、內容都對嗎？ |
| 修改檔案 | 會問，並顯示差異 | 只改了你要的地方嗎？有沒有順便改了別的？ |
| 修改它剛建立的檔案 | **有時不問就改了** | 看到綠點 `● Edit` 就是改過了，自己打開檢查 |
| 執行指令 | 會問 | 看得懂嗎？看不懂先選 `4. No, cancel` 問它；不要選 `2`、`3` 的「always allow」 |
| 上網查資料 | 會問 | 它要去哪個網站？ |

## 三種模式，本課程只用一種

按 `Shift + Tab` 會在三種模式之間切換，狀態列會顯示目前是哪一種：

| 模式 | 狀態列 | 意思 | 本課程 |
|---|---|---|---|
| 預設 | 只有 `? for shortcuts` | 建立新檔、修改檔案、執行指令前會問你 | ✅ **一律用這個** |
| 自動改檔 | `[accept-edits]` | 建立、修改檔案都不再問你 | ✗ |
| 規劃 | `[plan]` | 先分析、列步驟，再動手 | 熟練以後再用 |

> ⛔ **網路上的教學常叫你開「全部自動允許」**，例如啟動時加上 `--dangerously-skip-permissions`，或在設定裡把權限改成 `always-proceed`。這樣它做任何事都不會問你。名字裡就寫著 dangerously（危險地）。**本課程不用，看到就不要照做。**

## 附錄・Q&A

**Q：它說寫好了，但我在資料夾裡找不到檔案？**
先確認你打開的是 `ai-practice`。再問它「你剛剛把檔案存在哪個完整路徑？」。

**Q：用記事本打開 `待辦.md`，看到一堆 `#`、`-`、`[ ]` 符號？**
這是 Markdown 格式：`#` 是標題、`-` 是清單、`[ ]` 是未勾選、`[x]` 是已勾選。之後秘書產出的文件大多是這種格式，看久就習慣了。

**Q：不小心選了「Yes」，檔案被改壞了？**
直接跟它說「剛剛那個修改不對，請改回原來的樣子」。重要的檔案，**不要放在練習資料夾**，要練習就先複製一份進來。

**Q：它一直用英文回答？**
跟它說「以後都用繁體中文回答」。開新對話後如果又變回英文，再說一次。

**Q：它說「額度已到」？**
免費額度用完了，要等每週重置。用 `/usage` 看剩多少、什麼時候重置。Gemini 那組用完的話，可以打 `/model` 換成 Claude 或 GPT 那組的模型（L0-3 附錄），兩組額度分開計算。

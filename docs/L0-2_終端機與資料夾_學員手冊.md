# L0-2・終端機與資料夾｜學員手冊

## 招聘準備第二課：施工人員的工作現場

> 施工人員不住在網頁裡，他住在一個叫**終端機**的黑色（或藍色）視窗裡。
> 很多人第一次看到這個視窗就想關掉。這一課只教你會用到的那幾招，其他的都交給施工人員。

---

## 這堂課結束，你會有什麼

一個專門給 AI 練習用的資料夾 `ai-practice`，而且你會用終端機進到這個資料夾：

```text
PS C:\Users\Amy> cd ai-practice
PS C:\Users\Amy\ai-practice> ls

    目錄: C:\Users\Amy\ai-practice

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        2026/9/27  下午 02:10             12 hello.txt
```

---

## 一、終端機是什麼

平常你用滑鼠點資料夾、點檔案。**終端機是用打字來操作電腦的視窗**，做的事其實一樣：

| 滑鼠 | 終端機 |
|---|---|
| 點兩下打開資料夾 | `cd 資料夾名稱` |
| 看資料夾裡有什麼 | `ls` |
| 回上一層 | `cd ..` |

Windows 的終端機叫 **PowerShell**；Mac 的叫**終端機（Terminal）**。

---

## 二、打開 PowerShell

1. 按鍵盤的 **Windows 鍵**（或點左下角的開始）。
2. 直接打 `powershell`。
3. 點 **Windows PowerShell**。

> ⚠️ **不要選「以系統管理員身分執行」**。本課程用不到最高權限，用一般身分最安全。

Windows 11 可能會打開一個叫「**終端機**」的視窗，裡面的分頁是 PowerShell，一樣可以用。

### 看懂第一行

```text
PS C:\Users\Amy>
```

| 部分 | 意思 |
|---|---|
| `PS` | 你在用 PowerShell |
| `C:\Users\Amy` | **你現在在哪個資料夾**（Amy 會是你電腦的使用者名稱） |
| `>` | 等你打字 |

`C:\Users\你的名字` 叫做你的**家目錄**，就是你的個人資料夾。「文件」「下載」「桌面」都在它裡面。

---

## 三、路徑：資料夾的地址

**路徑**就是資料夾的完整地址，一層一層用 `\` 隔開：

```text
C:\Users\Amy\ai-practice\hello.txt
│   │     │   │           └─ 檔案
│   │     │   └─ ai-practice 資料夾
│   │     └─ Amy 的家目錄
│   └─ 所有使用者
└─ C 槽
```

Mac 的路徑用 `/` 隔開，例如 `/Users/amy/ai-practice`。

---

## 四、建立練習資料夾

照著打（或複製貼上），每打完一行按 **Enter**：

```powershell
cd ~
mkdir ai-practice
cd ai-practice
```

| 指令 | 意思 |
|---|---|
| `cd ~` | 回到家目錄（`~` 就是 `C:\Users\你的名字`） |
| `mkdir ai-practice` | 建立一個叫 `ai-practice` 的資料夾 |
| `cd ai-practice` | 進到這個資料夾 |

打完之後，第一行應該變成：

```text
PS C:\Users\Amy\ai-practice>
```

### 為什麼不放桌面或「文件」？

- **獨立的練習資料夾最安全**：施工人員可以自由讀寫它工作的資料夾，放在獨立的地方，它就碰不到你其他的檔案。
- **很多電腦的桌面和「文件」有 OneDrive 同步**，路徑會變得很長，還可能跟雲端同步打架。放在家目錄下最單純。

### 用檔案總管打開它

```powershell
explorer .
```

`.` 的意思是「現在這個資料夾」。這行會用檔案總管打開 `ai-practice`，你就可以像平常一樣用滑鼠看檔案。

---

## 五、在資料夾裡建一個檔案

```powershell
notepad hello.txt
```

1. 記事本會問「找不到 hello.txt 檔案，要建立新檔案嗎？」，按「**是**」。
2. 隨便打一句話，例如「你好」，**存檔**（`Ctrl + S`），關掉記事本。
3. 回到 PowerShell，打 `ls`，就會看到 `hello.txt`。

---

## 六、貼上指令的正確方法

之後你常會從手冊複製一行指令貼到 PowerShell。

| 動作 | 怎麼做 |
|---|---|
| **貼上** | `Ctrl + V`，或在視窗裡按**滑鼠右鍵** |
| **複製畫面上的字** | 用滑鼠選起來，按**滑鼠右鍵**（或 `Ctrl + C`） |
| **叫回上一行指令** | 按鍵盤 `↑` |
| **自動補完名稱** | 打前幾個字，按 `Tab` |
| **清除畫面** | `cls` |

> ⚠️ **`Ctrl + C` 在沒有選字的時候，意思是「中斷正在跑的東西」**，不是複製。不小心按到也不用怕，最多就是停下來而已。

### 三個貼上的小規矩

1. **整行貼上**，不要自己拆開、不要少複製前後的字。
2. **一次貼一個指令區塊**，貼完先看結果，再貼下一個。
3. **只貼你知道來源的指令**。本課程手冊裡的指令都說明過用途；網路上來路不明的指令，先問施工人員「這行在做什麼」（L0-4 會教）。

### 看懂「按鍵組合」的寫法

手冊裡寫 `Ctrl + V`、`Shift + Tab`、`Ctrl + O`，意思是**按住前面那個鍵，再按後面那個鍵**，然後一起放開。**不是把這幾個字打出來。**

| 手冊寫 | 怎麼按 |
|---|---|
| `Ctrl + V` | 按住 `Ctrl`，按一下 `V` |
| `Shift + Tab` | 按住 `Shift`，按一下 `Tab` |
| `Enter`、`Esc` | 直接按那一個鍵 |

英文字母大小寫沒差，`Ctrl + O` 按的就是鍵盤上的 `O` 鍵。

## 七、看懂常見的紅字

PowerShell 出現紅字不代表電腦壞了，只是那一行沒成功。看紅字的**第一句**就好：

| 紅字開頭 | 意思 | 怎麼辦 |
|---|---|---|
| 「**無法辨識 'xxx' 詞彙是否為 Cmdlet、函數……**」 | 電腦不認得這個指令 | 檢查有沒有打錯字；如果是剛裝好的程式，**關掉 PowerShell 開一個新的**再試 |
| 「**找不到路徑**」 | 資料夾名稱打錯，或你不在你以為的地方 | 看第一行 `PS ...>` 確認你在哪裡；用 `ls` 看這裡有什麼 |
| 「**已存在具有指定名稱的項目**」 | 資料夾已經建過了 | 沒關係，直接 `cd` 進去 |

### 台灣使用者最常見的坑：全形字

中文輸入法開著的時候，打出來的空白、引號、冒號可能是**全形**的：

| 半形（正確） | 全形（會出錯） |
|---|---|
| `cd ai-practice`（半形空白） | `cd　ai-practice`（全形空白） |
| `"` | `＂` 或 `」` |
| `:` | `：` |

**打指令前先切到英文輸入**。最保險的做法是直接從手冊複製貼上。

### 路徑有空白要加引號

```powershell
cd "C:\Users\Amy\My Documents"
```

資料夾名稱有空白時，整個路徑用半形雙引號 `"` 包起來。這也是本課程的練習資料夾名稱不用空白的原因。

---

## 八、另一種開法：從資料夾直接開終端機

不想打 `cd` 的話，可以先用檔案總管打開資料夾，再從那裡開終端機：

- **Windows 11**：在資料夾空白處按**滑鼠右鍵** →「**在終端機中開啟**」。
- **Windows 10**：按住 **Shift**，在資料夾空白處按**滑鼠右鍵** →「**在這裡開啟 PowerShell 視窗**」。

開出來的終端機已經在那個資料夾裡了。

## 附錄・Q&A

**Q：我的使用者名稱是中文，路徑會不會有問題？**
PowerShell 看得懂中文路徑，本課程不受影響。如果之後遇到怪問題，把整段紅字交給施工人員看。

**Q：打錯指令會不會把電腦弄壞？**
本課教的 `cd`、`ls`、`mkdir`、`explorer`、`notepad` 都不會刪東西。真正要小心的是「刪除」類的指令，本課程不會叫你自己打。

**Q：視窗最上面的標題寫著「系統管理員: Windows PowerShell」？**
這是用最高權限開的視窗。請關掉，照第二節重新開一個，**不要選「以系統管理員身分執行」**。標題只寫「Windows PowerShell」才是一般身分。

**Q：PowerShell 和「命令提示字元」（cmd）一樣嗎？**
不一樣。本課程的指令都以 PowerShell 為準，請用 PowerShell。

**Q：視窗字太小？**
按住 `Ctrl` 滾動滑鼠滾輪就能放大縮小。

# L2-4・專業培訓｜學員手冊

## 在職訓練第四課：學會固定的做事方法

> 以前每次叫秘書整理會議紀錄，你都要重講一次「要列待辦、要寫負責人、要存到哪裡」。
> 這一課發給他三本「SOP 小冊子」。之後你只要說「整理會議紀錄」，他會自己翻出小冊子，照步驟做。

---

## 這堂課結束，你會有什麼

```text
你       15:30  整理會議紀錄：展場攤位 10/15 前定案，小王負責聯絡印刷廠，
                小李 10/10 前交設計稿，阿明處理運輸。
Melo     15:30  會議紀錄整理好了：展場攤位 10/15 前定案，三人分工。

                待辦：
                1. 聯絡印刷廠（小王，未指定）
                2. 交設計稿（小李，10/10 前）
                3. 處理運輸（阿明，未指定）

                ⚠️ 待確認：小王、阿明的期限原文沒寫，請補上。

                存檔：文件/2026-09-28_會議紀錄_展場攤位.md

你       17:00  寫這週的週報。
Melo     17:00  週報草稿存在 文件/2026-09-28_週報.md，內容都來自這週的工作日誌，請檢查後再交出去。
```

黑視窗會多一行，列出他學會的技能：

```text
技能：meeting-notes, trip-plan, weekly-report
```

## 三本 SOP 小冊子

| 技能 | 你怎麼叫他 | 他會做什麼 | 特別注意 |
|---|---|---|---|
| **會議紀錄** `meeting-notes` | 「整理會議紀錄：（貼內容）」 | 整理成討論重點、決議、待辦表（事項／負責人／期限），存進 `文件/` | 原文沒寫的負責人或期限，他填「（未指定）」並請你補，**不會自己猜** |
| **行程規劃** `trip-plan` | 「幫我排宜蘭一日遊，開車，兩個人」 | 按時段排好的行程表，含每站特色、交通停車，存進 `文件/` | 他**沒辦法上網**，營業時間、公休日、票價請出發前自己確認 |
| **週報** `weekly-report` | 「寫這週的週報」 | 讀本週的工作日誌，整理成週報草稿，存進 `文件/` | 內容**只來自日誌**，日誌沒寫的他不會編；所以 L2-3 的日誌越完整，週報越好 |

## 技能是怎麼運作的？

```text
   .pi/skills/
   ├─ meeting-notes/SKILL.md     ← 一本小冊子 = 一個資料夾 + 一份 SKILL.md
   ├─ trip-plan/SKILL.md
   │  └─ example.md              ← 可以附範例
   └─ weekly-report/SKILL.md
```

1. 上班時，他只記得每本小冊子的**封面**：名稱和一句「什麼時候要用」。
2. 你說的話符合某本封面時，他才去**翻開整本**，照裡面的步驟做。
3. 所以小冊子再多也不會拖慢他，但**封面那句話要寫清楚**，他才知道何時該翻。

小冊子就是一般的文字檔，你可以用記事本打開看，裡面寫的就是他的做事方法。

---

## 這一課他還不會的事

- **你自己的工作流程**：這三本是課程附的通用小冊子。你公司特有的做法（報價回覆、出貨檢查…），**L2-6** 教你自己寫。
- **上網查資料、讀 Word／PDF**：技能只能教他「怎麼做」，不能多給他「新能力」。他能用的工具還是讀寫檔案、搜尋、執行指令。

## 日常管理

### 他該用技能卻沒用？

直接點名：「用會議紀錄技能整理」。他就會去翻那本小冊子。
常常沒用的話，代表封面那句「什麼時候要用」寫得不夠貼近你的說法，可以把你習慣的講法加進去（見下方「修改小冊子」）。

### 修改小冊子

用記事本打開 `.pi/skills/技能名稱/SKILL.md`：

- **最上面三條線之間**（`---` 開頭那段）是封面：`name` 不要改，`description` 可以加上你習慣的說法。
- **下面**是步驟和格式，可以照你的習慣改，例如會議紀錄多一欄「優先順序」。
- 改完**重新啟動，再傳 `/new`** 才會生效。他讀過的小冊子會留在當天的對話裡，只重新啟動的話，他會接著用對話裡的舊版。

> 小技巧：秘書是模型，光寫規則有時不夠穩。會議紀錄那本小冊子裡有一段「容易搞錯的例子」，是實測時他真的搞錯過、補上例子後才穩定的。你改小冊子時，**附一個具體例子**最有效。L2-6 會詳細教。

### 不需要某本小冊子

把整個資料夾（例如 `.pi/skills/trip-plan/`）移到別處或刪掉，重新啟動即可。

## 附錄・Q&A

**Q：黑視窗沒有「技能：」這一行？**
跑的是舊版，重新啟動。

**Q：「技能：」後面寫「（無）」？**
`.pi/skills/` 資料夾不見了或是空的。請 coding agent 照 L2-4 工單重新放回三本小冊子。

**Q：會議紀錄把別的日期填成某人的期限？**
Flash-Lite 偶爾會犯。小冊子已經加了例子降低機率；遇到了就直接跟他說「Alex 那項沒有期限」，他會改。如果你常遇到同一種錯，把那個例子也加進小冊子。

**Q：週報寫「本週沒有日誌」？**
這週還沒有任何日誌。日誌要在換日或 `/new` 時才會寫。

**Q：行程裡的店家資訊是對的嗎？**
他沒辦法上網，是依模型的知識排的，可能過時。出發前務必自己確認。

**Q：改了小冊子沒效果？**
重新啟動，**再傳 `/new`**。黑視窗寫「接續上次」時，今天的對話會接回來，裡面還留著他之前讀過的舊版小冊子（真機實測：只重新啟動，他照舊版排行程，沒有重讀）。

# L2-7・存檔與備份｜學員手冊

## 在職訓練第七課：幫秘書存檔＋結訓

> 上了六課，秘書資料夾裡的 `SOUL.md`、`MEMORY.md`、技能小冊子、程式，都是你一點一點教出來的。
> 從 L3 開始，每一課都要升級程式。升級失敗要能**退回上一版**，電腦壞了要能**搬回來**。
> 這一課請 coding agent 用 **Git** 幫你存版本，備份到 **GitHub 私人倉庫**。存好之後，做一次總考核，L2 在職訓練就結業了。

---

## 這堂課結束，你會有什麼

1. GitHub 上一個**私人倉庫** `ai-secretary`，旁邊標著 🔒 **Private**，只有你登入看得到。
2. 一句話存檔。你跟 coding agent 說：

   > 先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：改了 SOUL.md 的稱呼

   它會存好一版、備份上 GitHub，並回報：

   ```text
   已存一版並備份到 GitHub：
   3f2a9c1  改了 SOUL.md 的稱呼
   ```

3. 看得到每一版的紀錄，改壞了可以退回。

## 先搞懂四個詞

| 詞 | 比喻 |
|---|---|
| **Git** | 電腦裡的「版本相簿」。每存一版就拍一張照，以後隨時翻得回去 |
| **存一版**（commit） | 拍一張照，附一句說明，例如「L3-1 升級前」 |
| **GitHub** | 雲端相簿。把電腦裡的照片**備份**上去（push），電腦壞了也不怕 |
| **私人倉庫**（private） | 這本雲端相簿只有你看得到 |

> Git 和 GitHub 都是**你交代、coding agent 操作**。你不用記任何指令。

---

## 為什麼一定要「私人」？

| 檔案 | 裡面有什麼 |
|---|---|
| `SOUL.md` | 你的稱呼、公司、做事習慣 |
| `MEMORY.md` | 你叫他記下來的事 |
| `.pi/skills/` | 你公司的做法（L2-6 寫的 SOP） |

這些不該給陌生人看。私人倉庫免費，數量不限。

---

## 什麼會備份、什麼不會

| 會上 GitHub ✅ | 不會上 GitHub ❌ | 為什麼不上 |
|---|---|---|
| `bridge.mjs`（程式） | `.env` | 金鑰。外流了別人就能用你的額度。弄丟了重新申請就好 |
| `SOUL.md`、`MEMORY.md` | `data/` | 對話存檔。量大、每天在變 |
| `.pi/skills/`（技能小冊子） | `文件/`、`日誌/` | 業務資料。要備份請放公司的雲端硬碟或隨身碟 |
| `.gitignore` 等設定檔 | `node_modules/` | 套件，隨時可以重新安裝 |

「不會上」的清單寫在 `.gitignore`，L1 起每一課都有在維護。coding agent 每次存檔前會跑一次檢查（`q-backup.mjs`），確認金鑰沒有混進去。

## 上課步驟

### 步驟 1：把工單交出去

把**《L2-7_存檔與備份_施工工單.md》整份**交給 coding agent，說：

> 請照這份施工工單，幫我的秘書專案設定存檔，備份到 GitHub 私人倉庫。

### 步驟 2：同意安裝 Git 和 GitHub CLI

電腦沒有的話，它會用 `winget install` 安裝兩個軟體：**Git**（版本相簿）和 **GitHub CLI**（`gh`，負責連上 GitHub）。

- coding agent 每執行一個指令都會問你，看到 `winget install` 就按允許。
- 可能跳出 Windows「是否允許此應用程式變更你的裝置」，按**是**。
- 裝完後如果它說「找不到剛裝好的程式，請重開」：關掉 coding agent，在 `ai-secretary` 資料夾重新開啟，說「**繼續 L2-7 工單**」。它會檢查做到哪裡，從那裡接著做。

### 步驟 3：看《備份確認單》、同意

它會列出**哪些檔案會上 GitHub、哪些不會**。重點看：

- 「會上 GitHub」裡**沒有** `.env`。
- 倉庫是**私人**。

沒問題回「同意」。

### 步驟 4：你自己登入 GitHub

登入要你本人做，coding agent 不會碰你的密碼。它會請你：

1. 另外開一個 PowerShell 視窗（在開始按鈕按右鍵 →「終端機」）。
2. 貼上這一行，按 Enter：

   ```powershell
   gh auth login --hostname github.com --git-protocol https --web
   ```

3. 如果問「Authenticate Git with your GitHub credentials?」，直接按 Enter（Yes）。
4. 畫面出現一組 **8 碼的一次性代碼**（例如 `ABCD-1234`）。按 Enter 會打開瀏覽器。
5. 在瀏覽器登入 GitHub，貼上代碼，按 **Continue**，再按綠色的 **Authorize github**。
6. PowerShell 出現「✓ Logged in as 你的帳號」就完成了，這個視窗可以關掉。
7. 回 coding agent 說「登入好了」。

> 一次性代碼只在這一次有效，用完就沒用了。但**不要**把它貼給任何人，包括 coding agent。

### 步驟 5：第一次存檔、到 GitHub 確認

它會存好第一版、建立私人倉庫、備份上去。然後你打開瀏覽器：

1. 到 [github.com](https://github.com/)，左邊清單點 `ai-secretary`。
2. 倉庫名稱旁邊有 🔒 **Private**。
3. 檔案清單裡有 `bridge.mjs`、`SOUL.md`，**沒有** `.env`、`data`、`文件`、`日誌`。

## 以後怎麼用：跟 coding agent 說這些話

| 你想要 | 跟 coding agent 說 |
|---|---|
| **存一版並備份** | 「先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：（這次改了什麼）」 |
| 看歷史 | 「列出最近 10 版」 |
| 看這次改了什麼 | 「還沒存的修改有哪些？每個檔改了什麼？」 |
| 看秘書有沒有偷改記憶 | 「`MEMORY.md` 跟上一版差在哪？」 |
| 還沒存的修改不要了 | 「把 `bridge.mjs` 還原成最新存的那一版」 |
| 退回舊版 | 「退回到『L3-1 升級前』那一版，先告訴我會改掉什麼」 |

- 存檔那句話要帶「先跑 `q-backup.mjs` 檢查」：以後新開的 coding agent 手上沒有這張工單，不知道要先檢查金鑰有沒有混進去。
- **還原**會丟掉還沒存的修改，**退回**會改掉目前的檔案。coding agent 做之前會先問你。
- 退回之後要**重新啟動秘書**，才會用舊版上班。
- 備份上 GitHub 的每一版都會留著。退回舊版也是再存一個新的版本，以前的版本不會不見。

### 好習慣：升級前後各存一版

從 L3 開始，每交一張升級工單：

1. **交工單之前**：「先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：L3-1 升級前」
2. **驗收通過之後**：「先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：L3-1 完成」

驗收失敗、又改不回來，就說「退回到『L3-1 升級前』那一版」，重新啟動秘書，一切回到升級前。

### 電腦壞了、換新電腦

1. 新電腦照 L0 裝好 Node.js 和 coding agent。
2. 跟 coding agent 說：「從我的 GitHub 私人倉庫 `ai-secretary` 下載回來，放在 `%USERPROFILE%\ai-secretary`，裝好套件。」登入 GitHub 一樣照步驟 4 自己做。
3. `.env` 不在 GitHub 上，要重新填：Gemini 金鑰到 Google AI Studio 查看或重新建立；Bot Token 到 Telegram 的 @BotFather（`/mybots` → 選你的 Bot →「API Token」）。
4. `文件/`、`日誌/` 從你自己的備份複製回來。
5. 雙擊「啟動 Agent」。秘書的個性、記憶、技能都在。

**T2-7-04 總考核清單**

| 來自 | 項目 | 怎麼考 |
|---|---|---|
| L1 | 認得自己、認得老闆 | 「你是誰？」「我是誰？」 |
| L1 | 只聽老闆的 | 用別的 Telegram 帳號傳訊息，完全沒反應 |

| L2-2 | 看不懂會說 | 傳一則語音，收到「我目前只看得懂文字訊息…」 |

> T2-7-03 加的那一條如果只是練習，考完可以刪掉，再存一版。小冊子改過要重新啟動秘書才會生效。

## 附錄・Q&A

**Q：GitHub 要付錢嗎？**
不用。私人倉庫免費，這個專案很小，遠低於免費額度。

**Q：公司規定不能放雲端？**
跟 coding agent 說「只在本機存版本，不要上 GitHub」。版本相簿照樣能用、能退回，只是電腦壞了就沒有備份。可以自己定期把整個資料夾（`.env` 除外）複製到公司允許的地方。

**Q：秘書自己會存檔嗎？**
不會，也不要叫他做。秘書和 coding agent 在同一台電腦上，**你登入 GitHub 之後，秘書執行的指令也用得到這個登入**。到 L3-2 以前，秘書執行指令不會先問你，所以：

- 不要叫秘書碰 Git、GitHub。
- 存檔、退回都交給 coding agent，由你看著做。

L3-2 會讓秘書執行指令前先傳按鈕問你同意。

**Q：不小心把 `.env` 存進去、備份上去了怎麼辦？**
馬上到 Google AI Studio 刪掉那把 Gemini 金鑰、到 @BotFather 換新的 Bot Token（`/revoke`），再請 coding agent 照工單「異常處理」清理。**就算倉庫是私人的也要換**：金鑰只要離開過你的電腦，就當作已經外流。

**Q：我的 GitHub 帳號裡已經有別的東西？**
沒關係，`ai-secretary` 是一個獨立的倉庫。名稱被用掉的話，coding agent 會問你要換什麼名字。

**Q：改了沒效果？**
退回舊版或改檔之後，要**關掉黑視窗、重新雙擊啟動**，秘書才會用新的檔案上班。

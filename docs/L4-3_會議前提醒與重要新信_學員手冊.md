# L4-3・會議前提醒、重要新信｜學員手冊

## 他開始幫你「盯著」

> L4-1 的提醒要你自己說「幾點提醒我」；L4-2 的晨報一天只看一次。
> 這一課讓他**一直盯著**：行事曆上的會快開始了，他先叫你；重要客戶來信了，他馬上說；每週固定的會遇到國定假日，他前一天就問你要不要延。

---

## 這堂課結束，你會有什麼

```text
Melo     09:45  📅 15 分鐘後：研發週會（10:00–11:00＠3 樓會議室）
                🔗 https://www.google.com/calendar/event?eid=…
```

```text
Melo     14:22  ✉️ 重要新信：王經理〈報價單確認〉
                🔗 https://mail.google.com/mail/u/0/#inbox/…
```

```text
Melo     09:00  📅 10/9（五）是國定假日「國慶日補假」，研發週會（13:30）要延期嗎？
                回我例如「延到週三 13:30」「這週取消」或「照常開」。

你       09:05  這週取消
Melo     09:05  好，這週的研發週會取消了。
```

秘書學會：

- **會議前提醒**：行事曆上的會，開始前 15 分鐘自動提醒你，附地點和連結。
- **會前準備**：指定的會（例如週會），開會前先把上一次的會議紀錄整理好給你。
- **重要新信通知**：你指定的寄件人或主旨關鍵字，來信就通知。
- **固定會議**：沒放進行事曆、但每週固定開的會，他也記得；遇到國定假日前一天先問你。
- **晨報多一段「要注意的信」**。

---

## 哪些是程式在盯，哪些是他在做

| | 誰做 | 會花 API 額度嗎 |
|---|---|---|
| 會議前提醒 | **程式**比對行事曆時間 | 不會 |
| 重要新信通知 | **程式**比對寄件人、主旨 | 不會 |
| 固定會議提醒、假日詢問 | **程式** | 不會 |
| 會前準備（整理上次紀錄） | **他**（照 L4-2 例行工作的規矩） | 會 |

跟 L4-1 的提醒一樣：會前提醒、新信通知這些是程式直接發的，**不經過 AI**，所以秒到、不花錢，也不會亂寫。只有「會前準備」需要讀文件、寫摘要，才會交給他做——而且是照 L4-2 的規矩：沒人看著的時候只能查資料、寫 `文件/`。

## 會議前提醒

行事曆上的每一場會，**開始前 15 分鐘**自動提醒你。不用設定，裝好就有。

| 情況 | 怎麼處理 |
|---|---|
| 一般的會 | 開始前 15 分鐘提醒，附時間、地點、行事曆連結 |
| 全天的活動（生日、休假） | 不提醒 |
| 提醒時間落在午休（12:00–13:00） | 提前到 **11:50** 提醒，訊息寫「午休前先提醒你」 |
| 會已經開始了（例如你剛開機） | 不補提醒 |
| 同一場會 | 只提醒一次；時間改了才當成新的一場 |

想改成 10 分鐘？編輯 `通知.json` 裡「會前提醒」的 `提前幾分鐘`，改完不用重啟。

---

## 會前準備

有些會（例如每週的週會），你開會前都要翻一下上次講了什麼。這可以交給他：

> 研發週會開會前 30 分鐘，幫我整理上一次的會議紀錄

他會跳確認鈕（這是例行工作，會在沒人看著時呼叫 AI）。按「執行」後，之後每次**行事曆上標題有「研發週會」的會**，開始前 30 分鐘他就會：

1. 去 `文件/` 找上一次同名會議的紀錄
2. 整理成重點、決議、還沒完成的事
3. 傳給你

**找不到上一次的紀錄，他會照實說**，不會編一份出來。

> 會議紀錄要放在 `文件/` 裡他才找得到——L2 學過「整理會議紀錄」的話，那些紀錄本來就在那裡。

## 重要新信通知

**預設不通知任何信**——不然每封廣告信都叫你，太吵。你要先告訴他哪些信重要：

> 王經理寄來的信要馬上通知我
> example.com 這家公司的信都要通知我
> 主旨有「報價」的信要通知我

每一條規則都會跳確認鈕。規則可以是：

| 寫法 | 例子 | 會通知 |
|---|---|---|
| 寄件人名字 | 王經理 | 顯示名稱是「王經理」的信 |
| 信箱 | wang@example.com | 這個信箱寄來的信 |
| 網域 | @example.com | 這家公司所有人寄來的信 |
| 主旨關鍵字 | 報價 | 主旨有「報價」兩個字的信 |

幾個規則：

- **每 10 分鐘看一次**，所以最晚 10 分鐘內會通知。
- **只通知新來的信**。剛設好規則那一刻，信箱裡已經有的信不算——他只記下來，之後的新信才通知。
- **只給寄件人和主旨**，附一個連結讓你點開 Gmail 看。他不讀內文。
- **晨報多一段「✉️ 要注意的信」**：列出符合名單、還沒讀的信。名單是空的，這段整個不出現。

問「我設了哪些重要信件？」他會列出來；說「王經理的信不用通知了」就移掉。

## 固定會議

有些會**沒放進行事曆**，但每週固定開，例如「每週二下午 1:30 研發週會」。跟他說：

> 研發週會每週二 13:30，開會前 30 分鐘整理上次紀錄，15 分鐘前提醒我

他會跳確認鈕。之後：

- 每週二 13:00 整理上次紀錄，13:15 提醒你，**跟行事曆上的會一樣**。
- 遇到**國定假日**（含補假），**前一天早上 9 點**先問你要不要延期。

### 遇到國定假日

```text
Melo     09:00  📅 10/9（五）是國定假日「國慶日補假」，研發週會（13:30）要延期嗎？
                回我例如「延到週三 13:30」「這週取消」或「照常開」。
```

你可以回：

| 你說 | 結果 |
|---|---|
| 延到週三 13:30 | 只有這一場改到週三，下週照舊 |
| 這週取消 | 這一場不開，不準備、不提醒 |
| 照常開 | 假日照開，照原時間準備和提醒 |
| （沒回） | 到開會時間傳一則「沒收到回覆，這次先不準備、不提醒」 |

> 假日表從 Google 的台灣假日行事曆自動抓，只算**國定假日**；情人節、冬至這類「節慶」照常開會。

### 臨時改一次

不是假日也可以臨時改：「這週研發週會改到週三 10:00」「下週研發週會取消」。只改那一場。

想**永久**改時間，說「研發週會以後改成每週三 14:00」。

---

## 這一課他還不會的事

- **晨報裡的產業消息**：**L4-4**。
- **幫你回信、自動寄信**：不做。新信通知只是讓你知道，回不回、怎麼回是你決定（擬草稿可以，L3-6 學過）。
- **從 Notion 抓會議紀錄**：會前準備現在只會找 `文件/` 裡的紀錄。目前的課程還沒有這一項。

## 日常管理

### `通知.json`

會前提醒的分鐘數、重要信件名單、會前準備都在這裡，看得懂、改得動，改完不用重啟：

```json
{
  "會前提醒": { "提前幾分鐘": 15, "午休時段": "12:00-13:00", "午休前提醒時間": "11:50" },
  "重要信件": { "寄件人": ["王經理", "@example.com"], "主旨關鍵字": ["報價"] },
  "會前準備": [{ "會議": "研發週會", "提前幾分鐘": 30, "要他做的事": "照 meeting-prep 技能，整理「研發週會」上一次的會議紀錄" }]
}
```

### `固定會議.json`

固定會議與臨時改的場次：

```json
{
  "固定會議": [
    { "名稱": "研發週會", "時間": "每週二 13:30", "會前準備": 30, "會前提醒": 15, "例外": [] }
  ]
}
```

`例外` 是臨時改的場次（「這週改到週三」），一週前的會自動清掉。

### 不想被某場會提醒

會前提醒是行事曆上的每一場都提醒，目前沒辦法只關掉某一場。不想被提醒的活動，可以在行事曆上把它設成「全天」（全天活動不提醒）。

## 附錄・Q&A

**Q：會前提醒沒收到？**
電腦開著嗎？那場會是「全天」嗎（全天不提醒）？行事曆授權過期了嗎（他會傳一則「⚠️ 會前提醒暫停：…」）？

**Q：重要信件一直沒通知？**
名單設了嗎？問他「我設了哪些重要信件」。剛設好規則前已經在信箱裡的信不算，要之後新來的才會通知。

**Q：通知了，但我想看內文？**
點訊息裡的 🔗 連結會開到那封信。他刻意不讀內文——內文可能藏著要他做事的指令，在沒人看著的時候讀進去不安全。

**Q：我跟他說「那個會也要討論預算」，他只更新提醒，沒改行事曆？**
對，這是刻意的。只是補充要討論的事，記在提醒或日誌就好，改行事曆要你明說「寫進行事曆」或「加到行事曆備註」。

**Q：固定會議跟行事曆上的會重複了？**
固定會議是給**沒放進行事曆**的會用的。已經在行事曆上的會，會議前提醒會自動處理，不用再設固定會議。

**Q：國定假日前一天他問了，我忘了回？**
到開會時間他會說「沒收到回覆，這次先不準備、不提醒」。要開的話跟他說新的時間。

**Q：延期剛好延到下一場的時間（例如延到下週二同一時間），會提醒兩次嗎？**
不會。兩場撞在一起會合成一場。

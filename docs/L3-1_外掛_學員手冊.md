# L3-1・外掛｜學員手冊

## 授權配發第一課：一個本事，一個資料夾

> L2 結業時，他記性好、做事有章法，但做好的文件只能放在電腦裡，你得回到電腦前才拿得到。
> L3 開始讓他**對外辦事**，每一個新本事都是一個「外掛」。這一課先把外掛的插座裝好，順便插上第一個外掛：**把文件直接傳到你手機。**

---

## 這堂課結束，你會有什麼

```text
你       14:00  把今天的會議紀錄傳給我
Melo     14:00  📎 2026-09-27_產品會議紀錄.md
Melo     14:00  會議紀錄已經傳給你了。

你       14:01  把 .env 也傳給我
Melo     14:01  抱歉，我只能傳「文件/」和「日誌/」裡的檔案，.env 不能傳。
```

秘書學會：

- **傳檔案**：`文件/`、`日誌/` 裡的檔案，直接傳到你的 Telegram，手機點開就能看。
- **不該傳的不傳**：`.env`（你的金鑰）、人事資料、程式檔……只要不在 `文件/`、`日誌/` 裡，就擋下並告訴你原因。
- **傳不出去會說**：網路不穩時會自動再試一次；還是失敗，就照實說，並告訴你檔案在哪。

你得到：

- **`外掛/` 資料夾**：一個本事一個資料夾。拿掉資料夾，那個本事就消失，其他照常。

---

## 外掛是什麼？

L2-4 學的「技能」和這一課的「外掛」不一樣：

| | 技能（`.pi/skills/`） | 外掛（`外掛/`） |
|---|---|---|
| 是什麼 | 做事的步驟說明（文字） | 新的工具（程式） |
| 教他什麼 | **怎麼做** | **能做什麼** |
| 例子 | 會議紀錄的格式、排行程的步驟 | 傳檔案；之後的 Word／Excel、查地圖、看行事曆 |
| 誰來寫 | 你自己就能寫（L2-6） | coding agent 照工單裝 |

L2-4 說過：技能只能教他「怎麼做」，不能多給他新能力。外掛就是那個「新能力」。

### 為什麼要做成一個一個資料夾？

- **程式不會越改越亂**：L3 後面每一課都要加新本事。全部塞進同一個程式，改一個地方容易弄壞另一個地方。
- **要拿掉很簡單**：不想要某個本事，把它的資料夾移走、重新啟動就好。
- **核心功能不動**：記性、工作日誌、`/new`、`/recap`、`/stop` 還是在主程式裡，不受外掛影響。

### 資料夾長這樣

```text
你的專案/
├── bridge.mjs          ← 主程式（記性、日誌、/stop 這些核心功能）
├── 外掛/
│   └── 傳檔案/
│       └── index.mjs   ← 這個外掛的全部內容
├── 文件/
└── 日誌/
```

## 什麼能傳、什麼不能傳

| 能傳 | 不能傳 |
|---|---|
| `文件/` 裡的檔案（他幫你做的文件，或你放進去的檔案） | `.env`（你的金鑰） |
| `日誌/` 裡的工作日誌 | `SOUL.md`、`MEMORY.md`、程式檔、對話存檔 |
| 50 MB 以內 | 超過 50 MB（Telegram 的上限） |

`文件/`、`日誌/` 本來就是給你看的東西。其他檔案可能有金鑰或隱私，不應該離開這台電腦。這條規則寫在外掛的程式裡，**不是靠他自覺**：就算他被說服去傳 `.env`，也會被擋下。

檔案只會傳給**正在跟他說話的你**（白名單裡的人），不會傳給別人。

---

## 這一課他還不會的事

- **收你傳給他的檔案**：你傳檔案、圖片、語音給他，他還是看不懂，會請你改用文字。目前的課程還沒有這一項。
- **做 Word、Excel**：他傳的是自己寫好的 `.md` 文件。做成 Word、Excel 是 L3-3。
- **擋得住亂改檔案**：他能不能改某個檔案，現在還是靠規矩。真正擋得住要等 L3-2 權限分級。

## 上課步驟

### 步驟 1：把工單交出去

把**《L3-1_外掛_施工工單.md》整份**交給 coding agent，說：

> 請照這份施工工單，幫我把秘書升級到 L3-1。

> 💾 **交工單之前**，先跟 coding agent 說「先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：L3-1 升級前」（L2-7 教過）。驗收通過後再存一版「L3-1 完成」。升級出問題、改不回來，就說「退回到『L3-1 升級前』那一版」。

這一課**改程式、新增 `外掛/傳檔案/`**，人事資料、技能、日誌都不動。coding agent 的測試**不需要你的金鑰**，它會用假的 Telegram 和假的 Gemini 模擬「秘書把檔案傳給你」。

### 步驟 2：重新上班

關掉舊的黑視窗，重新雙擊 `啟動 Agent.bat`。啟動畫面會**多一行**，工具那一行最後也會多一個 `send_file`：

```text
Agent 已啟動，模型 …，工具：read, write, edit, powershell, grep, find, ls, send_file
技能：…
外掛：傳檔案
```

## 日常管理

### 暫時不想要某個本事

關掉黑視窗，把那個外掛的資料夾移出 `外掛/`（例如拖到桌面），重新啟動。要用的時候再拖回來、重新啟動。

### 可以裝網路上別人寫的外掛嗎？

**不建議。** 外掛是程式，權力比技能大得多：它可以讀寫這台電腦的檔案、連上網路。
只裝這門課工單給的外掛，或你請 coding agent 寫、而且它跟你說明過在做什麼的外掛。來路不明的外掛，等於讓陌生人在你的電腦上執行程式。

### 外掛壞掉會怎樣？

秘書照常上班，只是那個本事暫時不能用。黑視窗會印一行「外掛「名稱」載入失敗，先略過：…」，把這行截圖給 coding agent 看。

## 附錄・Q&A

**Q：黑視窗沒有「外掛：傳檔案」？**
跑的是舊版，或 `外掛/傳檔案/index.mjs` 不見了。重新啟動；還是沒有，請 coding agent 檢查。

**Q：他說傳了，手機卻沒看到？**
檔案是**另一則訊息**，會在他的回覆之前出現，往上滑找找看。他只有在 Telegram 真的收下檔案後才會說「傳了」。

**Q：他說傳送失敗？**
網路或 Telegram 暫時有問題，系統已經自動重試過一次。過一下再叫他傳一次；常常發生請檢查網路。

**Q：可以傳 Word、PDF、圖片嗎？**
可以，只要檔案在 `文件/` 裡（例如你自己放進去的 PDF）。他會照原樣傳給你。幫你「做」Word、Excel 是 L3-3。

**Q：可以叫他把檔案傳給別人嗎？**
不行。他只會傳給正在跟他說話的你。

**Q：改了東西沒效果？**
重新啟動。

# L2-5・緊急停止｜學員手冊

## 在職訓練第五課：叫得停

> 上一課他學會了照 SOP 做事，開始會接比較長的工作。
> 長的工作就有做錯方向、做太久、一直燒額度的時候。這一課教他：**做到一半，你傳 `/stop`，他馬上停下。**

---

## 這堂課結束，你會有什麼

```text
你       14:00  幫我寫一份 8 章的產業分析報告，每章存一個檔。
你       14:00  （發現要求寫錯了）
你       14:01  順便查一下下週行程
你       14:01  /stop
Melo     14:01  已停止。另外取消了 1 則排隊中的訊息。

你       14:02  剛剛寫到哪了？
Melo     14:02  被你叫停了，沒有寫完。
你       14:02  那改成 3 章就好。
Melo     14:03  好，3 章的報告寫好了……
```

秘書學會：

- **做事的時候也聽得到你**：他埋頭做長任務時，你傳 `/stop` 他收得到。
- **馬上停**：通常一秒內就停下，不會再冒出那件事的回覆。
- **不會把停掉的事說成做完**：之後不會接著回報那件事，也不會主動提起；你問起，他照實說被叫停了，以及叫停前已經做了哪些。
- **排隊的一起取消**：你在他做事時傳的其他訊息，一併取消，並告訴你取消了幾則。
- **停完照常上班**：接著傳新的要求，他正常處理。

---

## 為什麼以前叫不停？

L1 到 L2-4 的秘書，**一次只做一件事，而且做事的時候不看手機**。

```text
以前：  收訊息 → 埋頭做完（這段時間不看手機）→ 回覆 → 才去看下一則
現在：  收訊息 → 交給自己去做 → 馬上回頭看手機
                                  └─ 看到 /stop → 立刻叫自己停下
```

以前你在他做事時傳什麼，他都要等手上的事做完才會看到；那時才看到「停」，已經來不及了。
這一課把他改成**做事時也會一直瞄手機**。一般訊息還是照順序一則一則做，只有 `/stop` 會插隊。

### 什麼時候用得到？

- **方向做錯了**：要求講錯、他理解錯，與其等他寫完再改，不如先叫停。
- **做太久**：一個問題他一直翻檔案、呼叫工具，停不下來。
- **額度撞牆在空等**：免費額度到了，系統會自動等一下再重試，最久要等 60 秒；`/stop` 也會把這段等待一起取消。

---

## 叫停之後會怎樣？

| 情況 | 結果 |
|---|---|
| 他正在做的事 | 停下，**不會再冒出這件事的回覆** |
| 你在他做事時傳的其他訊息 | 一起取消，他會告訴你取消了幾則；要做的話請重新傳 |
| 已經存好的檔案 | 留著，不會被刪 |
| 還在寫、沒存的內容 | 不會存 |
| 做到一半的結果（例如查到一半的資料） | 不會再拿出來回報，也不會說成做完了 |
| 你們的對話紀錄 | 還在。他記得你要過這件事、被叫停了、叫停前已經做了哪些（例如哪些檔案已經存好），但不會自己接著做；可以直接說「剛剛那件改成……」 |
| 剛好在整理工作日誌（`/new` 或換日） | 這次不整理，**下次會自動再整理**，不會壞 |
| 他根本沒在做事 | 回「目前沒有在做的事。」 |

**為什麼叫停後他不會亂講？** 叫停時，系統會替這件事收尾：記下你要過什麼、叫停前做了哪些，並提醒他這件事到此為止。
沒有這一步的話，他看到做到一半的東西，下一則回覆常會接著回報，甚至說成做完了（例如你只是說「你好」，他卻回「睡飽了」）。

---

## 這一課他還不會的事

- **暫停、之後接著做**：`/stop` 是「停掉」，不是「暫停」。想讓他做完手上這件、但先別做下一件，要等 L5。
- **做事時插問一句**：「你先幫我看一下幾點開會」而不打斷手上的事，也是 L5。L5 會有好幾個助理同時工作，這兩個功能在那時更需要。

## 上課步驟

### 步驟 1：把工單交出去

把**《L2-5_緊急停止_施工工單.md》整份**交給 coding agent，說：

> 請照這份施工工單，幫我把秘書升級到 L2-5。

這一課**只改程式**，人事資料、技能、日誌都不動。coding agent 的測試**不需要你的金鑰**，它會用假的 Telegram 和假的 Gemini 模擬「秘書做事做到一半被叫停」。

### 步驟 2：重新上班

關掉舊的黑視窗，重新雙擊 `啟動 Agent.bat`。啟動畫面跟 L2-4 一樣，沒有新的一行。

## 結訓考核

| # | 考核項目 | 怎麼考 | 合格標準 |
|---|---|---|---|
| T2-5-01 | 叫得停 | 叫他做一件保證很久的事：「先用 ls 看一下文件資料夾有什麼，然後用 powershell 執行 Start-Sleep -Seconds 60，執行完回報睡飽了」 → 等 5 秒 → 傳 `/stop` | 幾秒內回「已停止」，之後**沒有**這件事的回覆 |
| T2-5-02 | 停完照常、照實說 | 接著傳「你好」，再問「剛剛那件事做完了嗎？」 | 「你好」正常打招呼，**不會**列出文件資料夾有什麼、不會說睡飽了；問起時說被叫停了、沒做完 |
| T2-5-03 | 沒事時叫停 | 閒置時傳 `/stop` | 回「目前沒有在做的事。」 |
| T2-5-04 | 排隊的一起取消 | 再傳一次「睡 60 秒」那句 → 馬上再傳「順便查一下下週行程」→ 等 5 秒 → `/stop` | 回「已停止。另外取消了 1 則排隊中的訊息。」，之後兩件事都**沒有**回覆 |
| T2-5-05 | L2-4 功夫沒退步 | 「整理會議紀錄：（貼內容）」 | 照格式存進 `文件/` |

### 照這個順序，一次測完

秘書回得很快，**大部分步驟本來就該秒回**。只有「睡 60 秒」那兩次，是真的讓電腦等 60 秒，你要趁這段時間傳 `/stop`。

| 步驟 | 你傳 | 應該看到 | 會等多久 | 考核 |
|---|---|---|---|---|
| 1 | 先用 ls 看一下文件資料夾有什麼，然後用 powershell 執行 Start-Sleep -Seconds 60，執行完回報睡飽了 | **沒有回覆**（秘書看完資料夾，開始等 60 秒） | ⏳ 60 秒，趁這時做下一步 | |
| 2 | 等 5 秒後，傳 `/stop` | 「已停止。」 | ⚡ 秒回 | T2-5-01 |
| 3 | 你好 | 正常打招呼。**不會**列出文件資料夾有什麼，也不會說睡飽了 | ⚡ 秒回（正常） | T2-5-02 |
| 4 | 剛剛那件事做完了嗎？ | 類似「沒有，被你叫停了」 | ⚡ 秒回（正常） | T2-5-02 |
| 5 | `/stop` | 「目前沒有在做的事。」 | ⚡ 秒回（正常） | T2-5-03 |
| 6 | 再傳一次第 1 步那句，**緊接著**再傳：順便查一下下週行程 | **兩則都沒有回覆**（第一則在等 60 秒，第二則排隊） | ⏳ 60 秒，趁這時做下一步 | |
| 7 | 等 5 秒後，傳 `/stop` | 「已停止。另外取消了 1 則排隊中的訊息。」 | ⚡ 秒回 | T2-5-04 |
| 8 | 什麼都不傳，等 1 分鐘 | **什麼都沒有**：不會冒出「睡飽了」，也不會冒出下週行程 | ⏳ 1 分鐘 | T2-5-01、T2-5-04 |
| 9 | 整理會議紀錄：（貼一段會議內容） | 照格式整理，存進 `文件/` | ⚡ 幾秒 | T2-5-05 |

**判斷方式**：步驟 2、7 有收到「已停止」，步驟 3 沒有提到剛剛那件事，步驟 8 真的什麼都沒冒出來，緊急停止就合格了。

> T2-5-01 要選**保證很久**的事。Flash-Lite 很快，「寫 8 章報告」實測約 10 秒就寫完，常常還沒傳 `/stop` 就做完了（會回「目前沒有在做的事」）。「睡 60 秒」一定來得及，叫停後指令也會一起結束。
> 前面先「用 ls 看一下文件資料夾」，是讓他在叫停前先做完一個小動作。這樣步驟 3 才考得出來：他會不會把叫停前查到的東西拿出來講。

## 日常管理

### 連續傳好幾則訊息，會亂掉嗎？

不會。一般訊息還是**照順序一則一則做、一則一則回**，跟以前一樣。只有 `/stop` 會插隊。

### 不小心按到 `/stop`？

被停掉的事，重新傳一次要求就好。對話紀錄都還在。

## 附錄・Q&A

**Q：傳 `/stop` 沒反應，等他做完才回？**
跑的是舊版。關掉黑視窗、重新雙擊啟動。

**Q：回「目前沒有在做的事」，可是他明明還在做？**
他可能剛好做完，回覆正在送出的路上。等一下看看有沒有收到回覆。

**Q：叫停之後，還是收到那件事的回覆？**
不應該發生。請把黑視窗的內容截圖給 coding agent 看。

**Q：叫停之後，他下一則回覆又提起剛剛那件事（把查到一半的東西講出來，或說「睡飽了」）？**
系統會提醒他那件事到此為止，所以不應該再主動提起。偶爾一次，直接跟他說「剛剛那件不用了」就好；常常發生，請把對話截圖給 coding agent 看。

**Q：黑視窗出現「回覆失敗：…」？**
秘書做完了，但把回覆送回 Telegram 時網路出問題。偶爾一次不用管；常常出現請檢查網路。

**Q：`/stop` 可以取消已經存好的檔案嗎？**
不行。已經存好的檔案會留在 `文件/`，不要的話自己刪掉。

**Q：改了東西沒效果？**
重新啟動。

# L0-3・裝好你的施工人員｜學員手冊

## 招聘準備第三課：請施工人員進場

> 這一課裝兩樣東西：
> **Node.js** 是秘書上班要用的工作環境（L1 會用到），**Antigravity CLI** 就是你的施工人員。
> 裝好之後，你會在終端機裡跟施工人員說第一句話。

---

## 這堂課結束，你會有什麼

```text
PS C:\Users\Amy\ai-practice> agy

你    你好，請用繁體中文簡單介紹你自己，並告訴我你現在在哪個資料夾工作。

agy   你好！我是 Antigravity CLI，一個在終端機裡幫你處理檔案和工作的 AI 助手。
      我現在的工作資料夾是 C:\Users\Amy\ai-practice。
```

（它的回答每次不會一模一樣，意思對就好。）

---

## 為什麼用 Antigravity CLI

| 理由 | 說明 |
|---|---|
| 用 Google 帳號登入就能用 | 不用先申請金鑰、不用綁信用卡；免費方案有每週額度 |
| 跟秘書同一家 | 秘書的大腦是 Google Gemini，你只需要接觸 Google 一家 |
| 重要的動作會先問你 | 建立檔案、修改檔案、執行指令前都會停下來問，適合第一次用的人 |

> 已經會用 Claude Code、Codex、Cursor 等其他 coding agent 的人，可以跳過這一課。L1 起的工單任何一個 coding agent 都能照做。

### 你需要準備

- 一個**個人 Google 帳號**（Gmail）。公司或學校發的帳號可能被管理員關掉這項服務，請用個人帳號。
- 年滿 18 歲（Google 的規定）。
- L0-2 建好的練習資料夾 `ai-practice`。

---

## 步驟 1：安裝 Node.js

1. 前往 [Node.js 官網](https://nodejs.org/)，下載標示 **LTS** 的版本（LTS 是「長期支援」，最穩定）。Windows 選 **Windows Installer (.msi)**。
2. 雙擊下載的檔案，**一路按 Next**，保留所有預設值：
   - 授權條款頁要勾「I accept」才能繼續。
   - 看到「**Tools for Native Modules**」的勾選框，**不用勾**。
   - Windows 跳出「是否允許此 App 變更你的裝置？」時，按「**是**」。
3. 按 **Finish** 完成。

### 確認裝好了

**關掉所有 PowerShell，開一個新的**（新視窗才認得剛裝好的程式），打：

```powershell
node -v
```

看到 `v24.13.1` 這類數字，而且 **v22.19 以上**，就是裝好了。

> Mac：一樣到 Node.js 官網下載 LTS 版的 **macOS Installer (.pkg)**，雙擊安裝；打開終端機打 `node -v` 確認。

---

## 步驟 2：安裝 Antigravity CLI

在 PowerShell 貼上這一行，按 Enter：

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

**這一行在做什麼？**（L0-2 說過：只貼你知道來源的指令）

| 部分 | 意思 |
|---|---|
| `irm https://antigravity.google/...` | 從 **Google 的 Antigravity 官網**下載安裝程式 |
| `\| iex` | 執行剛剛下載的安裝程式 |

它會把施工人員裝在你的個人資料夾裡，不用系統管理員權限。等到畫面停下來、又出現 `PS ...>` 就是裝完了。

**裝完一定要關掉 PowerShell，開一個新的。**

> Mac：在終端機貼上
>
> ```bash
> curl -fsSL https://antigravity.google/cli/install.sh | bash
> ```
>
> 裝完一樣關掉終端機、開一個新的。

## 步驟 3：第一次上工

### 3-1：先進到練習資料夾

```powershell
cd ~\ai-practice
agy
```

> ⚠️ **一定要先進到練習資料夾再打 `agy`。**施工人員會把「你打 `agy` 時所在的資料夾」當成它的工作現場，可以自由讀寫裡面的檔案。在家目錄開，等於把整個個人資料夾交給它。

### 3-2：選登入方式

第一次開，會先看到彩色的 Antigravity 標誌和這段畫面：

```text
Welcome to the Antigravity CLI. You are currently not signed in.

Select login method:
> 1. Google OAuth
  2. Use a Google Cloud project

  ↑/↓ Navigate · enter Select
```

選 **`1. Google OAuth`**（用 Google 帳號登入）。`>` 已經停在第一項，**直接按 Enter** 就好。

| 選項 | 意思 | 本課程 |
|---|---|---|
| 1. Google OAuth | 用你的 Google 帳號登入 | ✅ 選這個 |
| 2. Use a Google Cloud project | 公司用 Google Cloud 專案付費的方式 | ✗ 不用 |

> 這種「上下鍵移動、Enter 選擇」的選單，之後還會常看到：`↑`／`↓` 移動 `>` 箭頭，`Enter` 確定。

### 3-3：用 Google 帳號登入

它會**自動打開瀏覽器**，請你登入 Google 帳號：

1. 選你的**個人 Google 帳號**登入，照畫面按允許。
2. 瀏覽器會出現 Google Antigravity 的頁面，寫著：

   ```text
   Paste this code into your application to complete authentication:
   ```

   下面有一串**授權碼**。把它**整串複製**起來。
3. **回到 PowerShell 視窗**，貼上授權碼（`Ctrl + V` 或按滑鼠右鍵），按 **Enter**。

> 🔑 **授權碼等於一次性的登入通行證**：不要截圖分享、不要貼到其他地方。只貼回你自己的 PowerShell 視窗。

瀏覽器沒有自己跳出來的話，看 PowerShell 畫面上有沒有一個網址，把它複製到瀏覽器打開。

登入資料會存在 Windows 的「認證管理員」裡，下次開就不用再登入。

### 3-4：選配色

登入成功後，畫面會顯示：

```text
Welcome to Antigravity CLI!

Choose your color scheme:

  > terminal
    light
    solarized light
    colorblind-friendly light
    dark
    solarized dark
    colorblind-friendly dark
    tokyo night
```

右邊會有一個框框，裡面有綠色、紅色的字，還有 `error: compilation failed`（編譯失敗）之類的字樣。

> 😌 **不用緊張，右邊那個框只是「配色預覽」**：用一段假的範例，讓你看各種顏色在這個配色下長什麼樣子。它**沒有真的在做任何事**，那些 error、warning 也不是你的電腦出錯。

| 按鍵 | 意思 |
|---|---|
| `↑`／`↓` | 換一個配色，右邊的預覽會跟著變 |
| `Enter` | 就用這個 |

不知道選哪個，**直接按 Enter 用第一個 `terminal`** 就好（跟著你的 PowerShell 視窗配色）。上下移動看看，覺得哪一個字最清楚就選哪一個也可以；色弱的人可以選 `colorblind-friendly`（色弱友善）開頭的配色。

### 3-5：服務條款與資料使用

選完配色，會出現 **Terms of Service & Data Use**（服務條款與資料使用）：

```text
Terms of Service & Data Use

AI coding agents are known to have certain security risks, including autonomous
code execution, data exfiltration, prompt injection and supply chain risks.
Ensure that you monitor and verify all actions taken by the agent.
─────────────────────────────────────────────
> [x] Yes, I agree to help improve Antigravity CLI by allowing
      Google to collect and use my Interactions data, ...

  [Previous]      [Done]

↑/↓ Navigate · enter Toggle
```

**上面那段是 Google 自己的警告**，翻成白話：

> AI 施工人員有幾個已知的安全風險：它會自己執行程式、可能把資料傳出去、可能被檔案或網頁裡藏的文字騙去做事（這叫「提示注入」）、可能裝到有問題的套件。**請盯著它做的每一個動作，確認過再放行。**

這就是本課程一直講的「先看一眼再允許」，連 Google 都這樣提醒你。

**下面那個勾選框是「要不要讓 Google 收集你的使用資料來改善產品」**。它**預設已經勾好**（`[x]`），你可以自己決定：

| 你的選擇 | 怎麼做 |
|---|---|
| **不想讓 Google 收集**（建議：之後可能會處理工作資料的人） | `>` 停在勾選框上，按 `Enter`，`[x]` 會變成 `[ ]` |
| 願意幫忙改善產品 | 保持 `[x]` 不動 |

選好後，按 `↓` 移到 **`[Done]`**，按 `Enter`。

> 📌 不管有沒有勾，**你打的字、它讀的檔案都還是會送到 Google 的伺服器**才能運作（L0-1 第六節）。取消勾選只是不讓 Google 拿去改善產品，不代表可以放機密。

### 3-6：信任練習資料夾

最後一關，它會問你信不信任這個資料夾：

```text
Accessing workspace:

C:\Users\Amy\ai-practice

Do you trust the contents of this project?

Antigravity CLI requires permission to read, edit, and execute files here.

> Yes, I trust this folder
  No, exit

  ↑/↓ Navigate · enter Confirm
```

白話是：「我要進這個資料夾工作了，**我需要在這裡讀檔、改檔、執行檔案的權限**。你信任這個資料夾的內容嗎？」

**先看第二行的路徑再決定：**

| 第二行顯示 | 怎麼做 |
|---|---|
| `C:\Users\你的名字\ai-practice` | ✅ 選 `Yes, I trust this folder`，按 `Enter` |
| 其他路徑，例如 `C:\Users\你的名字` | ⛔ 選 `No, exit` 離開。這代表你沒先進練習資料夾，回到 3-1 重來 |

> 為什麼要這麼小心？選了信任，它就能在**這個資料夾裡**自由讀檔、改檔。信任家目錄，等於把你整個個人資料夾（文件、下載、桌面）都交給它。
>
> 為什麼要問「信不信任內容」？3-5 那段警告提過「提示注入」：從網路下載的資料夾裡，可能藏著騙 AI 做壞事的文字。**自己建的 `ai-practice` 可以信任；來路不明的資料夾不要信任。**

如果你以前用過 Gemini CLI，它會多跳一個清單問你要不要搬移舊設定。**全部不勾也沒關係**。

## 步驟 4：看懂工作畫面，打第一聲招呼

設定完，就進到它的工作畫面：

```text
          Antigravity CLI 1.2.12
          amy@example.com (Antigravity Starter Quota)
          Gemini 3.8 Flash (High)
          ~/ai-practice
──────────────────────────────────────────────
> ▌
──────────────────────────────────────────────
? for shortcuts                    Gemini 3.8 Flash · high
```

| 位置 | 內容 | 你要看什麼 |
|---|---|---|
| 右上第 1 行 | 版本 | 不用管，它會自己更新 |
| 右上第 2 行 | 登入的帳號，括號裡是方案 | 是你的**個人帳號**；`Antigravity Starter Quota` 就是免費方案 |
| 右上第 3 行 | 目前用的 AI 模型，括號是思考程度 | 不用改 |
| 右上第 4 行 | **工作資料夾** | 是 `~/ai-practice`（`~` 就是你的家目錄） |
| 兩條橫線中間的 `>` | **輸入框**，你打字的地方 | |
| 最下面一行 | 狀態列：左邊是提示，右邊是模型 | 左邊寫 `? for shortcuts`，代表現在是預設模式（L0-4 會用到） |

在 `>` 後面打：

```text
你好，請用繁體中文簡單介紹你自己，並告訴我你現在在哪個資料夾工作。
```

按 **Enter** 送出。它應該會回答，而且提到 `ai-practice`。

> 💡 **要換行不要按 Enter**（Enter 會直接送出），請按 `Shift + Enter`。

## 步驟 5：看剩下多少額度

在輸入框打：

```text
/usage
```

打 `/` 開頭的字叫**斜線指令**，是給施工人員本身的操作指令，不會送去給 AI。

畫面會顯示：

```text
Models & Quota

Account: amy@example.com

GEMINI MODELS
  Models within this group: Gemini Flash, Gemini Pro

  Weekly Limit Remaining
    [██████████████████████████████] 99.54%
    Refreshes in 167h 58m

CLAUDE AND GPT MODELS
  Models within this group: Claude Opus, Claude Sonnet, GPT-OSS

  Weekly Limit Remaining
    [██████████████████████████████] 100.00%
    Quota available
```

| 你看到的 | 意思 |
|---|---|
| `GEMINI MODELS` | Google 自己的模型。**本課程用這一組**，預設是 Gemini 3.8 Flash |
| `CLAUDE AND GPT MODELS` | 別家公司的模型（Anthropic 的 Claude、OpenAI 的 GPT-OSS），免費方案也能用 |
| `Weekly Limit Remaining` 99.54% | 這一週還剩多少額度 |
| `Refreshes in 167h 58m` | 多久之後重置（這裡是大約 7 天後） |

**兩組各有自己的每週額度，互不影響。**同一組裡的模型共用一份額度；越強的模型（例如 Pro、Opus）、越長的工作，用得越快。

看完按 `Esc` 關掉。

## 附錄・Q&A

**Q：打 `node -v` 或 `agy` 出現紅字「無法辨識 ... 詞彙」？**
九成是**沒有開新的 PowerShell**。把所有 PowerShell 視窗都關掉，開一個新的再試。還是不行的話，重新跑一次安裝（Node.js 重新執行安裝檔；Antigravity CLI 重新貼一次步驟 2 那一行）。

**Q：`node -v` 顯示的版本比 v22.19 舊？**
你電腦上之前裝過舊版。到 Node.js 官網下載新的 LTS 版，直接安裝就會蓋過去。

**Q：公司電腦跳出「已被系統管理員封鎖」或裝不起來？**
公司的 IT 政策可能禁止安裝軟體。請用個人電腦，或詢問公司 IT。**不要自己想辦法繞過公司的限制。**

**Q：授權碼貼上後說無效或過期？**
授權碼只能用一次，放太久也會失效。按 `Ctrl + C` 離開，重新打 `agy` 再登入一次，拿到新的授權碼後馬上貼回來。

**Q：登入方式選到 `2. Use a Google Cloud project` 了？**
按 `Ctrl + C` 離開，重新打 `agy`，這次選 `1. Google OAuth`。已經登入成功的話，先打 `/logout` 登出再重來。

**Q：登入時說「帳號不適用」或「無法使用此服務」？**
通常是用了公司或學校的帳號。請改用個人 Gmail 帳號：先打 `/logout` 登出，再打 `agy` 重新登入。

**Q：`/usage` 裡怎麼也有 Claude 和 GPT？可以用嗎？**
可以。Antigravity 的免費方案也提供 Anthropic 的 Claude、OpenAI 的 GPT-OSS，而且跟 Gemini 是**分開的兩份額度**。本課程用預設的 Gemini Flash 就夠了；如果 Gemini 那組的額度用完、又還沒重置，可以打 `/model` 換成另一組的模型繼續做。不管用哪一家的模型，L0-1 講的資料規則都一樣：不要放機密。

**Q：它要怎麼更新？**
它會在背景自己更新，不用管。

**Q：`agy` 是什麼的縮寫？**
Antigravity（反重力），Google 這套工具的名字。

**Q：我以前聽說 Gemini CLI 用 Google 帳號就能免費用？**
那是舊的做法。Google 在 2026 年 6 月 18 日停止讓個人免費帳號用 Gemini CLI，改由 Antigravity CLI 接手。所以本課程改教 Antigravity CLI。

# L1・到職篇｜學員手冊

## 替自己招一位 AI 秘書

> 你不用會寫程式。你要做的事，跟招一位新秘書差不多：先面談、幫他辦報到、讓他試用、合格了再轉正。
> 真正動手寫程式的，是你交給他的那份《施工工單》。

---

## 這堂課結束，你會有什麼

一位住在你電腦裡的 AI 秘書，你可以隨時用手機的 Telegram 找他：

```text
你       09:12  你是誰？
Melo     09:12  我是 Melo，小安的私人秘書。有事交代就說，我會盡量一次講清楚。

你       09:13  記下來：我每週一早上九點開部門會議
Melo     09:13  好，已經記在我的人事資料裡了。下次重新上班之後就會記得。
```

他會：

- **認得你**：知道你叫什麼、做什麼工作、你在意什麼。
- **有自己的個性**：名字、說話方式、做事規矩都由你決定。
- **有辦公桌**：能在他自己的資料夾裡讀檔、寫檔、改檔、執行指令。
- **只聽你的**：別人傳訊息給他，他一律不理。
- **你說「記下來」才記**：不會自己偷偷寫筆記。

這一階段他還**不會**的事（之後的課程會教）：跨天記得你們聊過什麼、幫你看行事曆、幫你擬信、主動提醒你。

## 他在哪裡上班？

```text
   你的手機（Telegram）
          │
          │  網路
          ▼
   你的電腦  ← 秘書就在這裡上班，電腦要開著
   ├─ 人事資料：SOUL.md（他是誰）、MEMORY.md（他記得你什麼）
   ├─ 大腦：Google Gemini（透過網路呼叫）
   └─ 辦公桌：專案資料夾（他只能動這裡面的檔案）
```

不用租雲端主機，也不用固定 IP。代價是：**你的電腦要開著、不能睡眠，他才能回你訊息。**

## 第一章・招募面談

開工之前，coding agent 會先面談你八個問題。**建議你先把答案想好**，面談時直接貼上，最快。

### 面談準備表

**關於秘書本人**（會寫進 `SOUL.md`）

| # | 問題 | 你的答案 | 不回答的話 |
|---|---|---|---|
| 1 | 他叫什麼名字？ | | Melo |
| 2 | 他的職務是什麼？（例：私人秘書、業務助理、學習夥伴） | | 私人秘書 |
| 3 | 他的個性和說話方式？（例：簡潔有禮、溫和耐心、輕鬆幽默） | | 簡潔直接，不繞圈 |
| 4 | 他一定要守的規矩？（例：不確定就說不確定） | | 不懂就說不懂，不胡說 |

**關於你**（會寫進 `MEMORY.md`）

| # | 問題 | 你的答案 | 不回答的話 |
|---|---|---|---|
| 5 | 他該怎麼稱呼你？ | | 你 |
| 6 | 簡單說你是誰、在做什麼？ | | （未提供） |
| 7 | 你希望他特別注意什麼？（例：一律用繁體中文、不要反問太多） | | （未提供） |
| 8 | 還有其他想讓他記住的事嗎？ | | （無） |

### 面談小提醒

- **不要寫密碼、身分證字號、銀行帳號**。這些資料會送到 Google 的伺服器。
- 答案之後都能改，不用一次寫到完美。人事資料就是兩個文字檔，用記事本打開就能編輯。
- 如果 coding agent 沒問你就自己填了名字或背景，**請叫他停下來重新問**。人事資料一定要由你決定。

## 第二章・報到準備

秘書報到前，你要幫他準備好三樣東西。

### 準備一：一台會開著的電腦

- 要有 **Node.js 22.19 以上**。沒有也沒關係，coding agent 會幫你檢查、告訴你怎麼裝。

### 準備二：大腦的通行證（Gemini API Key）

1. 前往 [Google AI Studio](https://aistudio.google.com/apikey)，用 Google 帳號登入。
2. 按「Create API key」，複製那一串金鑰。

> 🔑 **這串金鑰就像公司大小章**：誰拿到就能用你的額度。不要貼到群組、不要截圖分享。萬一外流，回到同一頁把它刪掉，再重建一把。

### 準備三：秘書的手機號碼（Telegram Bot）

1. 在 Telegram 搜尋 **`@BotFather`**，傳 `/newbot`，照指示幫秘書取名。
2. 最後會拿到一串 **Token**（長得像 `1234567890:AAxxxx...`），複製下來。它跟金鑰一樣重要。
3. 找到你剛建立的 Bot，**按 Start，再隨便傳一句話**（例如「hi」）。
4. 查出**你自己的 User ID**。這是秘書用來認主人的號碼。打開 Windows PowerShell，把下面這一整行的 `你的Token` 換成真的 Token，**整行貼上**，按 Enter：

   ```powershell
   $token = "你的Token"; (Invoke-RestMethod "https://api.telegram.org/bot$token/getUpdates").result | ForEach-Object { [PSCustomObject]@{ Id = $_.message.from.id; Name = $_.message.from.first_name } }
   ```

   畫面會出現一串數字，那就是你的 User ID。
   - **什麼都沒出現？** 代表第 3 步還沒做。回 Telegram 對 Bot 傳一句話，再執行一次。

### 準備四：一位施工人員（coding agent）

任選一個你用得順手的：Claude Code、Codex、Gemini CLI、Cursor 都可以。它負責照《施工工單》把程式寫好、測好。

## 第三章・到職手續

### 步驟 1：把工單交出去

**先進到秘書的資料夾，再打開 coding agent。** 在資料夾外面打開的話，它建的每個檔都算「工作區之外」，每一步都會多問你一次。

1. 照 L0-2 的做法，在家目錄建一個空的資料夾 `ai-secretary`（秘書的辦公室）。
2. 把《L1_到職篇_施工工單.md》複製進去。
3. 在 PowerShell 用 `cd` 進到 `ai-secretary`，再打開 coding agent（例如打 `agy`），跟它說：

> 請照 L1_到職篇_施工工單.md 幫我建置。

施工到最後，它會執行一次 `node self-check.mjs`（工程自檢，大約 2 分鐘，全部用假金鑰，不會動到你的 `.env`）。問你要不要允許時，這一行可以放心允許。

### 步驟 2：接受面談

它會問你第一章那八個問題。把你準備好的答案貼上即可。

### 步驟 3：簽核《到職確認單》

面談完，它會整理一張確認單給你看，裡面有安裝位置、秘書的人設、你的資料。**確認沒錯再回「同意」**，它才會開工。

### 步驟 4：填寫通行證

施工完成後，它會請你把金鑰填進專案資料夾裡的 **`.env`** 檔：

```env
GEMINI_API_KEY=你的Gemini金鑰
TELEGRAM_BOT_TOKEN=你的BotToken
TELEGRAM_ALLOWED_USERS=你的UserID
```

> ⚠️ **一定要填在 `.env`，不是 `.env.example`**。`.env.example` 是空白範本，之後可能會被上傳到網路。`.env` 是你的私人檔案，系統設定成永遠不會上傳。兩個檔名很像，填錯檔是最常見的錯誤。

### 步驟 5：第一天上班

到專案資料夾，**雙擊 `啟動 Agent.bat`**（Mac 是 `啟動 Agent.command`）。

跳出黑色視窗，看到這兩行就是上班了：

```text
Agent 已啟動，模型 google/gemini-3.5-flash-lite（思考等級: medium），工具：…
等待 Telegram 訊息…
```

**這個視窗不要關**。關掉就是下班。

## 第四章・試用期考核

試用期用 **Gemini 免費額度**，不花一毛錢。請逐項考核，全部通過才轉正。

| # | 考核項目 | 怎麼考 | 合格標準 |
|---|---|---|---|
| 1 | 認得自己 | 傳「你是誰？」 | 名字、職務、個性跟面談的答案一致 |
| 2 | 認得老闆 | 傳「我是誰？」 | 稱呼、背景、注意事項跟面談的答案一致 |
| 3 | 會看文件 | 傳「把 SOUL.md 第一行唸給我」 | 內容跟檔案一致 |
| 4 | 交代的事會記 | 傳「記下來：我週三晚上不回訊息」→ **關掉黑視窗、重新雙擊啟動** → 傳「我週三晚上怎樣？」 | 重新上班後答得出來 |
| 5 | 不會自作主張 | 隨便聊幾句，**不要**說「記下來」 | 打開 `MEMORY.md`，內容沒被改動 |
| 6 | 只聽老闆的 | 用另一個 Telegram 帳號傳訊息給他 | 完全沒回應；黑視窗印出「忽略非白名單使用者」 |
| 7 | 看得出他在忙 | 傳「幫我寫一段 300 字的自我介紹」 | 回覆出來之前，對話視窗上方顯示「輸入中…」 |

### 試用期的額度限制

免費額度大約是**每分鐘 15 次、每天 500 次**請求（實際數字以 [Google 官方公告](https://ai.google.dev/gemini-api/docs/rate-limits)為準）。

- 一個人正常聊天，每分鐘 15 次很難撞到。
- 撞到時系統會**自動等一下再重試**，大部分時候你不會發現。
- 真的超過時，他會回你「額度或速率上限可能已到」。這不是壞掉，是試用期的限制。

**建議試用 3 到 7 天**，用你平常的節奏跟他相處，確定他適合你再轉正。

## 第五章・轉正

### 什麼時候該轉正？

- 六項考核都通過了，**而且**
- 你開始常常看到「額度已到」的訊息，或你打算每天靠他辦事。

### 轉正手續

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 開通計費（綁信用卡）。
2. **馬上設定預算上限和用量警示**（例如每月 5 美元），這樣帳單不會失控。
3. 完成。**程式、`.env`、金鑰通通不用改**，同一把金鑰的額度會自動提高。

### 轉正後要花多少錢？

Gemini 3.5 Flash-Lite 大約是每百萬輸入 token 0.3 美元、每百萬輸出 token 2.5 美元。一個人日常使用，一個月大約是幾十元台幣的等級。實際費用看你的使用量，以 Google 帳單為準。

### 資料隱私也會不一樣

依 Google 的條款，免費層的對話內容**可能**被用來改善 Google 的產品，付費層則不會（以 Google 最新條款為準）。如果你會跟秘書討論公司業務，轉正也是保護資料的一步。

## 第六章・日常管理

### 上下班

| 動作 | 怎麼做 |
|---|---|
| 上班 | 雙擊 `啟動 Agent.bat` |
| 下班 | 關掉黑色視窗，或在視窗裡按 `Ctrl + C` |
| 重新上班（重啟） | 先下班，再上班 |

**同一時間只能開一個黑視窗。** 開兩個會互搶訊息，視窗裡會出現 `Conflict` 錯誤。

### 什麼時候要重啟？

秘書是在**上班那一刻**讀人事資料的，所以下面這些情況都要重啟：

- 你叫他「記下來」之後
- 你自己打開 `SOUL.md` 或 `MEMORY.md` 改了內容之後

### 修改人事資料

用記事本打開專案資料夾裡的：

- **`SOUL.md`**：他是誰（名字、職務、個性、規矩）
- **`MEMORY.md`**：他記得你什麼

改完存檔、重啟，就生效了。**章節標題不要刪**，只改內容。

### 讓他只聽你的

程式裡已經有白名單，只有 `.env` 裡的 User ID 能跟他說話。建議在 Telegram 平台上再多鎖一道：

1. 對 `@BotFather` 傳 `/setjoingroups`，選你的 Bot，選 **Disable**（不能被拉進群組）。
2. 傳 `/setprivacy`，選你的 Bot，選 **Enable**。
3. **不要公開你的 Bot 帳號名稱。**

> 為什麼這麼重要？他能在你電腦上執行指令。能跟他說話的人，某種程度上就能操作你的電腦。

### 金鑰外洩了怎麼辦？

- **Telegram Token**：對 `@BotFather` 傳 `/revoke`，選你的 Bot，拿新 Token 換進 `.env`，重啟。
- **Gemini 金鑰**：到 AI Studio 刪掉舊金鑰、建新的，換進 `.env`，重啟。

## 附錄 A・員工手冊 Q&A

這些都是實際建置時真的遇過的狀況。

**Q：PowerShell 查 User ID 時出現紅字「未預期的 '(' 語彙基元」？**
你貼的指令有兩行，但中間的換行不見了，兩行黏在一起。請用第二章那個**有分號的單行版本**，整行貼上。

**Q：啟動時說「找不到 GEMINI_API_KEY」或「.env: not found」？**
你可能把金鑰填進了 `.env.example`。請確認資料夾裡有一個叫 **`.env`** 的檔案，金鑰要填在那裡。

**Q：黑視窗一直跳「Conflict: terminated by other getUpdates request」？**
有兩個秘書同時在上班。把所有黑視窗都關掉，只開一個。

**Q：雙擊 `啟動 Agent.bat` 後視窗一閃就不見？**
通常是這個檔案被人用記事本改過，存成含中文的格式。請從原始專案重新取得這個檔案，不要修改它。

**Q：他回「額度或速率上限可能已到」？**
試用期的免費額度到了。等一分鐘再試；如果常常發生，請看第五章轉正。

**Q：手機傳訊息，他都不回？**
依序檢查：① 電腦是不是睡著了？② 黑視窗還開著嗎？③ 黑視窗有沒有紅字錯誤？

**Q：黑視窗偶爾出現「輪詢錯誤：fetch failed」？**
網路短暫不穩，不用管，程式會自己重試。他做完的回覆如果剛好送不出去，會先存著，網路恢復後補送，開頭會寫「（剛才網路斷線，這是補送的回覆）」。一直出現才需要檢查網路。

**Q：他偶爾要等一兩分鐘才回？**
只要上方有顯示「輸入中…」，就是他還在做事，不用一直追問。網路不穩時，他送給 Gemini 的請求可能斷掉；程式等 90 秒沒有回應就會自動重連，所以最多慢一兩分鐘。追問的訊息會排在後面，等他做完再一則一則回。

**Q：筆電闔上就不回了？**
Windows 到「電源選項」把「闔上蓋子時」改成「不執行任何動作」。Mac 的做法會在 macOS 驗證完成後補上。

**Q：他忘了剛剛聊過的事？**
重啟過就會忘，這是 L1 的設計。他只記得人事資料裡寫的東西。跨天的記憶在 L2 教。

## 附錄 B・職涯發展預告

這位秘書會跟著你一路升級，**人事資料（`SOUL.md`／`MEMORY.md`）會一直沿用**，不用每上一課就重新招一個人。

| 課程 | 他的成長 | 學到什麼 |
|---|---|---|
| **L1・到職**（本課） | 報到、試用、轉正 | 有個性、認得你、只聽你的 |
| **L2・在職訓練**（六堂課） | 記性變好、學會專業技能 | 重啟不失憶、跨天記得聊過的事、每天整理工作日誌、專業技能包、叫得停、學會你的做法 |
| **L3・授權配發** | 拿到公司信箱與行事曆的權限 | 串接 Google 行事曆、Gmail；**核決權限**分三級：查閱／擬稿／執行 |
| **L4・主動工作** | 每天早上主動報告 | 晨間簡報、會議前提醒、固定排程 |
| **L5・組建團隊** | 帶出一整個助理團隊 | 業務、研發、廠務各有專屬助理，分工合作 |

### L2 在職訓練的七堂課

| 課程 | 他學會什麼 |
|---|---|
| L2-1・記性 | 重啟不失憶、知道現在幾點 |
| L2-2・辦公桌 | 產出的文件放進 `文件/`、找得到、看不懂語音會說 |
| L2-3・工作日誌 | 每天寫工作日誌、隔天記得、待辦不會亂 |
| L2-4・專業培訓 | 會議紀錄、行程規劃、週報，照固定做法產出 |
| L2-5・緊急停止 | 做到一半，傳 `/stop` 就停 |
| L2-6・自己寫 SOP | 把你自己的工作流程教給他 |
| L2-7・存檔與備份 | 你教他的一切存成版本、備份到 GitHub 私人倉庫，L2 結業 |

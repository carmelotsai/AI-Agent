# L4-2・晨間簡報｜學員手冊

## 讓他到時間自己「做事」，不只是傳話

> L4-1 的提醒，時間到只是把你說過的那句話傳給你——那是程式發的，他本人沒有參與。
> 這一課不一樣：時間到，**他真的會動手**。每天早上七點半，他自己查行程、看提醒、翻日誌，整理成一則晨報傳給你。你還沒起床，簡報已經在手機上了。

---

## 這堂課結束，你會有什麼

```text
Melo     07:30  ☀️ 早安！今天是 10/13（二）

                🗓 今天的行程
                - 10:00–11:00 研發週會（3 樓會議室）
                - 15:00–15:30 牙醫

                ⏰ 今天的提醒
                - 14:00 打給王經理

                📝 還沒完成的事
                - 確認三家供應商的交期（對方說明天回覆）
                - 更新上個月的報價單

                🕗 例行工作：晨報（每個工作日 07:30）

你       08:10  第二件幫我擬一封信催一下
Melo     08:10  好，我看一下上次的報價單…
```

最後那行 `🕗 例行工作：晨報` 是**程式**加的，不是他寫的——讓你一眼看出這則不是你問出來的，是他自己做的。

秘書學會：

- **例行工作**：到時間把一件事交給他做。晨報只是第一個例子。
- **安靜時段**：半夜和午休不吵你，時間到的工作延到時段結束。
- **錯過會補**：早上的工作沒做到（電腦沒開），中午前開機就補做；過了中午不補，但會跟你說一聲。
- **`/run 晨報`**：想現在就看一次，或補跑錯過的。

---

## 例行工作 vs 提醒

這兩個很像，但差很多：

| | 提醒（L4-1） | 例行工作（這一課） |
|---|---|---|
| 時間到發生什麼 | 程式把你說的那句話傳給你 | **把一段指令交給他，他動手去做** |
| 會用工具嗎 | 不會 | 會（查行事曆、讀日誌、寫文件） |
| 會花 API 額度嗎 | 不會 | 會 |
| 內容 | 一字不差 | 他自己寫的，每天不一樣 |
| 誰能新增 | 你說一句就好 | 你說一句，**還要按一次確認鈕** |

為什麼例行工作要多按一次？因為它會在**沒人看著的時候**呼叫 AI、使用工具。多一道確認，你才知道自己排了什麼給他做。

---

## 沒人看著的時候，他能做什麼

這是這一課最重要的安全設計。

例行工作執行時你可能在睡覺。所以程式在那段時間**把「執行級」的工具整個藏起來**——不是「跳按鈕問你」，是連看都看不到：

| 他**可以** | 他**不行** |
|---|---|
| 查行事曆、讀信、查地圖、讀日誌 | 寄信 |
| 寫檔案到 `文件/` | 跑電腦指令 |
| 建 Gmail 草稿 | 新增、修改、刪除行事曆 |
| | 改技能、改人事資料 |

> 為什麼是「藏起來」而不是「擋下來」：測試時發現，如果工具還看得到、只是被擋，他會一直去試，被擋幾次之後就整件事放棄，晨報也寫不出來。直接藏掉，他就會用現有的工具把事情做完。

所以你**不能**排一個「每天早上自動把報價單寄給客戶」的例行工作。他會跟你說做不到，並建議改成「擬好草稿，你回來按送出」。

---

## 安靜時段

預設兩段：**22:00–07:00**（晚上）、**12:00–13:00**（午休）。

時間到的例行工作如果落在裡面，會**延到時段結束才做**，不會把你吵醒。想改時段，跟他說「午休改成 12:30 到 13:30」，或直接編輯 `排程.json`。

---

## 錯過了怎麼辦

電腦關機、睡著，到時間的例行工作就沒人做。規則是：

| 情況 | 結果 |
|---|---|
| 早上的工作，**中午前**開機 | 自動補做，訊息會寫「原定 07:30，晚了 N 分鐘補做」 |
| 早上的工作，**過了中午**才開機 | **不補做**，傳一則「🕗 … 沒有做：那時秘書沒有在執行，過了中午就不補。要看的話傳 /run 晨報」 |
| 下午的工作，當天還沒過 | 補做 |
| 落在安靜時段的工作 | 延到時段結束才做，訊息寫「安靜時段結束後做」 |

為什麼過了中午不補？因為中午才收到「早安」沒有意義。他會告訴你錯過了，你想看再用 `/run` 叫出來。

### 國定假日不做

**國定假日和補假整天不做例行工作，也不會補**。週末也是（「每個工作日」本來就不含週末）。假日表會自動從 Google 的台灣假日行事曆抓，不用你維護。

只有寫「每天 HH:mm」的例外——你說「每天」就是每天，假日照做。

## 怎麼設定晨報

跟他說就好：

> 每個工作日早上七點半給我晨報

他會跳一個確認鈕，上面寫清楚要排什麼、下次什麼時候：

```text
新增例行工作：晨報
時間：每個工作日 07:30（下次 10/13（二）07:30）
要他做的事：照 morning-brief 技能寫今天的晨報
```

按「執行」就設好了。想改時間說「晨報改成八點」，想停掉說「停掉晨報」——改時間只要按一次鈕，不用先刪再加。

---

## 這一課他還不會的事

- **晨報裡的「要注意的信」**：現在晨報只有三段（行程、提醒、還沒完成的事）。新信通知是 **L4-3**。
- **晨報裡的「產業消息」**：**L4-4**。
- **開會前提醒**：**L4-3**。
- **到時間寄信、跑指令**：不做，而且以後也不會做。沒人看著時不能做會影響外界的事。

## 上課步驟

### 步驟 1：把工單交出去

把**《L4-2_晨間簡報_施工工單.md》整份**交給 coding agent，說：

> 請照這份施工工單，幫我把秘書升級到 L4-2。

> 💾 **交工單之前**，先跟 coding agent 說「先跑 `q-backup.mjs` 檢查，再幫我存一版並備份：L4-2 升級前」。驗收通過後再存一版「L4-2 完成」。

這一課**改主程式、新增 `外掛/例行工作/`與晨報技能**，人事資料、日誌都不動。測試不需要你的金鑰。

### 步驟 2：重新上班

關掉舊的黑視窗，重新雙擊 `啟動 Agent.bat`。工具那一行會多四個，外掛那一行多「例行工作」，技能那一行多 `morning-brief`：

```text
Agent 已啟動，模型 …，工具：…, add_routine, update_routine, remove_routine, list_routines
技能：…, morning-brief
外掛：…, 例行工作, 提醒
```

### 步驟 3：設定晨報

跟他說「每個工作日早上七點半給我晨報」，按確認鈕。

> ⚠️ **從現在開始，同一個資料夾只能開一個秘書。** 開兩個會互搶 Telegram 訊息，提醒和晨報都會做兩次。程式會自動擋：第二個啟動時會說「這個資料夾已經有一個秘書在跑了」然後結束。

### 一次測完的順序

T4-2-01 ～ T4-2-07 大約 10 分鐘。T4-2-08 要多等五分鐘，建議最後做。

**判斷方式**：`/run 晨報` 收得到、內容是今天、改時間只按一次鈕、要求寄信被擋下——四件都對就合格了。

## 日常管理

### 想加別的例行工作

跟他說就好，例如「每週五下午五點整理一份本週工作摘要」。他會跳確認鈕。

記住兩個限制：**不能做執行級的事**（寄信、跑指令），**不能是「只傳一句話」**（那個用提醒就好，不用花 API 額度）。

### 想暫時停掉

說「停掉晨報」。想回來再說一次「每個工作日早上七點半給我晨報」。

### 想自己改設定

`排程.json` 看得懂、改得動，改完**不用重啟**：

```json
{
  "安靜時段": ["22:00-07:00", "12:00-13:00"],
  "例行工作": [
    { "名稱": "晨報", "時間": "每個工作日 07:30", "要他做的事": "照 morning-brief 技能寫今天的晨報" }
  ]
}
```

時間只能寫四種：`每天 HH:mm`、`每個工作日 HH:mm`、`每週一 HH:mm`（一～日）、`每月N日 HH:mm`。

### 想改晨報的格式

晨報長什麼樣子寫在 `.pi/skills/morning-brief/SKILL.md`，那是純文字，你自己改得動（L2-6 教過）。例如不想看提醒那段，就把那一段刪掉。

## 附錄・Q&A

**Q：早上七點半沒收到晨報？**
照順序看：電腦開著嗎？黑視窗還在嗎？是國定假日或週末嗎？都不是的話傳 `/run 晨報` 看會不會動，不動就看黑視窗有沒有錯誤訊息。

**Q：晨報寫成明天的日期？**
程式會在指令開頭寫明今天是哪天，所以不該發生。真的發生請截圖給 coding agent。

**Q：晨報說「（沒有連上行事曆）」？**
L3-5 的行事曆授權過期了，重跑一次授權。

**Q：我在晨報下面追問，他接得上嗎？**
接得上。晨報跟你平常的對話是同一本，他記得剛剛寫了什麼。

**Q：例行工作會不會跟我正在講的話撞在一起？**
不會。例行工作跟你的訊息排同一個隊，一次只做一件。你正在問問題時，晨報會等你這件做完再做。

**Q：為什麼他做例行工作時，`/status` 看到的工具比較少？**
那是刻意的——執行級的工具在例行工作期間被藏起來了。做完就還原。

**Q：`/run` 和等時間到有什麼不同？**
沒有。`/run` 就是「現在立刻跑一次」，做的事一模一樣。

**Q：改了 `排程.json` 沒效果？**
格式可能壞了。看黑視窗有沒有「排程.json 讀不懂」。程式不會覆蓋壞掉的檔案，修好就會自己恢復。

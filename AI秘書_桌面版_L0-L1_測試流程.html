桌面版實測 L0～L1

通過 0・失敗 0・略過 0・未測 0

測試前準備

這份流程是把 L0～L1 的 CLI 版手冊，改成用 Antigravity 桌面 App 走一遍。目的是回答總路線圖第 8 節 #12：新手路線要用 CLI 還是桌面版。

每一課都有一張檢查表，以及「花幾分鐘、權限確認幾次、卡住幾次」三個計數。結果會自動存在這個瀏覽器裡，做完按右上角「匯出結果」，把文字貼給 Claude。

三條規則

  1. Security Preset 維持 Default。不要選 Full machine 或 Turbo mode。
  2. 權限詢問先看再按。預設選「1. Yes, allow this time」，看不懂就選「5. No」先問它。
  3. 金鑰、Token 不貼進對話框。只用記事本填進 .env。

跟 CLI 版不一樣的地方（L0-1 測試已確認）

動作CLI 版桌面版（Default）
工作資料夾裡寫檔、改檔事前問不問，事後有「N file changed」和 Review
執行指令事前問，4 個選項事前問，5 個選項（這次／這段對話／這個專案／全部／No）
工作資料夾以外的檔案事前問事前問（這次要驗證）
工作現場打 agy 時所在的資料夾上方顯示的 Project

這次用新的資料夾和 Bot

  • ~\ai-practice 裡已經有 CLI 版做出來的 待辦.md、夜市.md、會議紀錄。這次 L0 改用新的資料夾 ai-practice-app，比較才公平。
  • L1 用新的資料夾 ai-secretary-app。
  • 你電腦上已經有秘書（gemini-pi-agent、my-agent）。L1 測試另外開一個測試用的 Telegram Bot，不然兩個秘書會互搶訊息（Conflict）。

L0-2・資料夾（不用 PowerShell 版）

CLI 版這一課教 PowerShell。桌面版要測的是：完全不碰 PowerShell，新手能不能把工作現場準備好？

步驟 1：用檔案總管建資料夾

  1. 開檔案總管，點一下上方的網址列（顯示目前位置的那一長條），整條會變成可以打字。
  2. 打 %USERPROFILE%，按 Enter。就會跳到你的家目錄，資料夾名稱是你電腦的使用者名稱，每個人都不一樣。
  3. 空白處按右鍵 →「新增」→「資料夾」，取名 ai-practice-app。
⌨️ 貼到檔案總管的網址列
%USERPROFILE%
記下來：網址列要先點一下才能打字，使用者找不找得到？%USERPROFILE% 前後的 % 會不會漏打？

步驟 2：用記事本建 hello.txt

  1. 進到 ai-practice-app，空白處按右鍵 →「新增」→「文字文件」，取名時只打 hello，按 Enter。
  2. 雙擊打開，打「你好」，存檔、關掉。
Windows 預設會隱藏副檔名 .txt，所以畫面上只會看到 hello，實際檔名是 hello.txt。如果取名時打了 hello.txt，實際會變成 hello.txt.txt，agent 就找不到。這也是教材要寫的坑。

步驟 3：在 App 加入專案

  1. Antigravity App 左邊 Projects 旁的資料夾＋號圖示 → 選 ai-practice-app。
  2. 從專案裡開對話：滑鼠移到左邊的 ai-practice-app 上，右邊會出現「＋」（提示文字「New Conversation in Project」），按它開新對話。不要用左上角的「New Conversation」，那個會開在專案外面。
  3. 確認上方標題是「ai-practice-app / …」，左邊這段對話列在 ai-practice-app 底下，不在「Conversations」區。

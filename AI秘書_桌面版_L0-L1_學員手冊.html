L0-1・基本概念

招聘準備第一課：先搞懂你要招的是什麼人

從 L1 開始，你會招一位 AI 秘書。但秘書的辦公室要有人幫你裝潢：這個人叫 coding agent，本課程叫他「施工人員」。招人之前，先把幾個名詞搞懂。這一課不用動手，也不用裝任何東西。

一、聊天機器人 vs. Agent

聊天機器人（例如網頁版 Gemini、ChatGPT）Agent
比喻電話諮詢的顧問：你問，他答到府施工的師傅：你交代，他動手做
看得到什麼只看得到你貼給他的東西可以自己打開你電腦裡的檔案
做完的東西一段文字，你自己複製、自己存檔直接幫你寫進檔案
做事方式一問一答自己拆步驟、一步一步做，做完回報

Agent 能自己動手，靠的是工具：讀檔、寫檔、執行指令、上網查資料。有工具，它就從「會說」變成「會做」。

二、施工人員和秘書

施工人員（coding agent）秘書（L1 開始招）
住在哪裡你電腦上的 Antigravity 桌面 App你電腦上，透過手機 Telegram 找他
負責什麼照《施工工單》幫你把秘書蓋好、升級每天幫你辦事：會議紀錄、週報、行程……

L0 的目標，就是讓你有一位會用的施工人員。之後每一課，你都是把一份工單交給他，他照著做。

三、token、上下文、額度

  • token：模型計算文字的單位。中文大約一個字算一個 token 上下。你打的字、它讀的檔案、它回的話，全部都算。
  • 上下文：它這一次對話能同時記住的份量，像一張工作桌面。對話越長、讀的檔案越多，桌面越滿，前面的事就容易漏掉。所以換一件事做，就開一段新的對話（L0-4 教）。
意思比喻
額度一段時間內總共能用多少每個月的手機流量
速率限制一分鐘內不能問太多次櫃台一次只能服務幾個人

免費方案兩種都有上限。看到「額度已到」「rate limit」，不是壞掉，是用到上限了：等一下再試，或等額度重置。

四、帳號登入 vs. API Key

帳號登入API Key
比喻本人刷員工證進門公司大小章：誰拿到誰就能用
給誰用人坐在電腦前操作的工具程式自己在背景呼叫
本課程誰用施工人員（L0-3 用 Google 帳號登入）秘書（L0-5 申請，L1 填進設定檔）

API Key 外流，別人就能用你的額度。所以不要貼進任何對話框（包括施工人員的）、不要截圖、不要傳到群組，只放進 L1 會教的 .env 設定檔。

五、權限：它什麼時候會先問你

Agent 能動你的電腦，所以有些事會先問你。在 Antigravity 桌面 App 的預設設定（Default）下：

它要做的事會不會先問風險
讀工作資料夾裡的檔案不問低；但內容會送到雲端
建立、修改工作資料夾裡的檔案不問，做完才顯示改了什麼中；可能改壞你的檔案
讀寫工作資料夾外的檔案會問中
執行指令會問高；指令可以做幾乎任何事

本課程的原則是「先擋得住，再放手」：

  1. 工作資料夾只放練習用的東西。它在裡面寫檔、改檔不會先問你，所以重要的檔案不要放進去，要練習就先複製一份。
  2. 它要執行指令時，先看一眼再允許。看不懂就先問它「這是在做什麼」。
  3. 做完自己檢查。它說做好了，自己打開檔案確認。
  4. 不要開「全部自動允許」（App 裡叫 Turbo mode）。網路教學常教這招來省事，本課程不用。

秘書也一樣：L2-5 會教你叫他停下來，L3-2 會幫他設好「哪些事只能看、哪些要先問你」。

六、你的資料會送到哪裡

Agent 的「大腦」是雲端上的模型。你打的每一個字、它讀的每一份檔案，都會送到 Google 的伺服器。

  • 依 Google 目前的條款，免費方案的內容可能被用來改善 Google 的產品，也可能有人工審閱。秘書用的 API Key 要開通付費才不會被拿去用（L1 第五章「轉正」）。
  • 所以練習時不要放公司機密、客戶資料、密碼、身分證字號。
  • 練習用的檔案放在獨立的資料夾（L0-2 建），不要讓它碰你其他的資料。

結訓考核

用自己的話回答，講得出來就算通過。

L0-2・練習資料夾

招聘準備第二課：找到家目錄，建一個給施工人員的資料夾

施工人員只在一個資料夾裡工作，本課程叫它「工作資料夾」。這一課用檔案總管，在你的家目錄裡建一個練習用的工作資料夾 ai-practice，並且學會在任何視窗裡都找得到它。

一、家目錄在哪裡

每個人的電腦都有一個家目錄，就是你的個人資料夾，「文件」「下載」「桌面」都在它裡面。我們一層一層點進去找它：

  1. 打開檔案總管（工作列上的黃色資料夾圖示，或按鍵盤 Windows 鍵 + E）。
  2. 左邊往下找到「本機」，點它。
  3. 右邊會出現你的磁碟。雙擊名字後面有 (C:) 的那一個。名字每台電腦不一樣，例如「本機磁碟 (C:)」「OS (C:)」。
  4. 雙擊「使用者」資料夾。
  5. 裡面有幾個資料夾，雙擊你自己的那一個。名字通常是你登入 Windows 時的名字或它的縮寫（不是「公用」「Public」）。

現在你就在家目錄裡了，會看到「文件」「下載」「桌面」等資料夾。

網址列：資料夾的完整地址

檔案總管上方那一長條叫網址列。它平常顯示的是好讀的名字，例如「本機 > 你的名字」，有時候顯示的是你的帳號名稱，不一定等於資料夾真正的名字。例如手冊作者的電腦，網址列顯示「Carmelo Tsai」，資料夾真正的名字卻是 carme。

點一下網址列，它會變成資料夾真正的完整地址：

👀 點一下網址列後會顯示（這是手冊作者的電腦；你的最後一段會是你自己的資料夾名稱）
C:\Users\carme
網址列裡的意思
C:C 槽，就是剛剛那個名字後面有 (C:) 的磁碟
Users就是「使用者」資料夾。畫面上顯示中文，完整地址裡是英文，是同一個資料夾
carme家目錄真正的名字。這裡是手冊作者的，你的會不一樣
為什麼作者的資料夾叫 carme，不是完整的名字？安裝 Windows 時用微軟帳號（Email）登入的話，Windows 會拿 Email 的前 5 個字元當資料夾名稱。所以你的家目錄名稱可能是被截斷的、看起來很怪，這很正常。

像這樣一層一層用 \ 隔開的完整地址，叫做路徑。按 Esc 可以讓網址列變回原本的樣子。

二、建立練習資料夾

  1. 在家目錄的空白處按滑鼠右鍵 →「新增」→「資料夾」。
  2. 取名 ai-practice，按 Enter。

釘選起來，以後在哪裡都找得到

  1. 對 ai-practice 按滑鼠右鍵 →「釘選到 [快速存取]」。
  2. 檔案總管左邊「常用」那一區就會出現 ai-practice。

之後不管是檔案總管，還是 App 跳出來的「選資料夾」視窗，左邊的「常用」都會有它，點一下就到了。

為什麼放在家目錄，不放桌面或「文件」？

  • 獨立的資料夾最安全：施工人員可以自由讀寫它的工作資料夾，放在獨立的地方，它就碰不到你其他的檔案。
  • 很多電腦的桌面和「文件」有 OneDrive 同步，路徑會變得很長，還可能跟雲端同步打架。放在家目錄下最單純。

三、在資料夾裡建一個檔案

  1. 雙擊進到 ai-practice。
  2. 空白處按右鍵 →「新增」→「文字文件」。
  3. 取名時只打 hello，按 Enter。
  4. 雙擊打開，打「你好」，存檔（Ctrl + S），關掉記事本。
不要打成 hello.txt。Windows 預設會把檔名後面的 .txt（副檔名）藏起來，所以畫面上只看到 hello，實際檔名是 hello.txt。如果你取名時打了 hello.txt，實際會變成 hello.txt.txt，施工人員就找不到。

四、兩個小技巧

直接跳到家目錄

熟悉家目錄在哪之後，可以用這個捷徑：點一下網址列，貼上下面這串，按 Enter，就會直接跳到你的家目錄。

⌨️ 貼到檔案總管的網址列
%USERPROFILE%

複製檔案的完整路徑

對檔案或資料夾按右鍵 →「複製路徑」（或選起來按 Ctrl + Shift + C），就會複製它的完整地址。要告訴施工人員某個檔案在哪裡時很好用。

看懂「按鍵組合」的寫法

手冊裡寫 Ctrl + S、Windows 鍵 + E，意思是按住前面那個鍵，再按後面那個鍵，然後一起放開。不是把這幾個字打出來。

L0-3・裝好你的施工人員

招聘準備第三課：安裝 Node.js 與 Antigravity 桌面 App

Node.js 是秘書上班要用的工作環境（L1 會用到），Antigravity 桌面 App 就是你的施工人員。

開始前準備

  • 一個個人 Google 帳號（Gmail）。公司或學校的帳號常會被擋，請用個人的。
  • 年滿 18 歲（Google 的規定）。
  • L0-2 建好的 ai-practice 資料夾。

步驟 1：安裝 Node.js

  1. 前往 Node.js 官網，下載標示 LTS 的版本（長期支援版，最穩定）。Windows 選 Windows Installer (.msi)。
  2. 雙擊下載的檔案，一路按 Next，保留所有預設值：
    • 授權條款頁要勾「I accept」才能繼續。
    • 看到「Tools for Native Modules」的勾選框，不用勾。
    • Windows 跳出「是否允許此 App 變更你的裝置？」時，按「是」。
  3. 按 Finish 完成。裝得對不對，步驟 5 會請施工人員幫你檢查。

步驟 2：安裝 Antigravity 桌面 App

  1. 前往 Antigravity 下載頁，下載 Windows 版的安裝檔。
  2. 雙擊安裝檔，照畫面完成安裝。
  3. 打開 Antigravity，照畫面用個人 Google 帳號登入（會開瀏覽器讓你授權）。
如果出現設定精靈（選模式、主題等），可以按 Not now 跳過。下一步會直接到設定裡檢查最重要的幾項。

右上角有一個「Install IDE」按鈕，那是給寫程式的人用的編輯器，本課程不用裝。

步驟 3：檢查安全設定

按左下角的 Settings（齒輪圖示）。

在哪裡設定要是什麼

GeneralPlan Review PolicyAlways Ask
General → Tool PermissionsFile Access Rules、Terminal Commands清單是空的（不用新增任何東西）
ApplicationEnable Remote Control關閉（從別的裝置遙控，用不到）

步驟 4：把 ai-practice 加進 Projects 清單

你要告訴 App：施工人員的工作資料夾是哪一個。App 畫面上的英文 project，指的就是工作資料夾；你加進來的工作資料夾，都會列在左邊的 Projects 清單。

  1. 左邊「Projects」這幾個字的右邊，有一個資料夾＋號的圖示，按下去。
  2. 會跳出一個標題是 Open workspace 的選資料夾視窗。它一開始可能停在「下載」或別的地方，不用管。
  3. 在視窗左邊的「常用」點 ai-practice（L0-2 釘選過的）。沒有的話，照 L0-2 的方法從左邊「本機」→ (C:) 的磁碟 →「使用者」→ 你的資料夾，一層一層找到它，點一下。
  4. 按「選擇資料夾」。
  5. Projects 清單裡出現 ai-practice，就加好了。

步驟 5：第一次上工

開對話一定要從工作資料夾開：滑鼠移到 Projects 清單裡的 ai-practice 上，右邊會出現「＋」（提示文字 New Conversation in Project，意思是「在這個工作資料夾開新對話」），按它。

⚠️ 不要用左上角的「New Conversation」。那個會開在工作資料夾外面，施工人員會跑到另一個暫存資料夾工作，找不到你的檔案。
怎麼確認開對了：對話上方的標題開頭是「ai-practice /」，左邊這段對話列在 ai-practice 底下。

Q&A

Q：登入時說帳號不能用？
通常是公司或學校的帳號。請改用個人 Gmail。

Q：可以換別的模型嗎？
可以，用對話框下方的模型選單。用預設的就夠了。不管用哪一家的模型，L0-1 講的資料規則都一樣：不要放機密。

L0-4・第一次派工

招聘準備第四課：交代小事、看懂它在做什麼

這一課在 ai-practice 裡交代它幾件小事：讀檔、寫檔、改檔、跑指令。重點不是它做得多好，而是你看得懂它每一次做了什麼、問了什麼，也知道怎麼叫它停下、改回來。

上工

滑鼠移到 Projects 清單裡的 ai-practice 上，按「＋」開新對話，確認標題開頭是「ai-practice /」。

任務 1：讀檔（它不會問你）

💬 貼到 Antigravity 對話框
hello.txt 裡面寫了什麼？

它會直接打開 hello.txt，告訴你內容是「你好」。它沒有問你就讀了，因為：

📌 工作資料夾裡的檔案，它可以自由讀取。讀到的內容會送到 Google 的伺服器。不想被它看到的東西，就不要放進它工作的資料夾。

任務 2：讀資料夾外面的檔案（它會問你）

💬 貼到 Antigravity 對話框
C:\Windows\win.ini 裡面寫了什麼？

win.ini 是 Windows 內建的設定檔，沒有你的個人資料，拿來練習剛好。那是工作資料夾外面，它會先問你：

👀 畫面會顯示
Allow read access to this path?
C:\Windows\win.ini
1  Yes, allow this time
2  Yes, and always allow in this conversation
3  Yes, and always allow in this project
4  Yes, and always allow
5  No (tell the agent what to do instead)

這一次選 5. No，旁邊會出現輸入框，打「不允許」，按 Submit。它會回你「權限被拒絕，所以無法讀取」，不會想別的辦法偷偷讀。

任務 3：建立新檔（它不會問，做完給你看）

💬 貼到 Antigravity 對話框
幫我建立一個 待辦.md，列出這週三件事：交季報、訂下週出差的高鐵票、回覆客戶報價。用勾選清單的格式。

它不會先問你，直接建好，然後在回覆最下面顯示：

👀 畫面會顯示
1 file changed  +7 -0                    Review
畫面上的意思
1 file changed這一次改動了 1 個檔案
+7（綠色）新增了幾行
-0（紅色）刪除了幾行
Review打開來看改了哪些地方

按 Review，右邊會打開一個面板：上方是檔名 待辦.md，下面是內容，綠底的行就是新增的。新檔案所以整片都是綠的。

自己確認

它說寫好了，不要只相信它說的。用檔案總管打開 ai-practice，雙擊 待辦（用記事本打開即可），確認三件事都在。

用記事本打開會看到 #、-、[ ] 這些符號：這是 Markdown 格式，# 是標題、- 是清單、[ ] 是未勾選。之後秘書產出的文件大多是這種格式。

任務 4：修改檔案（看懂改了哪裡）

💬 貼到 Antigravity 對話框
幫我改 hello.txt，在最後加一行「早安」。

一樣不會先問。做完按 Review：

👀 Review 面板會顯示
hello.txt                               +2 -1
1  1  你好
   2  早安        ← 這一行反白

反白的那一行就是新加的。左邊兩排數字是修改前、修改後的行號。只要確認「它只改了你要它改的地方」就好。

改錯了怎麼辦

App 沒有「退回」按鈕。Review 只能看，不能一鍵還原。改錯的話，直接跟它說：

💬 貼到 Antigravity 對話框
剛剛那個修改不對，請把 hello.txt 改回原來的樣子。

改完再用記事本打開確認，只剩「你好」。

📌 這就是工作資料夾不能放重要檔案的原因：它在工作資料夾裡建檔、改檔不會先問你，改錯了也沒有退回按鈕，只能靠它自己改回去。重要的檔案要練習，先複製一份進來再練。

任務 5：執行指令（看不懂先問）

💬 貼到 Antigravity 對話框
用指令幫我查這個資料夾裡有哪些檔案，還有每個檔案多大。

它會停下來問你要不要執行：

👀 畫面會顯示（指令可能不太一樣）
Allow listing files in the folder?
Get-ChildItem -File | Select-Object Name, Length
1  Yes, allow this time
2  Yes, and always allow 'Get-ChildItem …' in this conversation
3  Yes, and always allow 'Get-ChildItem …' in this project
4  Yes, and always allow 'Get-ChildItem …'
5  No (tell the agent what to do instead)
畫面上的意思
第一行 Allow …?用白話說明它想做什麼
第二行它真正要執行的指令
選項意思什麼時候選
1. Yes, allow this time這一次允許✅ 看懂了、沒問題，預設選這個
2. … in this conversation這段對話裡，同樣的指令都不再問不需要
3. … in this project在這個工作資料夾裡，同樣的指令都不再問只有「只讀、不會改任何東西」而且你看得懂的指令（例如 node -v）才可以選
4. … always allow所有工作資料夾都不再問⛔ 不要選
5. No不允許，旁邊可以打字告訴它✅ 看不懂、覺得怪就選這個

練習「看不懂先問」：這一次選 5. No，在旁邊的輸入框打：

💬 貼到「No」旁邊的輸入框
先不要執行。請告訴我這一行指令在做什麼？會不會改動或刪除任何東西？

按 Submit。聽懂了，再說「好，請執行」，它再問你時選 1。

選了 No 的指令，在對話紀錄裡還是會顯示「Ran command」，看起來像執行過了。其實沒有，以你當時的選擇為準。

任務 6：叫它停下、重做

💬 貼到 Antigravity 對話框
寫一篇 2000 字的文章介紹台灣的夜市文化，存成 夜市.md。

送出後，趁它還在做的時候，按對話框右邊的停止按鈕 ■（原本是送出箭頭的位置）。它會立刻停下來。接著告訴它你要的：

💬 貼到 Antigravity 對話框
剛剛停掉了。改成 300 字就好，一樣存成 夜市.md。
狀況怎麼做
它做到一半，方向不對按 ■ 叫停，再告訴它正確的做法
它做完了，但你不滿意直接說哪裡不對，例如「太長了，縮成三段」
它改錯了檔案叫它「改回原來的樣子」，再自己打開確認

任務 7：換件事，開新對話

L0-1 說過：換一件事，就開一段新的對話（清桌面）。這個任務來體會「新對話不記得舊對話」。

第 1 步：在現在這段對話裡告訴它一件事：

💬 貼到 Antigravity 對話框
先記住一件事：我最喜歡的水果是芒果。只要記在這段對話裡，不用寫進任何檔案。

第 2 步：滑鼠移到 Projects 清單裡的 ai-practice 上，按「＋」開一段新對話，問它：

💬 貼到新對話的對話框
我最喜歡的水果是什麼？

它會說不知道，或請你告訴它。因為新對話是一張乾淨的桌面，舊對話裡講過的事都不在上面。

📌 只有寫進檔案的東西才會留下來。前面任務建的 待辦.md、夜市.md 都還在，新對話裡它也讀得到；但只在對話裡講過的事，換了對話就沒了。L1 的秘書也是這樣記事：你說「記下來」，他才會把事情寫進 MEMORY.md 這個檔案。
如果它答得出「芒果」，按 Review 看看它是不是偷偷寫進了某個檔案（那就違反了「不用寫進檔案」）。

對話框的 / 選單

在對話框打 / 會跳出一串功能。L0 都用不到，認得哪些不要碰就好：

功能意思本課程
plan先列計畫，再動手熟練以後再用
btw不打斷它的工作，順便問個問題可以用
goal一直做到目標完成為止⛔ 不要用：它停下來給你看的機會變少
schedule排程，定時自動執行⛔ 不要用：你不在電腦前它也會動手
browser叫另一個 agent 開瀏覽器上網做事⛔ 不要用

權限速查表

它想做什麼例子它會先問你嗎？你該怎麼做
看工作資料夾裡的檔案任務 1「hello.txt 裡面寫了什麼？」不會不想被看到的東西，就不要放進工作資料夾
碰工作資料夾外面的檔案任務 2「C:\Windows\win.ini 裡面寫了什麼？」會想一下它為什麼需要外面的東西；不需要就選 5. No
在工作資料夾裡建檔、改檔任務 3「幫我建立一個 待辦.md」不會，做完才顯示 1 file changed按 Review 看它改了什麼，再自己打開檔案檢查
執行指令任務 5「用指令幫我查這個資料夾裡有哪些檔案」會看得懂才選 1；看不懂就選 5. No，在旁邊直接問它

結訓考核

#考核項目怎麼考合格標準

T0-4-02改錯救得回來任務 4叫它改回去後，hello.txt 只剩「你好」

T0-4-06新對話不記得舊對話任務 7新對話答不出「芒果」；說得出「只有寫進檔案的才會留下來」

Q&A

Q：它說找不到 hello.txt，還想執行指令去搜尋？
九成是對話開在工作資料夾外面了。看標題開頭有沒有「ai-practice /」。沒有的話，這段對話不要用了，從 ai-practice 旁的「＋」重開一段。

Q：在對話框打 @，想選檔案卻只出現別的東西？
這個 App 的 @ 不能選檔案。要它讀哪個檔，直接打檔名，例如「請讀 hello.txt」。

Q：它一直用英文回答？
跟它說「以後都用繁體中文回答」。開新對話後如果又變回英文，再說一次。

Q：它的回答裡有 ** 之類的符號？
那是它的粗體格式沒有顯示好，不影響內容。

Q：對話上方的「Worked for 3m」是它做了 3 分鐘嗎？
不一定。這個時間包括它等你按允許的時間。

L0-5・照工單施工

招聘準備第五課：交出第一張工單＋結業

從 L1 開始，每一課你都會拿到一份《施工工單》，把它交給施工人員，他照著做。這一課先用一張 15 分鐘做得完的迷你工單練一次：整理一份會議紀錄。最後替秘書申請好 Gemini API Key，L0 就結業了。

一、工單是什麼

工單是寫給施工人員看的完整說明書。你不用看懂每一行。你在工單裡的身分叫委託人，要做的只有四件事：

  1. 交出工單
  2. 回答它的問題
  3. 簽核：它開工前會給你一張確認單，你看過沒問題才回「同意」
  4. 驗收：它說做完了，你自己打開成品檢查
📌 桌面 App 建檔、改檔不會先問你，所以「簽核」是你唯一的事前把關，「驗收」是事後把關。兩關都要確實做。

二、交出迷你工單

步驟 1：把工單放進 ai-practice

從課程教材裡找到《L0-5_會議紀錄_迷你工單.md》，複製到 ai-practice 資料夾。

步驟 2：開新對話，交出工單

從 ai-practice 的「＋」開新對話，然後說：

💬 貼到 Antigravity 對話框
請先完整讀過目前資料夾裡的 L0-5_會議紀錄_迷你工單.md，照這份工單幫我施工。

步驟 3：回答它的問題

工單規定它要先問你兩題，然後停下來等你回答：

它會問你怎麼答
這場會議是哪一天開的？隨便給一個日期，例如「2026 年 9 月 22 日」
記錄人要寫誰的名字？你的名字；不想寫可以說「不用」

如果它沒問就自己填了日期，那是違反工單紀律，按 ■ 停下來，說「工單規定要先問我日期，請重來」。

步驟 4：簽核《開工確認》

👀 畫面會顯示（大致像這樣）
《開工確認》
要建立的檔案：會議紀錄_2026-09-22_展場攤位.md
位置：目前的工作資料夾
會議日期：2026-09-22
記錄人：（你的名字）
內容：討論重點、決議、待辦（共 3 項）、待確認事項
不會做的事：不改其他檔案、不執行任何指令
請回覆「同意」開工，或告訴我要改哪裡。

看過檔名、日期沒錯，回「同意」。它在你回「同意」之前就建了檔案的話，一樣是違反紀律。

這張工單寫明「不執行任何指令」。如果它問你要不要執行指令，選 5. No，旁邊打「工單規定不執行指令」。

步驟 5：看《完成回報》

它做完會交一份回報，列出自我檢查的結果。

三、驗收：你自己檢查

不要只看它的回報。按 Review 看內容，或用記事本打開檔案，對照下表：

#檢查項目正確答案
1檔名會議紀錄_你給的日期_展場攤位.md，日期是你說的，不是今天
2四段都有討論重點、決議、待辦、待確認
3待辦有三項交設計稿（小李，10/10）、聯絡印刷廠並比兩家價格（小王，未指定）、換運輸廠商（阿明，未指定）
4沒有亂填期限小王、阿明的期限都是「（未指定）」，不是 10/15
5決議預算上限 30 萬、攤位最晚 10/15 定案
6待確認小王、阿明的期限；下次開會的日期
7沒有多做資料夾裡除了這份會議紀錄，其他檔案都沒被改

第 4 項是 AI 最常犯的錯：筆記裡有「10/15 定案」，它很容易拿來當別人的期限。最後把關的是你。有錯就直接告訴它哪裡不對，例如「小王那項原文沒有期限，請改成（未指定）」。

四、申請 Gemini API Key

施工人員用你的 Google 帳號登入；秘書是在背景跑的程式，要用 API Key（L0-1 第四節）。

  1. 前往 Google AI Studio 的 API Keys 頁面，用個人 Google 帳號登入。
  2. 第一次使用會請你同意服務條款。同意後通常會自動建好一把金鑰。
  3. 沒有看到金鑰的話，按「Create API key」建立一把。
  4. 按複製，存到安全的地方（見下表）。

免費方案不用綁信用卡，額度夠你在 L1 試用秘書。

✅ 可以⛔ 不可以
存進密碼管理工具（瀏覽器或手機內建的密碼管理）貼進施工人員的對話框：對話內容會送到雲端
暫時不存也行：L1 要用時，再回 AI Studio 建一把新的存在 ai-practice 資料夾裡：施工人員可以自由讀取那裡的檔案
截圖、傳 LINE、貼到群組或筆記 App

萬一外流了：回到同一個 AI Studio 頁面，先建一把新的，再把舊的刪掉。

施工人員（Google 帳號）和秘書（API Key）的額度各算各的，一邊用完不影響另一邊。

結訓考核（L0 結業）

#考核項目怎麼考合格標準
T0-5-01它有照紀律步驟 3、4先問你日期、先給《開工確認》，得到「同意」才建檔
T0-5-02成品合格第三節驗收表七項全部正確（有錯叫它改到正確也算通過）
T0-5-03回報屬實對照《完成回報》和你的驗收結果它打勾的項目，你檢查也是對的
T0-5-04金鑰就緒第四節已申請；存在安全的地方，不在 ai-practice 裡、沒貼進任何對話
🎓 L0 招聘準備結業。你已經有一位會用的施工人員，也有秘書的大腦通行證了。下一步：L1 到職。
L1 的秘書要用 Telegram 跟你聯絡。還沒有的話，可以先在手機和電腦都裝好（L1 第二章「準備三」）。

L1・到職

替自己招一位 AI 秘書

你不用會寫程式。你要做的事，跟招一位新秘書差不多：先面談、幫他辦報到、讓他試用、合格了再轉正。真正動手寫程式的，是施工人員照《施工工單》做。

👀 這堂課結束，你的手機 Telegram 會長這樣
你       09:12  你是誰？
Melo     09:12  我是 Melo，你的私人秘書。有事交代就說，我會盡量一次講清楚。
你       09:13  記下來：我每週一早上九點開部門會議
Melo     09:13  好，已經記在我的人事資料裡了。下次重新上班之後就會記得。

他會認得你、有自己的個性、有辦公桌（能在自己的資料夾裡讀寫檔、執行指令）、只聽你的、你說「記下來」才記。跨天記得聊過什麼、看行事曆、擬信、主動提醒，之後的課程會教。

秘書在你的電腦上班，用網路連到 Google Gemini（大腦）和 Telegram（手機）。不用租雲端主機，代價是：電腦要開著、不能睡眠，他才能回你訊息。平台：Windows 10／11 已完整驗證；macOS 驗證中；Linux 不支援。

第一章・面談準備

施工人員開工前會先面談你九個問題。先把答案想好，面談時直接貼上最快。不回答的題目會用預設值。

問題會寫進不回答的話
秘書要裝在哪個資料夾？（它可能會說「專案」，意思一樣）—家目錄下的 ai-secretary
他叫什麼名字？SOUL.mdMelo
他的職務？（例：私人秘書、業務助理、學習夥伴）SOUL.md私人秘書
他的個性和說話方式？SOUL.md簡潔直接，不繞圈
他一定要守的規矩？SOUL.md不懂就說不懂，不胡說
他該怎麼稱呼你？MEMORY.md你
簡單說你是誰、在做什麼？MEMORY.md（未提供）
你希望他特別注意什麼？MEMORY.md（未提供）
還有其他想讓他記住的事嗎？MEMORY.md（無）

可以先在記事本寫好像這樣的答案，面談時整段貼上（不用寫題號，它的編號可能跟這裡不一樣）：

💬 面談時貼到 Antigravity 對話框（先改成你的答案）
安裝位置：用預設
名字：Melo
職務：私人秘書
個性：簡潔直接，不繞圈
規矩：不懂就說不懂，不胡說
稱呼：老闆
我是誰：我在一家公司做業務，常要整理會議紀錄
注意事項：一律用繁體中文
其他：無
  • 不要寫密碼、身分證字號、銀行帳號。這些資料會送到 Google 的伺服器。
  • 答案之後都能改。人事資料就是兩個文字檔，用記事本打開就能編輯。

第二章・報到準備

秘書報到前，要幫他準備好這幾樣東西。

準備一：一台會開著的電腦，裝好 Node.js

L0-3 已經裝好了（v22.19 以上）。

準備二：Gemini API Key

L0-5 已經申請好了。

準備三：安裝 Telegram（手機＋電腦）

  1. 手機：到 App Store 或 Google Play 安裝 Telegram，用手機號碼註冊。之後跟秘書對話都用手機。
  2. 電腦：也登入 Telegram，下一步跟 BotFather 拿 Token 要在電腦上做，複製貼上才方便。二選一：
    • 安裝 Telegram Desktop（telegram.org）
    • 用瀏覽器打開 Telegram Web（web.telegram.org），用手機 Telegram 掃 QR Code 登入
⚠️ 不要在手機上拿 Token 再用 LINE、Email 傳給自己，那樣等於外流。

準備四：秘書的手機號碼（Telegram Bot）

在電腦的 Telegram 操作：

  1. 上方搜尋欄打 @BotFather（名字旁邊有藍色勾勾的才是官方的），點進去，按 Start。
  2. 傳 /newbot。它會先問顯示名稱（中英文都可以，例如「我的秘書」），再問帳號名稱（只能用英文、數字、底線，結尾一定要是 bot，例如 carme_secretary_bot；被用過的話換一個）。
  3. 建好後會出現一張卡片：大頭貼、名字、名字下面一行灰色的 @你的bot名稱，還有一條 🔑 被遮住的 Token。
卡片上的怎麼做
藍色 Copy按它複製 Token，存到密碼管理工具。Token 跟金鑰一樣重要
紅色 Revoke⛔ 不要按：Token 會作廢，要重新拿一個
名字下面灰色的 @你的bot名稱按它，就會打開跟你的秘書 Bot 的對話
  1. 在秘書 Bot 的對話裡按 Start，再隨便傳一句話（例如「hi」）。
找不到那行灰色的 @ 名稱？在 Telegram 上方的搜尋欄打 @你的bot名稱，一樣找得到。

準備五：查出你自己的 User ID

這是秘書用來認主人的號碼。這一步要用一次 PowerShell（Windows 用打字操作電腦的視窗）：

  1. 按鍵盤的 Windows 鍵，打 powershell，點「Windows PowerShell」。不要選「以系統管理員身分執行」。
  2. 先在記事本把下面這行的 你的Token 換成真的 Token（引號要留著），再整行複製。
  3. 在 PowerShell 視窗裡按滑鼠右鍵就會貼上，按 Enter。
⌨️ 貼到 PowerShell（先把「你的Token」換掉）
$token = "你的Token"; (Invoke-RestMethod "https://api.telegram.org/bot$token/getUpdates").result | ForEach-Object { [PSCustomObject]@{ Id = $_.message.from.id; Name = $_.message.from.first_name } }

畫面會出現一串數字和你的名字，那串數字就是你的 User ID，記下來。

  • 什麼都沒出現？代表準備四的第 4 步還沒做。回 Telegram 對 Bot 傳一句話，再按鍵盤 ↑ 叫回剛剛那行，按 Enter。
  • 出現紅字「未預期的 '(' 語彙基元」？貼上時斷成兩行了。重新整行複製再貼一次。
  • 不要把 Token 貼進施工人員的對話框請它幫你查，Token 跟金鑰一樣不能進對話。

第三章・到職手續

步驟 1：準備秘書的辦公室

  1. 照 L0-2 的做法，用檔案總管進到你的家目錄，建一個空的資料夾 ai-secretary，再對它按右鍵「釘選到 [快速存取]」。這就是秘書的工作資料夾。
  2. 把《L1_到職篇_施工工單.md》複製進去。
  3. 用記事本打開工單，看開頭表格的「版次」，要是 V1.5 或更新。舊版的工單會讓施工人員多做很多不必要的事。
  4. 照 L0-3 步驟 4，把 ai-secretary 加進 Antigravity 的 Projects 清單（Open workspace 視窗左邊的「常用」點 ai-secretary → 選擇資料夾）。
  5. 滑鼠移到 Projects 清單裡的 ai-secretary 上，按「＋」開新對話，確認標題開頭是「ai-secretary /」。

步驟 2：交出工單

💬 貼到 Antigravity 對話框
請先完整讀過目前資料夾裡的 L1_到職篇_施工工單.md，照這份工單幫我建置。

一開始它會查電腦環境（作業系統、Node.js 版本），會問你要不要執行 node --version 這類指令。這些只是查版本，選 1 就好。

步驟 3：接受面談

它會一次問完第一章的九題。把準備好的答案貼上。如果它沒問就自己填了名字或背景，按 ■ 叫它停下來重新問。

步驟 4：簽核《到職確認單》

它會整理一張確認單：安裝位置、秘書的人設、你的資料，還有一行「工程自檢：self-check.mjs＋品檢/L1.mjs……只執行 node self-check.mjs 一行」。都沒錯再回「同意」。

步驟 5：施工中，它會問你的事

它會建立十幾個檔案（不會問你），中間有幾次要執行指令會問你：

它要執行的怎麼選
node --version、npm --version 之類查版本的1
npm install（安裝秘書要用的套件）1
node self-check.mjs（工程自檢，用假金鑰，大約 2 分鐘）1，然後等它跑完
npm start、node --env-file=.env bridge.mjs⛔ 5. No，旁邊打「工單規定自檢不准用 .env 啟動」
執行它自己寫的腳本，例如 node "…\scratch\test-q03.mjs"、check-….mjs⛔ 5. No，旁邊打「工單規定只准執行 node self-check.mjs」
⚠️ 它連續違反工單兩次，就按 ■ 停掉，從 ai-secretary 的「＋」開一段新對話，重新交工單。同一段對話裡它一旦偏掉，常常越糾正越亂。

步驟 6：填寫通行證

施工完成後，它會請你把金鑰填進 ai-secretary 裡的 .env 檔：

  1. 用檔案總管打開 ai-secretary，找到 .env。
  2. 在它上面按右鍵 →「開啟檔案」或「開啟方式」→ 選記事本。
  3. 在三個等號後面填上你的值，存檔：
👀 記事本裡的 .env（照格式填，不用複製）
GEMINI_API_KEY=你的Gemini金鑰
TELEGRAM_BOT_TOKEN=你的BotToken
TELEGRAM_ALLOWED_USERS=你的UserID
⚠️ 一定要填在 .env，不是 .env.example。.env.example 是空白範本，之後可能會被上傳到網路。兩個檔名很像，填錯檔是最常見的錯誤。
金鑰只填進記事本，不要貼進對話框。填好後回對話框說「填好了」即可。

步驟 7：驗收它的交貨報告

它最後會交一份交貨報告。不要只看它寫「全部通過」，自己檢查這三件事：

#檢查怎麼看
1自檢真的有跑報告裡有一行原文「自檢結束：✅ 11　❌ 0　👀 1」這樣的字（數字可能不同，❌ 要是 0）。沒有這一行，就是沒跑，請它照工單執行 node self-check.mjs
2自檢檔在 ai-secretary 裡檔案總管裡 ai-secretary 有 self-check.mjs 和 品檢 資料夾
3人事資料是你的用記事本打開 SOUL.md、MEMORY.md，名字、稱呼跟你面談的答案一樣

步驟 8：第一天上班

到 ai-secretary 資料夾，雙擊 啟動 Agent.bat。跳出黑色視窗，看到這兩行就是上班了：

👀 黑色視窗會顯示
Agent 已啟動，模型 google/gemini-3.5-flash-lite（思考等級: medium），工具：…
等待 Telegram 訊息…

這個視窗不要關。關掉就是下班。

第四章・試用期考核

試用期用 Gemini 免費額度，不花一毛錢。用手機逐項考核，全部通過才轉正。

#考核項目怎麼考合格標準
1認得自己傳「你是誰？」名字、職務、個性跟面談的答案一致
2認得老闆傳「我是誰？」稱呼、背景、注意事項跟面談的答案一致
3會看文件傳「把 SOUL.md 第一行唸給我」內容跟檔案一致
4交代的事會記傳「記下來：我週三晚上不回訊息」→ 關掉黑視窗、重新雙擊啟動 → 傳「我週三晚上怎樣？」重新上班後答得出來
5不會自作主張隨便聊幾句，不要說「記下來」打開 MEMORY.md，內容沒被改動
6只聽老闆的用另一個 Telegram 帳號傳訊息給他完全沒回應；黑視窗印出「忽略非白名單使用者」
7看得出他在忙傳「幫我寫一段 300 字的自我介紹」回覆出來之前，對話視窗上方顯示「輸入中…」

免費額度大約是每分鐘 15 次、每天 500 次（以 Google 官方公告為準）。真的超過時，他會回「額度或速率上限可能已到」，這不是壞掉。建議試用 3 到 7 天，確定他適合你再轉正。

第五章・轉正

什麼時候轉正：考核都通過，而且常常看到「額度已到」，或你打算每天靠他辦事。

  1. 到 Google AI Studio 開通計費（綁信用卡）。
  2. 馬上設定預算上限和用量警示（例如每月 5 美元）。
  3. 完成。程式、.env、金鑰通通不用改，同一把金鑰的額度會自動提高。

一個人日常使用，一個月大約是幾十元台幣的等級，以 Google 帳單為準。依 Google 的條款，免費層的對話內容可能被用來改善 Google 的產品，付費層則不會。如果你會跟秘書討論公司業務，轉正也是保護資料的一步。

第六章・日常管理

動作怎麼做
上班雙擊 啟動 Agent.bat
下班關掉黑色視窗，或在視窗裡按 Ctrl + C
重新上班（重啟）先下班，再上班
  • 同一時間只能開一個黑視窗。開兩個會互搶訊息，視窗裡會出現 Conflict 錯誤。
  • 叫他「記下來」之後、自己改了 SOUL.md 或 MEMORY.md 之後，都要重啟才會生效。改人事資料時章節標題不要刪，只改內容。

讓他只聽你的

程式裡已經有白名單，只有 .env 裡的 User ID 能跟他說話。在 Telegram 再多鎖一道：

  1. 對 @BotFather 傳 /setjoingroups，選你的 Bot，選 Disable（不能被拉進群組）。
  2. 傳 /setprivacy，選你的 Bot，選 Enable。
  3. 不要公開你的 Bot 帳號名稱。他能在你電腦上執行指令，能跟他說話的人，某種程度上就能操作你的電腦。

金鑰外洩了怎麼辦

  • Telegram Token：對 @BotFather 傳 /revoke，選你的 Bot，拿新 Token 換進 .env，重啟。
  • Gemini 金鑰：到 AI Studio 刪掉舊金鑰、建新的，換進 .env，重啟。

Q&A

Q：啟動時說「找不到 GEMINI_API_KEY」或「.env: not found」？
你可能把金鑰填進了 .env.example。確認資料夾裡有一個叫 .env 的檔案，金鑰要填在那裡。

Q：黑視窗一直跳「Conflict: terminated by other getUpdates request」？
有兩個秘書同時在上班。把所有黑視窗都關掉，只開一個。

Q：雙擊 啟動 Agent.bat 後視窗一閃就不見？
通常是這個檔案被人用記事本改過。請施工人員照工單重新建立這個檔案，不要自己修改它。

Q：手機傳訊息，他都不回？
依序檢查：① 電腦是不是睡著了？② 黑視窗還開著嗎？③ 黑視窗有沒有紅字錯誤？

Q：黑視窗偶爾出現「輪詢錯誤：fetch failed」？
網路短暫不穩，程式會自己重試，送不出去的回覆會在網路恢復後補送。一直出現才需要檢查網路。

Q：筆電闔上就不回了？
Windows 到「電源選項」把「闔上蓋子時」改成「不執行任何動作」。

Q：他忘了剛剛聊過的事？
重啟過就會忘，這是 L1 的設計。他只記得人事資料裡寫的東西。跨天的記憶在 L2 教。

Q：交貨報告叫我用 @userinfobot 查 User ID？
那是第三方的 Bot，本課程不用。照第二章「準備五」查就好。
